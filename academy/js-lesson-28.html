Arrow Function

Arrow Function — JavaScript'da function yozishning qisqaroq va zamonaviy usuli.

U ayniqsa qisqa functionlar va Array metodlari bilan ishlaganda juda qulay.

Arrow Function nima? 🤔

Oddiy function: 

function salom() {

    console.log("Salom!");

}

Shu functionni Arrow Function ko‘rinishida yozsak: 

const salom = () => {

    console.log("Salom!");

};

Arrow belgisi ➡️

=> belgisi Arrow Function'ning asosiy belgisi hisoblanadi. 

const salom = () => {

    console.log("Salom");

};

Bu yerda:

() → parametrlar
=> → arrow
{ } → function tanasi

Arrow Functionni chaqirish 📞 

const salom = () => {

    console.log("Salom, JavaScript!");

};

salom();
Salom, JavaScript!

Parametr bilan Arrow Function 📥 

const salom = (ism) => {

    console.log("Salom, " + ism);

};

salom("Ali");
Salom, Ali

Bu yerda ism — parametr.

Bir nechta parametr 🔢 

const qoshish = (a, b) => {

    console.log(a + b);

};

qoshish(10, 20);
30

return bilan Arrow Function ↩️

Arrow Function oddiy function kabi return ishlatishi mumkin. 

const qoshish = (a, b) => {

    return a + b;

};

console.log(qoshish(5, 7));
12

Implicit return ⚡

Agar Arrow Function faqat bitta expressionni qaytarsa, return va { } ni qisqartirish mumkin. 

const qoshish = (a, b) => a + b;

console.log(qoshish(5, 7));
12

Bu:


const qoshish = (a, b) => a + b;

quyidagiga teng:

const qoshish = (a, b) => { return a + b; };

Bitta parametr bo‘lsa 🔹

Bitta parametr bo‘lsa, qavslarni yozmaslik mumkin. 

const kvadrat = son => son * son;

console.log(kvadrat(5));
25

Qavs bilan ham yozish mumkin: 

const kvadrat = (son) => son * son;

Ikkala yozilish ham to‘g‘ri.

Parametr bo‘lmasa 🔸

Parametr bo‘lmasa, bo‘sh qavs yoziladi. 

const salom = () => "Salom!";

console.log(salom());

String bilan ishlash 📝 

const kattaHarf = matn =>
    matn.toUpperCase();

console.log(
    kattaHarf("javascript")
);
JAVASCRIPT

Boolean qaytarish ✅ 

const juftmi = son =>
    son % 2 === 0;

console.log(juftmi(10));
console.log(juftmi(7));
true
false

Arrow Function va if 🔀 

const baho = ball => {

    if (ball >= 90) {
        return "A";
    }

    if (ball >= 70) {
        return "B";
    }

    return "C";

};

console.log(baho(95));
console.log(baho(75));
console.log(baho(60));

Arrow Function va ternary ⚡ 

const tekshir = yosh =>
    yosh >= 18
        ? "Kirish mumkin"
        : "Kirish mumkin emas";

console.log(tekshir(20));
console.log(tekshir(15));

Oddiy function va Arrow Function ⚖️ 

// Oddiy function

function qoshish(a, b) {

    return a + b;

}


// Arrow Function

const qoshish2 = (a, b) => {

    return a + b;

};

Ikkalasi ham function hisoblanadi. Arrow Function esa qisqaroq yozilish imkonini beradi.

Eng qisqa ko‘rinish 🚀 

const qoshish = (a, b) => a + b;

const ayirish = (a, b) => a - b;

const kopaytirish = (a, b) => a * b;

const bolish = (a, b) => a / b;
console.log(qoshish(10, 5));
console.log(ayirish(10, 5));
console.log(kopaytirish(10, 5));
console.log(bolish(10, 5));

Arrow Function Object qaytarishi 🧩

Arrow Functiondan Object qaytarishda qavsga e'tibor berish kerak. 

const user = () => ({
    name: "Ali",
    age: 16
});

console.log(user());

Objectni ( ) ichiga olish kerak.

Arrow Function va Array 📚 

const mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

const birinchi = arr => arr[0];

console.log(
    birinchi(mevalar)
);
Olma

Arrow Functionni o‘zgaruvchiga saqlash 📦 

const ismniChiqar = ism =>
    `Salom, ${ism}!`;

let result = ismniChiqar("Mirjamol");

console.log(result);

Function sifatida boshqa functionga berish 🔗

Keyingi darslarda Arrow Function boshqa functionlarga argument sifatida berilishini ko‘p ko‘ramiz. 

const qoshish = (a, b) => a + b;

function hisobla(fn, a, b) {

    return fn(a, b);

}

console.log(
    hisobla(qoshish, 10, 20)
);
30

Muhim: Arrow Function va this ⚠️

Arrow Function oddiy functiondan ayrim jihatlari bilan farq qiladi.

Eng muhim farqlardan biri — Arrow Function o‘zining this qiymatini yaratmaydi.

this mavzusini keyinroq alohida darsda batafsil o‘rganamiz.

Bugungi asosiy sintaksis 📌

🔹 Parametrsiz:
const fn = () => qiymat;

🔹 Bitta parametr:
const fn = x => qiymat;

🔹 Bir nechta parametr:
const fn = (x, y) => qiymat;

🔹 Ko‘p qatorli:
const fn = (x) => {
  return x;
};
