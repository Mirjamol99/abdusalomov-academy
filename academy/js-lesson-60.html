LocalStorage

Bugun JavaScript yordamida ma'lumotlarni brauzerda saqlashni o‘rganamiz.

LocalStorage yordamida foydalanuvchi sahifani yopib ochsa ham ma'lumotlarni saqlab qolish mumkin.

💾 LocalStorage nima?

localStorage — brauzerning ma'lumot saqlash imkoniyatlaridan biri.

U orqali ma'lumotlarni brauzerda saqlash mumkin.

🔥 Masalan:

👤 Foydalanuvchi ismi
🛒 Savatchadagi mahsulotlar
⚙️ Sozlamalar
🎨 Theme
📚 Kursdagi bajarilgan darslar

📥 setItem()

LocalStorage'ga ma'lumot saqlash uchun setItem() ishlatiladi. 

localStorage.setItem(
    "name",
    "Mirjamol"
);
Birinchi qiymat — key.

Ikkinchi qiymat — value.

📤 getItem()

Saqlangan ma'lumotni olish uchun getItem() ishlatiladi. 

let name =
    localStorage.getItem("name");

console.log(name);
Natija:

Mirjamol

🗑️ removeItem()

Bitta ma'lumotni o‘chirish uchun removeItem() ishlatiladi. 

localStorage.removeItem(
    "name"
);

Endi name mavjud bo‘lmaydi.

🧹 clear()

LocalStorage'dagi barcha ma'lumotlarni o‘chirish uchun clear() ishlatiladi. 

localStorage.clear();
⚠️ E'tibor!

clear() barcha LocalStorage ma'lumotlarini o‘chiradi.

🔢 LocalStorage faqat string saqlaydi

LocalStorage ma'lumotlarni asosan string ko‘rinishida saqlaydi. 

localStorage.setItem(
    "age",
    15
);

Olib ko‘rsak: 

let age =
    localStorage.getItem("age");

console.log(age);
Agar son bilan hisoblash kerak bo‘lsa: 
let age =
    Number(
        localStorage.getItem("age")
    );

console.log(age + 1);

🔄 JSON.stringify()

Object yoki Array'ni LocalStorage'ga saqlash uchun JSON.stringify() ishlatiladi. 

let user = {
    name: "Mirjamol",
    age: 15
};

let data =
    JSON.stringify(user);

console.log(data);
JSON.stringify()

Object → String

🔁 JSON.parse()

JSON stringni yana Object'ga aylantirish uchun JSON.parse() ishlatiladi. 

let data =
    '{"name":"Mirjamol","age":15}';

let user =
    JSON.parse(data);

console.log(user.name);
JSON.parse()

String → Object

📦 Object saqlash 

let user = {
    name: "Ali",
    age: 20,
    city: "Qarshi"
};


localStorage.setItem(
    "user",
    JSON.stringify(user)
);

Keyin olish: 

let savedUser =
    JSON.parse(
        localStorage.getItem("user")
    );


console.log(savedUser.name);
console.log(savedUser.age);
console.log(savedUser.city);

📚 Array saqlash

Array'ni ham LocalStorage'da saqlash mumkin. 

let fruits = [
    "Apple",
    "Banana",
    "Orange"
];


localStorage.setItem(
    "fruits",
    JSON.stringify(fruits)
);

Olish: 

let savedFruits =
    JSON.parse(
        localStorage.getItem("fruits")
    );


console.log(savedFruits);

📝 Form + LocalStorage

59-darsda o‘rgangan formamizni LocalStorage bilan birlashtiramiz.

Ism hali saqlanmagan. 

let form =
    document.querySelector("#nameForm");


form.addEventListener(
    "submit",
    function(event) {

        event.preventDefault();


        let name =
            document.querySelector(
                "#nameInput"
            ).value;


        localStorage.setItem(
            "name",
            name
        );

    }
);

🔄 Sahifa ochilganda ma'lumotni olish

LocalStorage'ning eng katta foydasi — sahifa qayta ochilganda ma'lumotni yana olish mumkin. 

let savedName =
    localStorage.getItem("name");


if (savedName) {

    console.log(
        "Salom, " + savedName
    );

}

🛒 Cart bilan LocalStorage

E-commerce saytlarida savatchani saqlash uchun LocalStorage juda foydali. 

let cart = [
    {
        id: 1,
        name: "Pizza",
        price: 50000
    }
];


localStorage.setItem(
    "cart",
    JSON.stringify(cart)
);

Savatchani qayta olish: 

let cart =
    JSON.parse(
        localStorage.getItem("cart")
    ) || [];


console.log(cart);

➕ LocalStorage'ga yangi item qo‘shish 

let cart =
    JSON.parse(
        localStorage.getItem("cart")
    ) || [];


cart.push({
    id: 2,
    name: "Burger",
    price: 30000
});


localStorage.setItem(
    "cart",
    JSON.stringify(cart)
);
🔥 Muhim:

Avval LocalStorage'dan Array'ni olamiz.

Keyin push() qilamiz.

Oxirida yana LocalStorage'ga saqlaymiz.

🗑️ Cart item o‘chirish 

cart =
    cart.filter(function(item) {

        return item.id !== 2;

    });


localStorage.setItem(
    "cart",
    JSON.stringify(cart)
);

🎨 Theme saqlash

Foydalanuvchi tanlagan theme'ni ham LocalStorage'ga saqlash mumkin. 

localStorage.setItem(
    "theme",
    "dark"
);

Keyin: 

let theme =
    localStorage.getItem("theme");

console.log(theme);

📚 Dars progressini saqlash

Kurs saytimizda tugatilgan darslarni LocalStorage'ga saqlashimiz mumkin. 

let completedLessons =
    JSON.parse(
        localStorage.getItem(
            "completedLessons"
        )
    ) || [];


completedLessons.push(60);


localStorage.setItem(
    "completedLessons",
    JSON.stringify(
        completedLessons
    )
);

🔍 LocalStorage mavjudligini tekshirish 

let name =
    localStorage.getItem("name");


if (name !== null) {

    console.log(
        "Ma'lumot mavjud!"
    );

} else {

    console.log(
        "Ma'lumot topilmadi!"
    );

}
Agar key mavjud bo‘lmasa, getItem() odatda null qaytaradi.

🧠 LocalStorage metodlari

setItem()

getItem()

removeItem()

clear()

JSON.stringify()

Object yoki Array'ni JSON stringga aylantiradi.

JSON.parse()

JSON stringni Object yoki Array'ga aylantiradi.
