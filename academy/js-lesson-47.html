Destructuring

Bugungi darsda JavaScript'dagi Destructuring bilan tanishamiz.

Destructuring yordamida Array va Object ichidagi qiymatlarni tez va qulay tarzda alohida o‘zgaruvchilarga ajratib olish mumkin.

📦 Destructuring nima?

Destructuring — Array yoki Object ichidagi ma'lumotlarni alohida o‘zgaruvchilarga ajratib olish usuli.

Oddiy usulda Array'dan qiymat olish: 

let fruits = [
    "Apple",
    "Banana",
    "Mango"
];

let first = fruits[0];
let second = fruits[1];
let third = fruits[2];

console.log(first);
console.log(second);
console.log(third);

Destructuring bilan esa ancha qisqa: 

let fruits = [
    "Apple",
    "Banana",
    "Mango"
];

let [first, second, third] = fruits;

console.log(first);
console.log(second);
console.log(third);

🔢 Array Destructuring

Array destructuring'da qiymatlar o‘z navbatidagi index bo‘yicha o‘zgaruvchilarga biriktiriladi. 

let numbers = [10, 20, 30];

let [a, b, c] = numbers;

console.log(a);
console.log(b);
console.log(c);
10
20
30
a → 1-element
b → 2-element
c → 3-element

🎯 Kerakli qiymatni olish

Agar Array'dagi faqat ayrim qiymat kerak bo‘lsa, qolgan joyni bo‘sh qoldirish mumkin. 

let numbers = [
    10,
    20,
    30
];

let [, second, third] = numbers;

console.log(second);
console.log(third);
20
30
Birinchi elementni olish kerak emasligi uchun birinchi joy bo‘sh qoldirildi.

📦 Rest operator bilan Array Destructuring

... yordamida qolgan elementlarni bitta Array ichida yig‘ib olish mumkin. 

let numbers = [
    10,
    20,
    30,
    40,
    50
];

let [first, second, ...rest] = numbers;

console.log(first);
console.log(second);
console.log(rest);
10
20

[30, 40, 50]

🔄 Array qiymatlarini almashtirish

Destructuring yordamida ikkita o‘zgaruvchining qiymatini juda oson almashtirish mumkin. 

let a = 10;
let b = 20;

[a, b] = [b, a];

console.log(a);
console.log(b);
20
10
Bu usul JavaScript'da juda ko‘p ishlatiladi.

🎯 Default qiymat

Agar Array'da kerakli qiymat bo‘lmasa, default qiymat berish mumkin. 

let numbers = [10];

let [a, b = 20] = numbers;

console.log(a);
console.log(b);
10
20

📦 Object Destructuring

Endi Object bilan ishlaymiz.

Masalan: 

let user = {

    name: "Ali",

    age: 18,

    city: "Andijon"

};

Oddiy usul: 

let name = user.name;
let age = user.age;
let city = user.city;

console.log(name);
console.log(age);
console.log(city);

⚡ Object Destructuring bilan 

let user = {

    name: "Ali",

    age: 18,

    city: "Andijon"

};

let {
    name,
    age,
    city
} = user;

console.log(name);
console.log(age);
console.log(city);
Ali
18
Andijon

🔑 Object'da property nomi muhim

Object destructuring'da o‘zgaruvchi nomi Object'dagi key bilan mos keladi. 

let user = {

    name: "Ali",

    age: 18

};

let {
    name,
    age
} = user;

console.log(name);
console.log(age);

✏️ Boshqa nom berish

Object'dagi property'ni boshqa o‘zgaruvchi nomi bilan olish mumkin. 

let user = {

    name: "Ali",

    age: 18

};

let {
    name: userName,
    age: userAge
} = user;

console.log(userName);
console.log(userAge);
Ali
18
name: userName

Bu:
Object'dagi name qiymatini
userName o‘zgaruvchisiga beradi.

🎯 Object'da default qiymat 

let user = {

    name: "Ali"

};

let {
    name,
    age = 18
} = user;

console.log(name);
console.log(age);
Ali
18

📦 Object + Array

Object ichida Array bo‘lsa, destructuring yordamida uni ham ajratib olish mumkin. 

let student = {

    name: "Ali",

    subjects: [
        "Math",
        "English",
        "JavaScript"
    ]

};

let {
    name,
    subjects
} = student;

console.log(name);
console.log(subjects);

🔍 Nested Object Destructuring

Object ichida boshqa Object bo‘lsa, nested destructuring ishlatish mumkin. 

let user = {

    name: "Ali",

    address: {

        city: "Andijon",

        street: "Navoi"

    }

};

let {
    name,
    address: {
        city,
        street
    }
} = user;

console.log(name);
console.log(city);
console.log(street);
Ali
Andijon
Navoi

📤 Function parametrida Destructuring

Destructuring function parametrlarida ham juda ko‘p ishlatiladi. 

let user = {

    name: "Ali",

    age: 18

};

function showUser({ name, age }) {

    console.log(name);
    console.log(age);

}

showUser(user);
Ali
18

🔥 Array Object Destructuring

Array ichidagi Object'ni bir vaqtning o‘zida destructuring qilish mumkin. 

let users = [

    {
        name: "Ali",
        age: 18
    },

    {
        name: "Vali",
        age: 20
    }

];

let [
    { name: firstName },
    { name: secondName }
] = users;

console.log(firstName);
console.log(secondName);
Ali
Vali

🧠 Destructuring qayerda ishlatiladi?

Array

Array elementlarini ajratib olish.

Object

Object property'larini ajratib olish.

Function

Function parametrlarida ishlatish.
