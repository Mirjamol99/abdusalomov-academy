Label va Form elementlari

Form elementlarini label bilan bog'lash va foydalanuvchi uchun qulay formalar yaratishni o'rganamiz.

1. <label> nima?

<label> formadagi input, select yoki boshqa element nimaga tegishli ekanini ko'rsatadi. 

<label>
    Ismingiz
</label>

<input type="text">

2. for atributi

for labelni ma'lum bir input bilan bog'lash uchun ishlatiladi. 

<label for="name">
    Ismingiz
</label>

<input
    type="text"
    id="name">

Label ustiga bosib ko'rsangiz, input avtomatik tanlanadi.

3. id va for bir-biriga mos bo'lishi kerak

Labelning for qiymati inputning id qiymatiga teng bo'lishi kerak. 

<label for="email">
    Email
</label>

<input
    type="email"
    id="email">

4. Password bilan ishlash 

<label for="password">
    Parol
</label>

<input
    type="password"
    id="password">

5. Label + Select

Label faqat input uchun emas. Select bilan ham ishlatiladi. 

<label for="course">
    Kurs
</label>

<select id="course">

    <option>HTML</option>

    <option>CSS</option>

</select>

6. Label + Textarea 

<label for="message">
    Xabar
</label>

<textarea
    id="message">
</textarea>

7. Checkbox bilan label

Checkboxda ham label ishlatish foydalanuvchi uchun qulay. 

<input
    type="checkbox"
    id="agree">

<label for="agree">
    Qoidalarni qabul qilaman
</label>

8. Radio button bilan label

Radio button yordamida foydalanuvchi variantlardan birini tanlashi mumkin. 

<input
    type="radio"
    name="level"
    id="beginner">

<label for="beginner">
    Boshlang'ich
</label>


<input
    type="radio"
    name="level"
    id="advanced">

<label for="advanced">
    Yuqori
</label>
