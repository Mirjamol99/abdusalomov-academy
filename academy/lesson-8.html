HTML'da jadvallar

Bugun HTML yordamida chiroyli va tartibli jadvallar yaratishni o'rganamiz.

1. <table> tegi nima?

HTML'da jadval yaratish uchun <table> tegi ishlatiladi.

Jadval ichida qatorlar va kataklar bo'ladi.

2. <tr> — Jadval qatori

<tr> jadvaldagi bitta qatorni bildiradi. 

<table>

    <tr>
        ...
    </tr>

</table>

3. <td> — Oddiy katak

<td> jadvaldagi oddiy ma'lumot katagini yaratadi. 

<table>

    <tr>

        <td>Mirjamol</td>
        <td>16</td>

    </tr>

</table>

4. <th> — Sarlavha katagi

<th> jadvalning sarlavha katagini yaratadi. 

<tr>

    <th>Ism</th>
    <th>Yosh</th>

</tr>

5. To'liq jadval

Endi barcha teglarni birlashtirib, oddiy jadval yaratamiz. 

<table>

    <tr>
        <th>Ism</th>
        <th>Yosh</th>
        <th>Kurs</th>
    </tr>

    <tr>
        <td>Ali</td>
        <td>16</td>
        <td>HTML</td>
    </tr>

    <tr>
        <td>Vali</td>
        <td>17</td>
        <td>CSS</td>
    </tr>

</table>

Ism Yosh Kurs

Vali 17 CSS
Hasan 16 JavaScript

6. <thead> va <tbody>

Katta jadvallarda jadvalni qismlarga ajratish uchun thead va tbody ishlatiladi. 

<table>

    <thead>

        <tr>
            <th>Ism</th>
            <th>Kurs</th>
        </tr>

    </thead>


    <tbody>

        <tr>
            <td>Ali</td>
            <td>HTML</td>
        </tr>

    </tbody>

</table>

Jadval strukturasi 🧠

<table>

Jadvalni yaratadi.

<tr>

Qator yaratadi.

<th>

Sarlavha katagi.

<td>

Oddiy katak.
