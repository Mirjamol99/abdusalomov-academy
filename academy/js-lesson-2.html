JavaScriptni HTMLga ulash

Bugun JavaScript kodini HTML sahifamizga qanday ulashni o‘rganamiz.

JavaScript nima uchun HTMLga ulanadi? 🤔

HTML saytning tuzilishini yaratadi.

CSS saytning ko‘rinishini yaratadi.

JavaScript esa saytga harakat va interaktivlik beradi.

Shuning uchun JavaScript HTML sahifaga ulanishi kerak.

HTML + CSS + JavaScript

🧱 HTML → Tuzilish
🎨 CSS → Dizayn
⚡ JavaScript → Harakat

1-usul: Inline JavaScript

JavaScript kodini to‘g‘ridan-to‘g‘ri HTML elementining ichiga yozishimiz mumkin. 

<button onclick="alert('Salom!')">
    Bosish
</button>

Tugmani bosganimizda JavaScript ishlaydi.

2-usul: <script> tegi

JavaScript kodini <script> tegi ichida yozishimiz mumkin. 

<!DOCTYPE html>

<html>

<body>

    <h1>Salom JavaScript</h1>

    <script>

        alert("Salom!");

    </script>

</body>

</html>

✅ Brauzer sahifani ochganda JavaScript kodi ishlaydi.

3-usul: Tashqi JavaScript fayli ⭐

Eng yaxshi usullardan biri — JavaScript kodini alohida .js faylga yozish.

Masalan: 

index.html

script.js

HTML fayl

index.html ichida: 

<!DOCTYPE html>

<html lang="uz">

<head>

    <title>Mening saytim</title>

</head>

<body>

    <h1>Salom!</h1>


    <script src="script.js"></script>

</body>

</html>

JavaScript fayl

script.js ichida: 

alert("JavaScript ishladi!");

src nima?

src — JavaScript faylining manzilini ko‘rsatadi. 

<script src="script.js"></script>

📌 Agar fayl HTML bilan bir xil papkada bo‘lsa:

src="script.js"

Papka ichidagi JS fayl

Agar JavaScript fayli alohida papkada bo‘lsa, uning yo‘lini ko‘rsatamiz. 

project/

    index.html

    js/

        script.js

HTML'da: 

<script src="js/script.js"></script>

<script> qayerga yoziladi?

Odatda tashqi JavaScript faylini </body> dan oldin ulash juda qulay. 

<body>

    <h1>Salom</h1>


    <script src="script.js"></script>

</body>

✅ HTML elementlari yuklangandan keyin JavaScript ishlashi qulay bo‘ladi.

🔹 Tashqi JS faylni script.js kabi ulash mumkin.
