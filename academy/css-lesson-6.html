CSS Box Model 📦

CSS'dagi eng muhim mavzulardan biri — Box Model. Har bir HTML elementi aslida qanday "quti" ekanligini o'rganamiz.

1. Box Model nima?

CSS Box Model har bir HTML elementining o'lchami va atrofidagi bo'shliqlarni boshqaradi.

MARGIN
BORDER
PADDING
CONTENT
📦 Box Model 4 ta asosiy qismdan iborat:

1. Content — elementning asosiy mazmuni.
2. Padding — content bilan border orasidagi joy.
3. Border — element chegarasi.
4. Margin — elementning tashqarisidagi bo'sh joy.

2. `width`

`width` elementning kengligini belgilaydi. 

.box {
    width: 300px;
}
width: 300px

3. `height`

`height` elementning balandligini belgilaydi. 

.box {
    height: 150px;
}
height: 150px

4. `padding`

`padding` content bilan border orasidagi ichki bo'shliq. 

.box {
    padding: 30px;
}
Padding ichidagi content
💡 Padding elementning ichki bo'shlig'ini oshiradi.

5. `border`

`border` elementning chegarasini yaratadi. 

.box {
    border: 2px solid #22d3ee;
}
Border
Border yozilish tartibi:

`border: qalinlik turi rang;`

Masalan:
`border: 2px solid blue;`

6. `margin`

`margin` elementning tashqarisidagi bo'sh joyni belgilaydi. 

.box {
    margin: 30px;
}
BOX
📌 `padding` → ichkaridagi bo'sh joy.
📌 `margin` → tashqaridagi bo'sh joy.

7. `margin: auto`

`margin: auto` elementni gorizontal markazga joylashtirishda juda foydali. 

.box {
    width: 300px;
    margin: auto;
}
MEN MARKAZDAMAN 🎯

8. `box-sizing`

`box-sizing` elementning umumiy o'lchami qanday hisoblanishini belgilaydi. 

* {
    box-sizing: border-box;
}
⭐ Eng ko'p ishlatiladigan qiymat:

box-sizing: border-box;

Bu usulda `width` va `height` ichiga padding va border ham hisoblanadi.

9. Amaliy loyiha 💻

Endi Box Model yordamida zamonaviy card yaratamiz. 

<div class="card">

    <h2>
        Abdusalomov Academy
    </h2>

    <p>
        CSS Box Model
    </p>

</div>
.card {

    width: 100%;

    padding: 30px;

    margin: 20px 0;

    border: 2px solid #22d3ee;

    border-radius: 20px;

    box-sizing: border-box;

}
