CSS Display 🧩

CSS'da elementlarning sahifada qanday joylashishini boshqarish uchun display property ishlatiladi.

1. `display` nima?

`display` HTML elementining sahifada qanday ko'rinishda joylashishini belgilaydi. 

.box {
    display: block;
}
📌 Eng ko'p ishlatiladigan `display` qiymatlari:

`block`
`inline`
`inline-block`
`none`

2. `display: block`

`block` element yangi qatordan boshlanadi va mavjud kenglikni egallashga harakat qiladi. 

.box {
    display: block;
}
BLOCK 1
BLOCK 2
BLOCK 3
💡 `div`, `p`, `h1`, `section` kabi ko'plab elementlar odatda block sifatida ishlaydi.

3. `display: inline`

`inline` element yangi qatorga tushmaydi. U kerakli joyni egallaydi. 

.text {
    display: inline;
}
INLINE 1 INLINE 2 INLINE 3
📌 `span` elementi odatda inline sifatida ishlaydi.

4. `display: inline-block`

`inline-block` inline kabi bir qatorda turadi, lekin unga width va height berish mumkin. 

.box {
    display: inline-block;
    width: 150px;
    height: 100px;
}

5. `display: none`

`display: none` elementni sahifadan butunlay olib tashlaydi. 

.box {
    display: none;
}

Men ko'rinmayman ❌
⚠️ `display: none` berilgan element sahifada joy ham egallamaydi.

6. `visibility: hidden`

`visibility: hidden` elementni yashiradi, lekin uning joyi saqlanib qoladi. 

.box {
    visibility: hidden;
}

🔥 Farq:

`display: none` → joy ham yo'qoladi.
`visibility: hidden` → element yashirinadi, lekin joyi qoladi.
