do while loop

Bugun JavaScript'dagi do while loop bilan ishlashni o‘rganamiz.

do while loopning eng muhim xususiyati — shartni tekshirishdan oldin kodni kamida bir marta bajarishidir.

do while nima? 🤔

do while ham while kabi loop hisoblanadi.

Lekin ular orasida muhim farq bor.

while avval shartni tekshiradi, keyin kodni bajaradi.

do while esa avval kodni bajaradi, keyin shartni tekshiradi.

Sintaksisi 📚 

do {

    // bajariladigan kod

} while (shart);

do — bajariladigan kod blokini boshlaydi.

while — kod bajarilgandan keyin shartni tekshiradi.

E'tibor bering: do while oxirida ; yoziladi.

Eng oddiy misol

do {

    console.log(i);

    i++;

} while (i <= 5);

Quyidagi misolga qarang: 

let i = 10;

while (i < 5) {

    console.log(i);

}

Bu kod hech narsa chiqarmaydi, chunki 10 < 5 noto‘g‘ri. 

let i = 10;

do {

    console.log(i);

} while (i < 5);
10

Bu yerda shart boshidanoq false bo‘lsa ham, kod bir marta bajarildi.

    console.log("Hello");

continue bilan do while ⏭️

continue joriy aylanishni tashlab ketadi.

do while bilan ishlaganda o‘zgaruvchini shunday joylashtirish kerakki, loop cheksiz bo‘lib qolmasin.

Cheksiz loopdan ehtiyot bo‘ling ⚠️ 

let i = 1;

    console.log(i);

Bu yerda i o‘zgarmayapti.

Shuning uchun i <= 5 doim true bo‘lib qoladi.

Shu sababli do while kamida bir marta ishlaydi.

Qachon do while ishlatamiz? 🎯

do while quyidagi holatlarda foydali:

✅ Kod kamida bir marta bajarilishi kerak bo‘lsa.

✅ Foydalanuvchiga avval biror amal ko‘rsatib, keyin shartni tekshirish kerak bo‘lsa.

✅ Menyu yoki takroriy amalni kamida bir marta bajarish kerak bo‘lsa.

Masalan, foydalanuvchiga menyuni bir marta ko‘rsatish va keyin davom etish yoki chiqishni tekshirish.

♻️ do while — loopning yana bir turi.

🚀 Avval kod bajariladi, keyin shart tekshiriladi.

🔥 Shart false bo‘lsa ham, kod kamida bir marta bajariladi.

🛑 break — loopni to‘xtatadi.

⏭️ continue — joriy aylanishni tashlab ketadi.

⚠️ O‘zgaruvchini yangilashni unutmaslik kerak, aks holda cheksiz loop yuzaga kelishi mumkin.

🧠 while — avval shart, keyin kod.

🧠 do while — avval kod, keyin shart.
