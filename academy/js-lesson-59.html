Formalar va Inputlar

Bugun JavaScript yordamida form va input elementlari bilan ishlashni o‘rganamiz.

Foydalanuvchidan ma'lumot olish, qiymatni o‘qish, formani yuborish, preventDefault() va oddiy validation qilishni o‘rganamiz.

📋 Form nima?

<form> foydalanuvchidan ma'lumot olish va uni yuborish uchun ishlatiladi. 

<form>

    <input type="text">

    <button type="submit">
        Yuborish
    </button>

</form>
💡 Masalan:

Login formasi, ro‘yxatdan o‘tish, qidiruv, aloqa formasi va buyurtma formasi.

📝 Input nima?

<input> foydalanuvchi ma'lumot kiritishi uchun ishlatiladi. 

<input type="text">

text

Oddiy matn.

password

Parol kiritish.

email

Email manzil.

number

Son kiritish.

date

Sana tanlash.

checkbox

Belgilash.

🎯 Input qiymatini olish

Input qiymatini olish uchun .value ishlatiladi. 

let input =
    document.querySelector("#name");

console.log(input.value);
input.value → foydalanuvchi inputga yozgan qiymatni beradi.

🔥 Amaliy misol — ism olish

Natija shu yerda chiqadi. 

let input =
    document.querySelector("#demoName");

let button =
    document.querySelector("#showNameBtn");

let result =
    document.querySelector("#showNameResult");


button.addEventListener(
    "click",
    function () {

        result.textContent =
            input.value;

    }
);

🔐 Password input

Parol uchun type="password" ishlatiladi. 

<input
    type="password"
    id="password"
>

JavaScript orqali qiymatini olish: 

let password =
    document.querySelector("#password");

console.log(password.value);

📧 Email input 

<input
    type="email"
    id="email"
    placeholder="Email"
>

JavaScript: 

let email =
    document.querySelector("#email");

console.log(email.value);

🔢 Number input 

<input
    type="number"
    id="age"
>
⚠️ E'tibor bering:

Inputdan olingan qiymat odatda string bo‘ladi.

Hisoblash uchun: Number(input.value) ishlatish mumkin. 
let age =
    Number(
        document.querySelector("#age").value
    );

console.log(age + 1);

⚡ Form submit

Form yuborilganda submit event ishlaydi. 

let form =
    document.querySelector("#form");


form.addEventListener(
    "submit",
    function (event) {

        event.preventDefault();

        console.log(
            "Form yuborildi!"
        );

    }
);

🛑 preventDefault()

Form submit bo‘lganda brauzer odatda sahifani qayta yuklashi mumkin.

Buni to‘xtatish uchun: 

event.preventDefault();
🔥 JavaScript orqali formani o‘zimiz boshqarishimiz uchun preventDefault() juda muhim.

📝 To‘liq form misoli

Ma'lumot yuborilmagan. 

let form =
    document.querySelector("#studentForm");


form.addEventListener(
    "submit",
    function (event) {

        event.preventDefault();


        let name =
            document.querySelector(
                "#studentName"
            ).value;


        let email =
            document.querySelector(
                "#studentEmail"
            ).value;


        let age =
            document.querySelector(
                "#studentAge"
            ).value;


        console.log(name);
        console.log(email);
        console.log(age);

    }
);

🔍 Form validation

Validation — foydalanuvchi kiritgan ma'lumotlarni tekshirish.

Masalan: 

if (name === "") {

    console.log(
        "Ism kiritilmadi!"
    );

}
Bo‘sh inputni tekshirish uchun === "" ishlatish mumkin.

🔥 Validation amaliyoti 

form.addEventListener(
    "submit",
    function (event) {

        event.preventDefault();


        let name =
            document.querySelector(
                "#name"
            ).value;


        if (name === "") {

            alert(
                "Iltimos, ism kiriting!"
            );

            return;

        }


        alert(
            "Form muvaffaqiyatli yuborildi!"
        );

    }
);

✨ trim()

Foydalanuvchi faqat bo‘sh joy kiritib qo‘ymasligi uchun trim() ishlatiladi. 

let name =
    input.value.trim();


if (name === "") {

    console.log(
        "Input bo‘sh!"
    );

}
trim() matnning boshidagi va oxiridagi bo‘sh joylarni olib tashlaydi.

🔢 Number bilan validation 

let age =
    Number(ageInput.value);


if (age < 18) {

    console.log(
        "Yosh 18 dan kichik!"
    );

}

📏 minlength va maxlength

HTMLning o‘zida ham input uzunligini cheklash mumkin. 

<input
    type="text"
    minlength="3"
    maxlength="20"
>
minlength → minimal belgilar soni.

maxlength → maksimal belgilar soni.

⭐ required

Inputni majburiy qilish uchun required ishlatiladi. 

<input
    type="text"
    required
>
Agar foydalanuvchi inputni to‘ldirmasa, brauzer formani yuborishga ruxsat bermaydi.

📦 FormData

Formdagi ma'lumotlarni olishning yana bir usuli — FormData. 

let formData =
    new FormData(form);

Keyin ma'lumotni olish mumkin: 

let name =
    formData.get("name");
Buning uchun inputda name atributi bo‘lishi kerak. 
<input
    type="text"
    name="name"
>

💾 localStorage bilan saqlash

Formdan olingan ma'lumotni localStorage orqali brauzerda saqlash mumkin. 

localStorage.setItem(
    "name",
    name
);

Keyin qayta olish: 

let name =
    localStorage.getItem(
        "name"
    );
