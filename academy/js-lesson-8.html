Template Literals

Template Literals JavaScript'da matnlar bilan ishlashni ancha qulaylashtiradi. Bu darsda backtick, ${}, bir nechta qatorli matn va expression'larni o‘rganamiz.

Template Literal nima? 🤔

Template Literal — JavaScript'da String yozishning qulay usullaridan biri.

Oddiy String'da: 

let name = "Mirjamol";

console.log("Salom " + name);

Template Literal yordamida esa kod ancha tushunarli bo‘ladi: 

let name = "Mirjamol";

console.log(`Salom ${name}`);

Backtick ` ` belgisi

Template Literal oddiy " " yoki ' ' bilan emas, backtick belgisi bilan yoziladi. 

let text = `Salom, JavaScript!`;

console.log(text);

📌 Backtick belgisi: `

Ko‘pincha klaviaturada Esc tugmasi ostida joylashadi.

${} nima?

Template Literal ichida o‘zgaruvchini chiqarish uchun:

${o'zgaruvchi}

ko‘rinishidan foydalanamiz. 

let name = "Ali";
let age = 16;

console.log(`Ism: ${name}`);
console.log(`Yosh: ${age}`);
Ism: Ali
Yosh: 16

Bir nechta o‘zgaruvchi 🔥

Bitta Template Literal ichida bir nechta o‘zgaruvchidan foydalanish mumkin. 

let firstName = "Mirjamol";
let lastName = "Abdusalomov";
let age = 15;

console.log(
    `Mening ismim ${firstName} ${lastName}.
Men ${age} yoshdaman.`
);

String va Number bilan ishlash

Template Literal ichida String, Number va boshqa qiymatlarni birga ishlatish mumkin. 

let product = "Telefon";
let price = 2500000;
let quantity = 2;

console.log(
    `Mahsulot: ${product}
Narxi: ${price} so'm
Soni: ${quantity} ta`
);

Expression ishlatish 🧮

${} ichida faqat o‘zgaruvchi emas, matematik expression ham yozish mumkin. 

let a = 10;
let b = 5;

console.log(`Natija: ${a + b}`);

Natija: 

Natija: 15

Ko‘paytirish bilan 

let price = 20000;
let quantity = 3;

console.log(
    `Jami narx: ${price * quantity} so'm`
);
Jami narx: 60000 so'm

Funksiya natijasini chiqarish

Template Literal ichida funksiya chaqirish ham mumkin. 

function getName() {
    return "Mirjamol";
}

console.log(`Salom, ${getName()}!`);
Salom, Mirjamol!

Bir nechta qatorli String

Template Literal'ning katta afzalliklaridan biri — bir nechta qatorli matn yozish mumkin. 

let text = `
Salom!

Men JavaScript
o‘rganayapman.

Abdusalomov Academy
`;

console.log(text);

HTML bilan ishlash 🌐

Template Literal yordamida HTML kodlarini JavaScript ichida yaratish ham mumkin. 

let name = "Mirjamol";
let age = 15;

let card = `
    <div>
        <h2>${name}</h2>
        <p>Yosh: ${age}</p>
    </div>
`;

console.log(card);

Oddiy String va Template Literal

Oddiy String Template Literal
"Salom" `Salom`
"Salom " + name `Salom ${name}`
Ko‘p qator uchun noqulay Ko‘p qatorni oson yozish mumkin

Amaliy loyiha 💻

Foydalanuvchi haqida kichik ma'lumot tayyorlaymiz. 

let firstName = "Mirjamol";
let lastName = "Abdusalomov";
let age = 15;
let profession = "Front-End Developer";

let info = `
👤 Ism: ${firstName} ${lastName}
🎂 Yosh: ${age}
💻 Kasb: ${profession}
`;

console.log(info);

Amaliy mashq 🔥

Quyidagi ma'lumotlardan foydalanib Template Literal yarating: 

let name = "Ali";
let age = 17;
let city = "Toshkent";
let course = "JavaScript";

Console'da quyidagiga o‘xshash ma'lumot chiqaring: 

Ism: Ali
Yosh: 17
Shahar: Toshkent
Kurs: JavaScript

Uyga vazifa 📝

1️⃣ firstName, lastName, age va city o‘zgaruvchilarini yarating.

2️⃣ Template Literal yordamida barcha ma'lumotlarni bitta console.log() ichida chiqaring.

3️⃣ Ikki son yarating va ${} ichida ularning yig‘indisini hisoblang.

4️⃣ Mahsulot nomi, narxi va sonini yozib, jami narxni Template Literal orqali chiqaring.

5️⃣ Kamida 3 qatorli Template Literal yarating.
