String bilan ishlash

Bu darsda JavaScript'da matnlar bilan ishlashni, String yaratishni, birlashtirishni va String metodlaridan foydalanishni o‘rganamiz.

String nima? 🔤

String — JavaScript'da matnlarni saqlash uchun ishlatiladigan ma'lumot turi.

Masalan, ism, familiya, shahar, telefon raqami yoki oddiy gap String bo‘lishi mumkin. 

let firstName = "Mirjamol";

let lastName = "Abdusalomov";

let city = "Toshkent";

console.log(firstName);

String yaratish usullari

JavaScript'da String'ni uch xil yozishimiz mumkin:

1️⃣ Qo‘shtirnoq " "
2️⃣ Birtirnoq ' '
3️⃣ Backtick ` ` 

let name1 = "Ali";

let name2 = 'Vali';

let name3 = `Hasan`;

Stringlarni birlashtirish +

Ikki yoki undan ortiq String'ni + operatori yordamida birlashtirish mumkin. 

let firstName = "Mirjamol";
let lastName = "Abdusalomov";

let fullName = firstName + " " + lastName;

console.log(fullName);

Natija: 

Mirjamol Abdusalomov

String + Number 🔢

String bilan Number'ni + orqali birlashtirsak, JavaScript ularni matn sifatida birlashtiradi. 

let age = 15;

console.log("Mening yoshim: " + age);

Natija: 

Mening yoshim: 15

Template Literal 🔥

Template Literal backtick ` ` yordamida yoziladi.

O‘zgaruvchini matn ichiga joylashtirish uchun ${} ishlatiladi. 

let name = "Mirjamol";
let age = 15;

console.log(`Mening ismim ${name}.`);
console.log(`Men ${age} yoshdaman.`);

📌 Template Literal katta matnlarni yozishda va o‘zgaruvchilarni qo‘shishda juda qulay.

String uzunligi — length 📏

.length String ichidagi belgilar sonini aniqlaydi. 

let name = "JavaScript";

console.log(name.length);

Natija: 

10

Katta harflarga o‘tkazish

toUpperCase() String'dagi barcha harflarni katta harfga aylantiradi. 

let text = "javascript";

console.log(text.toUpperCase());
JAVASCRIPT

Kichik harflarga o‘tkazish

toLowerCase() barcha harflarni kichik harfga aylantiradi. 

let text = "JAVASCRIPT";

console.log(text.toLowerCase());
javascript

Belgini olish — charAt()

charAt() String ichidagi ma'lum indeksdagi belgini qaytaradi.

JavaScript'da indeks 0 dan boshlanadi. 

let word = "Salom";

console.log(word.charAt(0));

console.log(word.charAt(1));
S
a

includes() 🔎

includes() String ichida ma'lum matn bor yoki yo‘qligini tekshiradi.

Natija true yoki false bo‘ladi. 

let text = "Men JavaScript o‘rganayapman";

console.log(text.includes("JavaScript"));

console.log(text.includes("Python"));
true
false

startsWith()

startsWith() String ma'lum matn bilan boshlanishini tekshiradi. 

let text = "JavaScript";

console.log(text.startsWith("Java"));

console.log(text.startsWith("Python"));

endsWith()

endsWith() String ma'lum matn bilan tugashini tekshiradi. 

let file = "lesson.html";

console.log(file.endsWith(".html"));

console.log(file.endsWith(".css"));

trim() ✂️

trim() String boshidagi va oxiridagi ortiqcha bo‘sh joylarni olib tashlaydi. 

let username = "   Mirjamol   ";

console.log(username.trim());

Natijada boshidagi va oxiridagi bo‘sh joylar olib tashlanadi.

slice() ✂️

slice() String'ning ma'lum qismini ajratib olish uchun ishlatiladi. 

let text = "JavaScript";

console.log(text.slice(0, 4));
Java

replace() 🔄

replace() String ichidagi ma'lum bir qismni boshqa qiymatga almashtirish uchun ishlatiladi. 

let text = "Men HTML o‘rganayapman";

let result = text.replace(
    "HTML",
    "JavaScript"
);

console.log(result);
Men JavaScript o‘rganayapman

String metodlari jadvali 📚

Metod Vazifasi

toLowerCase() Kichik harflarga o‘tkazadi
charAt() Belgini oladi
includes() Matn mavjudligini tekshiradi
startsWith() Boshlanishini tekshiradi
endsWith() Tugashini tekshiradi
trim() Ortiqcha bo‘sh joyni olib tashlaydi
slice() String qismini ajratadi
replace() Matnni almashtiradi

Amaliy loyiha 💻

Foydalanuvchining ismi va familiyasini birlashtirib, ekranga chiqaramiz. 

let firstName = "Mirjamol";
let lastName = "Abdusalomov";
let age = 15;

let fullName = `${firstName} ${lastName}`;

console.log(`Ism: ${fullName}`);
console.log(`Yosh: ${age}`);
console.log(`Ism uzunligi: ${fullName.length}`);

Uyga vazifa 📝

1️⃣ firstName va lastName o‘zgaruvchilarini yarating.

2️⃣ Ularni birlashtirib, fullName yarating.

3️⃣ Ismni toUpperCase() bilan katta harfga o‘tkazing.

4️⃣ Familiyani toLowerCase() bilan kichik harfga o‘tkazing.

5️⃣ fullName.length orqali ism-familiya uzunligini toping.

6️⃣ includes() orqali fullName ichida ismingiz borligini tekshiring.

7️⃣ Natijalarni console.log() orqali chiqaring.
