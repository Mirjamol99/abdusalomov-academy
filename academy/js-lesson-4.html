O‘zgaruvchilar: let, const, var

Bugun JavaScript'dagi o‘zgaruvchilar nima ekanini va let, const, var o‘rtasidagi farqlarni o‘rganamiz.

O‘zgaruvchi nima? 🤔

O‘zgaruvchi — ma’lumotni vaqtincha saqlash uchun ishlatiladigan nomlangan joy.

Masalan, foydalanuvchining ismi, yoshi yoki ballini o‘zgaruvchida saqlashimiz mumkin. 

let name = "Mirjamol";

let age = 15;

let score = 95;

Bu yerda:

name → ismni saqlaydi
age → yoshni saqlaydi
score → ballni saqlaydi

let nima? 📦

let — o‘zgaruvchini yaratish uchun ishlatiladi.

let bilan yaratilgan o‘zgaruvchining qiymatini keyinchalik o‘zgartirish mumkin. 

let age = 15;

console.log(age);

age = 16;

console.log(age);

Natija:

15
16

let bilan qayta qiymat berish 🔄

let o‘zgaruvchisiga yangi qiymat berish mumkin. 

let city = "Toshkent";

city = "Samarqand";

console.log(city);

Natija: 

Samarqand

const nima? 🔒

const ham o‘zgaruvchi yaratish uchun ishlatiladi.

Lekin const bilan yaratilgan o‘zgaruvchiga keyinchalik boshqa qiymatni qayta berib bo‘lmaydi. 

const birthYear = 2010;

console.log(birthYear);

📌 const yaratishda unga boshlang‘ich qiymat berish kerak.

const qiymatini o‘zgartirish ❌

Quyidagi kod xatoga olib keladi: 

const country = "Uzbekistan";

country = "USA";

❌ const bilan yaratilgan qiymatni qayta tayinlab bo‘lmaydi.

var nima? 📦

var — JavaScript'dagi eski o‘zgaruvchi e’lon qilish usuli.

Zamonaviy JavaScript'da odatda let va const ishlatiladi. 

var name = "Mirjamol";

console.log(name);

var qiymatini o‘zgartirish

var qiymatini o‘zgartirish mumkin. 

var age = 15;

age = 16;

console.log(age);

Natija: 

16

let, const va var farqi ⚖️

Xususiyat let const var
Qiymatni o‘zgartirish Ha Yo‘q Ha
Zamonaviy JS Ha Ha Eski
Tavsiya ✅ ✅ ⚠️

Qachon let ishlatamiz?

Agar qiymat keyinchalik o‘zgaradigan bo‘lsa, let ishlatishimiz mumkin. 

let score = 0;

score = 10;

score = 20;

Masalan: 

let userAge = 15;

userAge = 16;

Qachon const ishlatamiz?

Agar o‘zgaruvchiga berilgan qiymatni qayta tayinlamasak, const ishlatish yaxshi tanlov. 

const country = "Uzbekistan";

const pi = 3.14;

O‘zgaruvchi nomlash qoidalari 📚

O‘zgaruvchi nomi harf, _ yoki $ bilan boshlanishi mumkin. 

let name = "Ali";

let userName = "Ali";

let _score = 100;

let $price = 5000;

Son bilan boshlash mumkin emas: 

// Noto‘g‘ri

let 1name = "Ali";

camelCase usuli 🐪

JavaScript'da bir nechta so‘zdan iborat o‘zgaruvchi nomlarida ko‘pincha camelCase ishlatiladi. 

let firstName = "Ali";

let lastName = "Valiyev";

let userAge = 15;

let phoneNumber = "998901234567";

Amaliy misol 💻 

let firstName = "Mirjamol";

let age = 15;

let score = 95;

const country = "Uzbekistan";


console.log(firstName);

console.log(age);

console.log(score);

console.log(country);

Uyga vazifa 📝

Quyidagi o‘zgaruvchilarni yarating:

1️⃣ firstName — ismingiz.

2️⃣ lastName — familiyangiz.

3️⃣ age — yoshingiz.

4️⃣ city — yashaydigan shahringiz.

5️⃣ country — mamlakatingiz.

6️⃣ score — biror ball.

Keyin ularning hammasini console.log() yordamida chiqaring.

Bugungi darsni eslab qoling 🎯

📦 let → qiymati o‘zgarishi mumkin.

🔒 const → qayta qiymat berilmaydi.

📦 var → eski usul, zamonaviy JS'da kamroq ishlatiladi.

🐪 Bir nechta so‘zdan iborat nomlarda camelCase ishlatish odatiy.
