find() va findIndex()

Bugungi darsda Array ichidan kerakli elementni topishni o‘rganamiz.

find() — birinchi mos keladigan elementni topadi.

findIndex() — birinchi mos keladigan elementning indexini topadi.

🎯 find() nima?

find() Array ichidagi elementlarni birma-bir tekshiradi.

Shartga mos kelgan birinchi elementni qaytaradi. 

let numbers = [5, 12, 18, 25, 30];

let result = numbers.find(function(number) {

    return number > 15;

});

console.log(result);
18

🔎 find() qanday ishlaydi?

[5, 12, 18, 25, 30]

↓

number > 15

↓

18

🧠 find() faqat birinchi elementni oladi 

let numbers = [10, 20, 30, 40];

let result = numbers.find(
    number => number > 15
);

console.log(result);
Natija: 20

Chunki 20, 30 va 40 ham shartga mos, lekin find() faqat birinchi mos elementni qaytaradi.

⚖️ find() va filter() farqi

filter() 

let numbers = [10, 20, 30, 40];

let result = numbers.filter(
    number => number > 15
);

console.log(result);

[20, 30, 40]

find() 

let result = numbers.find(
    number => number > 15
);

console.log(result);

20

⚡ Arrow Function bilan find() 

let numbers = [10, 20, 30, 40];

let result = numbers.find(
    number => number > 25
);

console.log(result);
30

❓ find() topmasa nima bo‘ladi?

Agar hech qanday element shartga mos kelmasa, find() undefined qaytaradi. 

let numbers = [1, 2, 3, 4];

let result = numbers.find(
    number => number > 100
);

console.log(result);
undefined

📍 findIndex() nima?

findIndex() birinchi mos keladigan elementning indexini qaytaradi. 

let numbers = [
    10,
    20,
    30,
    40
];

let index = numbers.findIndex(
    number => number > 15
);

console.log(index);
1

📊 Index qanday ishlaydi?

Index

0    1    2    3

↓    ↓    ↓    ↓

10   20   30   40

20 → index 1

🆚 find() va findIndex() 

let numbers = [10, 20, 30, 40];

let value = numbers.find(
    number => number > 15
);

let index = numbers.findIndex(
    number => number > 15
);

console.log(value);
console.log(index);
20
1
find() → elementni qaytaradi.

findIndex() → elementning indexini qaytaradi.

❌ findIndex() topmasa

Hech qanday element shartga mos kelmasa, -1 qaytariladi. 

let numbers = [10, 20, 30];

let index = numbers.findIndex(
    number => number === 100
);

console.log(index);
-1

✏️ findIndex() bilan ma'lumotni o‘zgartirish 

let products = [

    {
        id: 1,
        name: "Telefon",
        price: 3000000
    },

    {
        id: 2,
        name: "Noutbuk",
        price: 7000000
    }

];

let index = products.findIndex(
    product => product.id === 2
);

products[index].price = 6500000;

console.log(products);
Avval mahsulotning indexini topdik, keyin shu index orqali uning narxini o‘zgartirdik.

🛒 Cart bilan find()

Savatcha bilan ishlaganda ham find() juda ko‘p ishlatiladi. 

let cart = [

    {
        id: 1,
        name: "Pizza",
        quantity: 2
    },

    {
        id: 2,
        name: "Burger",
        quantity: 1
    }

];

let product = cart.find(
    item => item.id === 2
);

console.log(product);

➕ Topilgan mahsulotni o‘zgartirish 

let product = cart.find(
    item => item.id === 2
);

product.quantity++;

console.log(cart);
quantity: 2
