HTML'da ro'yxatlar

Bugun HTML'da tartibli va tartibsiz ro'yxatlar yaratishni o'rganamiz.

1. <ul> — Tartibsiz ro'yxat

<ul> tegi tartibsiz ro'yxat yaratish uchun ishlatiladi.

Bunday ro'yxatda elementlar odatda nuqta bilan ko'rsatiladi.

Kod: 

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Natija:

  • HTML
  • CSS
  • JavaScript

2. <li> — Ro'yxat elementi

<li> tegi ro'yxat ichidagi har bir elementni bildiradi. 

<ul>

    <li>Birinchi element</li>

    <li>Ikkinchi element</li>

    <li>Uchinchi element</li>

</ul>

3. <ol> — Tartibli ro'yxat

<ol> tegi raqamlangan ro'yxat yaratish uchun ishlatiladi.

Elementlar avtomatik ravishda 1, 2, 3... ko'rinishida chiqadi.

Kod: 

<ol>
    <li>HTML o'rganish</li>
    <li>CSS o'rganish</li>
    <li>JavaScript o'rganish</li>
</ol>

Natija:

  1. HTML o'rganish
  2. CSS o'rganish
  3. JavaScript o'rganish

<ol>
