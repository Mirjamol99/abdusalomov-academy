Scope

Scope — JavaScript'da o‘zgaruvchi va functionlarning qayerda mavjud bo‘lishini belgilaydigan muhim tushuncha.

Oddiy qilib aytganda:

🎯 Scope — "Bu o‘zgaruvchidan qayerda foydalanishim mumkin?" degan savolga javob beradi.

Scope nima? 🤔

Har bir o‘zgaruvchining o‘ziga tegishli "hududi" bo‘ladi.

Shu hudud ichida o‘zgaruvchidan foydalanish mumkin.

Hudud tashqarisida esa undan foydalanib bo‘lmaydi. 

let ism = "Ali";

console.log(ism);

Bu yerda ism global scope'da yaratilgan.

Global Scope 🌍

Function yoki boshqa block ichidan tashqarida yaratilgan o‘zgaruvchi global scope'da bo‘lishi mumkin. 

let ism = "Ali";

function salom() {

    console.log(ism);

}

salom();
Ali

Function ichida global o‘zgaruvchiga murojaat qilish mumkin.

Function Scope ⚙️

Function ichida yaratilgan o‘zgaruvchi faqat shu function ichida mavjud bo‘ladi. 

function test() {

    let ism = "Ali";

    console.log(ism);

}

test();

Lekin: 

function test() {

    let ism = "Ali";

}

console.log(ism);
❌ Bu holatda ism tashqaridan ko‘rinmaydi.

Block Scope 📦

{ } ichidagi block ham o‘z scope'iga ega bo‘lishi mumkin. 

{
    let ism = "Ali";

    console.log(ism);
}

Bu yerda ism block ichida ishlaydi. 

{
    let ism = "Ali";
}

console.log(ism);
❌ let bilan yaratilgan ism block tashqarisida mavjud emas.

let va Block Scope 🔒 

if (true) {

    let yosh = 16;

    console.log(yosh);

}

yosh faqat if block ichida mavjud.

const va Scope 🔒 

if (true) {

    const ism = "Ali";

    console.log(ism);

}

const ham let kabi block scope'ga ega.

var va Scope ⚠️

var esa let va const kabi block scope'ga ega emas. 

if (true) {

    var ism = "Ali";

}

console.log(ism);
Ali
⚠️ Shu sababli zamonaviy JavaScript'da ko‘pincha let va const ishlatiladi.

Scope va if 🔀 

let yosh = 20;

if (yosh >= 18) {

    let xabar = "Kirish mumkin";

    console.log(xabar);

}

console.log(yosh);

Global yosh if ichida ishlatilishi mumkin.

Ammo xabar if tashqarisida ishlamaydi.

Scope va for loop 🔁 

for (let i = 0; i < 3; i++) {

    console.log(i);

}

i faqat for loop scope'ida mavjud. 

for (let i = 0; i < 3; i++) {

    console.log(i);

}

console.log(i);
❌ Bu yerda i tashqarida mavjud emas.

Nested Scope 🪆

Bir scope ichida boshqa scope bo‘lishi mumkin. 

let tashqi = "Tashqi";

if (true) {

    let ichki = "Ichki";

    console.log(tashqi);
    console.log(ichki);

}

Ichki scope tashqi scope'dagi o‘zgaruvchini ko‘ra oladi.

Ichki Scope tashqi Scope'ni ko‘radi 👀 

let ism = "Ali";

function test() {

    let yosh = 16;

    console.log(ism);
    console.log(yosh);

}

test();

Function ichidagi scope global scope'dagi ismni ko‘ra oladi.

Lekin global scope function ichidagi yoshni ko‘ra olmaydi.

Scope Chain ⛓️

JavaScript kerakli o‘zgaruvchini topish uchun avval joriy scope'ni, keyin tashqi scope'larni tekshiradi. 

let a = 10;

function tashqi() {

    let b = 20;

    function ichki() {

        let c = 30;

        console.log(a);
        console.log(b);
        console.log(c);

    }

    ichki();

}

tashqi();
10
20
30

Bir xil nomdagi o‘zgaruvchilar ⚠️

Ichki scope'da tashqi scope bilan bir xil nomdagi o‘zgaruvchi yaratilishi mumkin. 

let ism = "Ali";

function test() {

    let ism = "Vali";

    console.log(ism);

}

test();

console.log(ism);
Vali
Ali

Ichki scope o‘zidagi ismni ishlatadi.

Shadowing 🌑

Ichki scope'dagi o‘zgaruvchi tashqi scope'dagi xuddi shu nomli o‘zgaruvchini vaqtincha "yashirishi" shadowing deyiladi. 

let son = 10;

if (true) {

    let son = 20;

    console.log(son);

}

console.log(son);
20
10

Global va Local Scope 🌍

🌍 Global Scope
Dastur bo‘ylab ko‘rinadigan scope.

📦 Local Scope
Function yoki block ichida mavjud bo‘ladigan scope. 

let global = "Global";

function test() {

    let local = "Local";

    console.log(global);
    console.log(local);

}

test();

Lexical Scope 📚

JavaScript'da function qayerda yozilgan bo‘lsa, uning scope'i shu joydagi tashqi scope'lar bilan bog‘liq bo‘ladi. 

let ism = "Ali";

function tashqi() {

    function ichki() {

        console.log(ism);

    }

    ichki();

}

tashqi();

ichki() o‘zining tashqi scope'laridan ismni topa oladi.

Scope va Function Parameter 📥

Function parametrlari ham function scope'ida mavjud bo‘ladi. 

function salom(ism) {

    console.log(ism);

}

salom("Ali");

ism faqat function ichida ishlatiladi.

Scope va Arrow Function ➡️ 

let ism = "Ali";

const salom = () => {

    console.log(ism);

};

salom();
Ali

Arrow Function ham tashqi scope'dagi o‘zgaruvchidan foydalanishi mumkin.

Scope'ni tushunish nima uchun kerak? 🎯

🔹 O‘zgaruvchilarni tartibli boshqarish uchun.

🔹 Bir xil nomdagi o‘zgaruvchilar bilan ishlashda xatolarning oldini olish uchun.

🔹 Function ichidagi ma'lumotlarni tashqaridan himoyalash uchun.

🔹 Katta JavaScript loyihalarini tushunish uchun.

🔹 Keyingi Closure mavzusini tushunish uchun.

Scope bo‘yicha asosiy qoida 📌

🌍 Tashqi scope'dagi qiymatni ichki scope ko‘rishi mumkin.

🔒 Ichki scope'dagi qiymatni tashqi scope to‘g‘ridan-to‘g‘ri ko‘ra olmaydi. 

let tashqi = 100;

function test() {

    let ichki = 200;

    console.log(tashqi);
    console.log(ichki);

}

test();

console.log(tashqi);

// console.log(ichki); ❌

Uyga vazifa 📝

1-vazifa:
Global scope'da ism o‘zgaruvchisini yarating va function ichida chiqaring.

2-vazifa:
Function ichida yosh o‘zgaruvchisini yarating. Uni function tashqarisida chiqarishga urinib ko‘ring.

3-vazifa:
if ichida let bilan o‘zgaruvchi yarating va uning scope'ini tekshiring.

4-vazifa:
var va let scope'larini taqqoslab ko‘ring.

5-vazifa:
Bir xil nomdagi global va local o‘zgaruvchi yarating. Natijani kuzating.

6-vazifa:
Nested function yarating va ichki function tashqi functiondagi o‘zgaruvchini ishlata olishini tekshiring.

7-vazifa:
for loop ichida let i yarating. Loop tashqarisida i bilan ishlashga urinib ko‘ring.

8-vazifa:
Global ball va function ichidagi ball o‘zgaruvchilarini yaratib, shadowingni kuzating.

Bugungi dars xulosasi 🎯

🎯 Scope — o‘zgaruvchining qayerda mavjudligini belgilaydi.

🌍 Global Scope — tashqi scope.

⚙️ Function Scope — function ichidagi scope.

📦 Block Scope — { } ichidagi scope.

🔒 let va const block scope'ga ega.

⚠️ var block scope'ga ega emas.

⛓️ Scope Chain — JavaScript tashqi scope'lardan qiymat izlash mexanizmi.

🌑 Shadowing — ichki scope'dagi bir xil nomli o‘zgaruvchining tashqi o‘zgaruvchini yashirishi.
