Boolean

Boolean — JavaScript'dagi eng muhim ma'lumot turlaridan biri. U biror narsa rost yoki yolg‘on ekanligini ifodalash uchun ishlatiladi.

Boolean nima? 🤔

Boolean faqat ikkita qiymatga ega:

🟢 true — rost
🔴 false — yolg‘on 

let isStudent = true;

let isAdmin = false;

console.log(isStudent);
console.log(isAdmin);
true
false

Boolean o‘zgaruvchisi

Boolean qiymatlarni odatda is, has yoki can bilan boshlanadigan o‘zgaruvchilarda ko‘p uchratamiz. 

let isLogin = true;

let isOnline = false;

let hasMoney = true;

let canDrive = false;

Bunday nomlar o‘zgaruvchining Boolean ekanligini tushunishni osonlashtiradi.

true va false qanday ishlaydi?

Masalan, foydalanuvchi tizimga kirgan bo‘lsa: 

let isLogin = true;

console.log(isLogin);

Agar foydalanuvchi tizimga kirmagan bo‘lsa: 

let isLogin = false;

console.log(isLogin);

Boolean va taqqoslash 🔎

Taqqoslash natijasi ham Boolean bo‘ladi. 

console.log(10 > 5);

console.log(10 < 5);

console.log(10 === 10);

console.log(10 === 20);
true
false
true
false

Demak, taqqoslash natijasida JavaScript bizga true yoki false qaytaradi.

> Katta

> operatori chap tarafdagi qiymat o‘ng tarafdagidan katta ekanligini tekshiradi. 

console.log(15 > 10);

console.log(5 > 10);
true
false

< Kichik

< operatori chap tarafdagi qiymat o‘ng tarafdagidan kichik ekanligini tekshiradi. 

console.log(5 < 10);

console.log(15 < 10);

>= Katta yoki teng 

console.log(10 >= 10);

console.log(15 >= 10);

console.log(5 >= 10);
true
true
false

<= Kichik yoki teng 

console.log(10 <= 10);

console.log(5 <= 10);

console.log(15 <= 10);
true
true
false

=== Tenglik

=== ikki qiymat tengligini tekshiradi. 

console.log(10 === 10);

console.log(10 === 20);
true
false

!== Teng emas

!== ikki qiymat teng emasligini tekshiradi. 

console.log(10 !== 20);

console.log(10 !== 10);
true
false

Boolean bilan if ishlatish 🚦

Boolean qiymatlar if shartlarida juda ko‘p ishlatiladi. 

let isLogin = true;

if (isLogin) {
    console.log("Xush kelibsiz!");
}

isLogin qiymati true bo‘lgani uchun xabar chiqadi.

if va false 

let isLogin = false;

if (isLogin) {
    console.log("Xush kelibsiz!");
}

Bu safar shart false bo‘lgani uchun if ichidagi kod bajarilmaydi.

if / else bilan Boolean 

let isLogin = false;

if (isLogin) {
    console.log("Xush kelibsiz!");
} else {
    console.log("Iltimos, tizimga kiring.");
}
Iltimos, tizimga kiring.

Amaliy misol 👨‍🎓

Foydalanuvchi talaba ekanligini Boolean orqali saqlashimiz mumkin. 

let isStudent = true;

if (isStudent) {
    console.log("Siz talabasisiz.");
} else {
    console.log("Siz talaba emassiz.");
}

Amaliy misol 💰 

let balance = 50000;

let hasMoney = balance > 0;

console.log(hasMoney);
true

Chunki 50000 > 0 natijasi true.

Boolean operatorlari 📚

Operator Vazifasi Misol
> Katta 10 > 5
< Kichik 5 < 10
>= Katta yoki teng 10 >= 10
<= Kichik yoki teng 5 <= 10
=== Teng 10 === 10
!== Teng emas 10 !== 5

Amaliy mashq 🔥

Quyidagi kodlarni yozing va Console'dagi natijani topishga harakat qiling. 

console.log(20 > 10);

console.log(7 === 7);

console.log(15 < 5);

console.log(10 !== 20);

console.log(5 >= 5);

Uyga vazifa 📝

1️⃣ isLogin nomli Boolean o‘zgaruvchi yarating.

2️⃣ isStudent nomli Boolean o‘zgaruvchi yarating.

3️⃣ hasMoney nomli Boolean o‘zgaruvchi yarating.

4️⃣ Quyidagi taqqoslashlarning natijasini Console'ga chiqaring: 

25 > 10
15 < 5
20 === 20
10 !== 5
50 >= 50
7 <= 3

5️⃣ if / else yordamida isLogin qiymatini tekshiring.

Agar true bo‘lsa: 

"Xush kelibsiz!"

Agar false bo‘lsa: 

"Iltimos, tizimga kiring."

Bugungi darsni eslab qoling 🎯

✅ true — rost.

❌ false — yolg‘on.

🔎 Taqqoslash operatorlari Boolean natija qaytaradi.

🚦 Boolean qiymatlar if / else bilan juda ko‘p ishlatiladi.

💻 Keyingi darslarda Boolean operatorlari yordamida murakkabroq shartlar tuzamiz.
