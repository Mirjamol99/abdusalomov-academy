Array asoslari

Array — bir nechta qiymatlarni bitta o‘zgaruvchi ichida saqlashga yordam beradigan ma'lumotlar strukturasi.

Masalan, 5 ta meva uchun 5 ta alohida o‘zgaruvchi yaratish o‘rniga bitta Array ishlatishimiz mumkin.

Array nima? 🤔

Array ichida bir nechta qiymatlarni tartib bilan saqlash mumkin. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

console.log(mevalar);

Bu yerda mevalar nomli Array yaratildi.

Unda 4 ta element bor.

Array yaratish 📦

Array odatda kvadrat qavslar [ ] yordamida yaratiladi. 

let sonlar = [10, 20, 30, 40, 50];

let ismlar = [
    "Ali",
    "Vali",
    "Hasan"
];

let aralash = [
    "Ali",
    16,
    true
];
Array ichida bir xil turdagi yoki turli turdagi qiymatlar bo‘lishi mumkin.

Array Index 🔢

Array'dagi har bir elementning o‘z index raqami bor.

Muhim:
JavaScript'da index 0 dan boshlanadi. 

let mevalar = [
    "Olma",    // index 0
    "Banan",   // index 1
    "Uzum",    // index 2
    "Anor"     // index 3
];

0 → Olma

1 → Banan

2 → Uzum

3 → Anor

Elementga murojaat qilish 🔍 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(mevalar[0]);

console.log(mevalar[1]);

console.log(mevalar[2]);
Olma
Banan
Uzum

Masalan:

mevalar[0] → birinchi element.

Oxirgi elementni olish 🎯

Array'ning oxirgi elementini length - 1 orqali olish mumkin. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

console.log(
    mevalar[mevalar.length - 1]
);
Anor

length 📏

length Array ichida nechta element borligini ko‘rsatadi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

console.log(mevalar.length);
4

Array elementini o‘zgartirish ✏️ 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

mevalar[1] = "Anor";

console.log(mevalar);
[
    "Olma",
    "Anor",
    "Uzum"
]

mevalar[1] oldin Banan edi, endi Anor bo‘ldi.

Array'ga yangi element qo‘shish ➕

Array oxiriga element qo‘shish uchun push() metodidan foydalanamiz. 

let mevalar = [
    "Olma",
    "Banan"
];

mevalar.push("Uzum");

console.log(mevalar);
[
    "Olma",
    "Banan",
    "Uzum"
]

Array oxiridan o‘chirish ➖

Oxirgi elementni o‘chirish uchun pop() ishlatiladi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

mevalar.pop();

console.log(mevalar);
[
    "Olma",
    "Banan"
]

Array boshiga qo‘shish ⬅️

Array boshiga element qo‘shish uchun unshift() ishlatiladi. 

let mevalar = [
    "Banan",
    "Uzum"
];

mevalar.unshift("Olma");

console.log(mevalar);
[
    "Olma",
    "Banan",
    "Uzum"
]

Array boshidan o‘chirish ⬆️

Birinchi elementni o‘chirish uchun shift() ishlatiladi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

mevalar.shift();

console.log(mevalar);
[
    "Banan",
    "Uzum"
]

Empty Array 📭

Bo‘sh Array ham yaratish mumkin. 

let mevalar = [];

console.log(mevalar);

Keyin unga elementlar qo‘shish mumkin: 

let mevalar = [];

mevalar.push("Olma");
mevalar.push("Banan");
mevalar.push("Uzum");

console.log(mevalar);

Array va for loop 🔁

Array elementlarini loop yordamida birma-bir chiqarish mumkin. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

for (let i = 0; i < mevalar.length; i++) {

    console.log(mevalar[i]);

}
Olma
Banan
Uzum

Array va for...of 🔄

Array elementlarini olishning qulay usullaridan biri — for...of. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

for (let meva of mevalar) {

    console.log(meva);

}

Array ichida Array 🪆

Array ichida boshqa Array ham bo‘lishi mumkin. 

let sonlar = [
    [1, 2, 3],
    [4, 5, 6]
];

console.log(sonlar[0]);
console.log(sonlar[0][1]);
[1, 2, 3]
2

Array'dagi indexni aniqlash 🔎

Keyingi darslarda Array metodlarini batafsil o‘rganamiz.

Masalan, indexOf() elementning indexini topishga yordam beradi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(
    mevalar.indexOf("Banan")
);
1

Array ichida qiymat borligini tekshirish ✅

includes() Array ichida qiymat bor-yo‘qligini tekshiradi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(
    mevalar.includes("Olma")
);

console.log(
    mevalar.includes("Anor")
);
true
false

Array'dan qiymat olish 📥 

const students = [
    "Ali",
    "Vali",
    "Hasan",
    "Husan"
];

let firstStudent = students[0];

console.log(firstStudent);
Ali

const bilan Array ⚠️

const bilan yaratilgan Array'ning elementlarini o‘zgartirish mumkin. 

const mevalar = [
    "Olma",
    "Banan"
];

mevalar[0] = "Uzum";

mevalar.push("Anor");

console.log(mevalar);
[
    "Uzum",
    "Banan",
    "Anor"
]

❗ Lekin const bilan yaratilgan o‘zgaruvchiga butunlay yangi Array biriktirish mumkin emas.

Array'ni boshqa Array'ga nusxalash 📋 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

let yangiMevalar = [
    ...mevalar
];

console.log(yangiMevalar);

... — spread operator. Uni keyingi darslarda batafsil o‘rganamiz.

Array bilan amaliy misol 🎓 

const students = [
    "Ali",
    "Vali",
    "Hasan",
    "Husan"
];

console.log("O‘quvchilar soni:",
    students.length
);

console.log("Birinchi o‘quvchi:",
    students[0]
);

console.log("Oxirgi o‘quvchi:",
    students[students.length - 1]
);

let games = [

Eng muhim Array metodlari 📌

➕ push() — oxiriga qo‘shadi.

➖ pop() — oxiridan o‘chiradi.

⬅️ unshift() — boshiga qo‘shadi.

⬆️ shift() — boshidan o‘chiradi.

🔎 indexOf() — indexni topadi.

✅ includes() — qiymat borligini tekshiradi.

📏 length — elementlar sonini beradi.
