querySelectorAll

Bugun JavaScript yordamida bir xil selectorga ega bo‘lgan barcha HTML elementlarni topishni o‘rganamiz.

querySelectorAll() — DOM'dagi bir nechta element bilan ishlash uchun juda muhim metod.

🔎 querySelectorAll nima?

querySelectorAll() CSS selector bo‘yicha mos keladigan barcha elementlarni topadi. 

document.querySelectorAll(".text");
Agar sahifada 5 ta .text class mavjud bo‘lsa, querySelectorAll() shu 5 ta elementning barchasini oladi.

🆚 querySelector va querySelectorAll

querySelector()

Birinchi mos keladigan elementni oladi. 

document.querySelector(
    ".item"
);

querySelectorAll()

Barcha mos keladigan elementlarni oladi. 

document.querySelectorAll(
    ".item"
);

📦 Bir nechta element 

<p class="text">Birinchi</p>

<p class="text">Ikkinchi</p>

<p class="text">Uchinchi</p>

Endi JavaScript: 

let texts =
    document.querySelectorAll(".text");

console.log(texts);
Natijada uchta .text elementning barchasi olinadi.

🔢 length bilan elementlar sonini bilish

querySelectorAll() natijasida nechta element topilganini length orqali bilish mumkin. 

let items =
    document.querySelectorAll(".item");

console.log(items.length);
Masalan, 5 ta element bo‘lsa:

items.length → 5

🔢 Index orqali element olish

Elementlar index orqali ham olinadi.

Index 0 dan boshlanadi. 

let items =
    document.querySelectorAll(".item");

console.log(items[0]);

console.log(items[1]);

console.log(items[2]);
items[0] → birinchi element
items[1] → ikkinchi element
items[2] → uchinchi element

🔁 for loop bilan ishlash

Barcha elementlarni o‘zgartirish uchun loop ishlatish mumkin. 

let items =
    document.querySelectorAll(".item");

for (let i = 0; i < items.length; i++) {

    items[i].style.color = "orange";

}
Loop barcha elementlarni bittadan ko‘rib chiqadi.

🔁 forEach bilan ishlash

querySelectorAll() natijasi bilan forEach() ham ishlatish mumkin. 

let items =
    document.querySelectorAll(".item");

items.forEach(function(item) {

    item.style.color = "orange";

});
Bu usul bir nechta element bilan ishlashda juda qulay.

🎯 Faqat kerakli elementlarni tanlash

CSS selectorlardan foydalangan holda aniq elementlarni tanlash mumkin. 

document.querySelectorAll(
    ".card"
);

    "p"

    "#products .card"
);

❌ Element topilmasa

Agar selector bo‘yicha hech qanday element topilmasa, bo‘sh NodeList qaytadi. 

let items =
    document.querySelectorAll(
        ".notFound"
    );

console.log(items);
querySelector() → null

querySelectorAll() → bo‘sh NodeList

🧠 NodeList nima?

querySelectorAll() natijasi odatda NodeList bo‘ladi. 

let items =
    document.querySelectorAll(".item");

console.log(items);
NodeList ichida topilgan elementlar saqlanadi.

U bilan:

length
index
forEach()

kabi usullar orqali ishlash mumkin.
