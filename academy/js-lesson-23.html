break va continue

Bugun JavaScript'dagi break va continue operatorlarini o‘rganamiz.

Ikkalasi ham looplarning ishlashini boshqarishda juda muhim.

break loopni to‘liq to‘xtatadi.

continue esa faqat joriy aylanishni tashlab, keyingi aylanishga o‘tadi.

break nima? 🛑

break loopni darhol to‘xtatish uchun ishlatiladi.

Loop ichida break ishlatilganda, loopdan chiqib ketiladi va undan keyingi kod bajariladi. 

for (let i = 1; i <= 10; i++) {

    if (i === 5) {
        break;
    }

    console.log(i);

}

Masalan, Array ichidan kerakli sonni topganimizdan keyin qidirishni to‘xtatishimiz mumkin.

        console.log("Topildi!");

Ichma-ich looplarda break 🔥

Agar loop ichida yana boshqa loop bo‘lsa, break eng yaqin joylashgan loopni to‘xtatadi.

break va return farqi ⚠️

break loopni to‘xtatadi.

return esa funksiyadan chiqadi va kerak bo‘lsa qiymat qaytaradi. 

function test() {

    for (let i = 1; i <= 5; i++) {

        if (i === 3) {
            return;
        }

        console.log(i);

    }

}

test();

Qachon break ishlatamiz? 🎯

🛑 Kerakli element topilganda qidirishni to‘xtatish.

🛑 Ma'lum bir shartga yetilganda loopdan chiqish.

🛑 Jarayonni majburan to‘xtatish.

🛑 Keraksiz aylanishlarning oldini olish.

Qachon continue ishlatamiz? 🎯

⏭️ Ayrim qiymatlarni tashlab ketish kerak bo‘lganda.

⏭️ Faqat kerakli qiymatlarni qayta ishlash kerak bo‘lganda.

⏭️ Ma'lum shartga mos kelmaydigan elementlarni o'tkazib yuborishda.

Bugungi darsni eslab qoling 🎯

🛑 break — loopni butunlay to‘xtatadi.

⏭️ continue — faqat joriy aylanishni tashlab ketadi.

🔄 break dan keyin loopning keyingi aylanishlari bajarilmaydi.

🔄 continue dan keyin loop keyingi aylanishga o‘tadi.

📦 Ikkalasidan ham for, while va do while bilan foydalanish mumkin.

⚠️ while yoki do while ichida continue ishlatilganda loop o‘zgaruvchisini yangilashga e'tibor bering.
