CSS Text & Fonts ✍️

CSS yordamida matnning joylashuvi, o'lchami, qalinligi, shrift turi va ko'rinishini boshqarishni o'rganamiz.

1. `text-align`

`text-align` matnning gorizontal joylashuvini belgilaydi. 

text-align: left;

text-align: center;

text-align: right;

Chap tomonda

Markazda

O'ng tomonda

💡 Eng ko'p ishlatiladigan qiymatlar:

`left` → chap
`center` → markaz
`right` → o'ng

2. `text-decoration`

Matnning tagiga, ustiga yoki ustidan chiziq qo'yish uchun ishlatiladi. 

text-decoration: underline;

text-decoration: line-through;

text-decoration: overline;

text-decoration: none;

Underline

Line Through

Overline

None

3. `text-transform`

Matn harflarining ko'rinishini ozgartirish uchun ishlatiladi. 

text-transform: uppercase;

text-transform: lowercase;

text-transform: capitalize;

abdusalomov academy

ABDUSALOMOV ACADEMY

abdusalomov academy

📌 `uppercase` → HAMMASI KATTA
📌 `lowercase` → hammasi kichik
📌 `capitalize` → Har Bir So'z Bosh Harfi Katta

4. `font-size`

Matnning o'lchamini belgilaydi. 

h1 {
    font-size: 40px;
}

p {
    font-size: 20px;
}

16px matn

24px matn

36px matn

5. `font-weight`

Matnning qalinligini belgilaydi. 

font-weight: 400;

font-weight: 500;

font-weight: 700;

font-weight: 900;

Font Weight 400

Font Weight 500

Font Weight 700

Font Weight 900

💡 `700` odatda bold ko'rinishga yaqin bo'ladi.

6. `font-family`

Matn qaysi shrift yordamida ko'rsatilishini belgilaydi. 

body {
    font-family: Arial, sans-serif;
}

Arial Font

Georgia Font

Monospace Font

📌 Ko'p ishlatiladigan shriftlar:

Arial
Georgia
Verdana
Tahoma
sans-serif

7. `font-style`

Matnni oddiy yoki qiya ko'rinishga keltiradi. 

font-style: normal;

font-style: italic;

Oddiy matn

Qiya matn

8. `line-height`

Qatorlar orasidagi masofani boshqaradi. 

p {
    line-height: 1.8;
}
CSS — web sahifalarni chiroyli ko'rsatish uchun ishlatiladi. CSS yordamida matn, rang, o'lcham va joylashuvni boshqarish mumkin.
