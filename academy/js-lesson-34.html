slice va splice

33-darsda shift() va unshift() orqali Array boshidan elementlar bilan ishlashni o‘rgandik.

Bugun esa Array ichidagi kerakli qismlarni olish va elementlarni o‘zgartirishni o‘rganamiz.

✂️ slice() nima?

slice() — Array'dan ma'lum bir qismini ajratib olib, yangi Array qaytaradi.

Eng muhim jihati:

slice() original Array'ni o‘zgartirmaydi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

let result = fruits.slice(1, 3);

console.log(result);

console.log(fruits);
[
    "Banan",
    "Uzum"
]

[
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
]

🔢 slice(start, end)

slice() ikkita asosiy parametr qabul qiladi:

start → qayerdan boshlash
end → qayergacha olish

⚠️ end indexdagi element olinmaydi. 

let numbers = [
    10,
    20,
    30,
    40,
    50
];

let result = numbers.slice(1, 4);

console.log(result);
[
    20,
    30,
    40
]

🧠 Index bilan tushunamiz

0 → "Olma"

1 → "Banan"

2 → "Uzum"

3 → "Anor" 

fruits.slice(1, 3);

1-indexdan boshlaydi:
Banan ✅
2-indexni oladi:
Uzum ✅

3-indexdagi Anor olinmaydi.

📌 slice() faqat start bilan

Agar faqat bitta qiymat berilsa, o‘sha indexdan Array oxirigacha elementlarni oladi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

let result = fruits.slice(2);

console.log(result);
[
    "Uzum",
    "Anor"
]

🔄 slice() va manfiy index

slice()da manfiy index ham ishlatish mumkin.

-1 → oxirgi element
-2 → oxiridan ikkinchi element 

let fruits = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

let result = fruits.slice(-2);

console.log(result);
[
    "Uzum",
    "Anor"
]

🔧 splice() nima?

splice() Array ichidagi elementlarni:

❌ o‘chirishi
➕ qo‘shishi
🔄 almashtirishi mumkin.

Eng muhim jihati:

splice() original Array'ni o‘zgartiradi.

❌ splice() bilan o‘chirish

Sintaksis: 

array.splice(start, deleteCount);
let fruits = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

fruits.splice(1, 1);

console.log(fruits);
[
    "Olma",
    "Uzum",
    "Anor"
]

🔢 deleteCount nima?

deleteCount nechta element o‘chirilishini bildiradi. 

let numbers = [
    10,
    20,
    30,
    40,
    50
];

numbers.splice(1, 2);

console.log(numbers);
[
    10,
    40,
    50
]

1-indexdan boshlab 2 ta element:
20 ❌
30 ❌

➕ splice() bilan qo‘shish

Agar deleteCount 0 bo‘lsa, element o‘chirilmaydi. Yangi elementlar esa shu indexga qo‘shiladi. 

let fruits = [
    "Olma",
    "Uzum"
];

fruits.splice(
    1,
    0,
    "Banan"
);

console.log(fruits);
[
    "Olma",
    "Banan",
    "Uzum"
]

➕ Bir nechta element qo‘shish 

let numbers = [
    10,
    40
];

numbers.splice(
    1,
    0,
    20,
    30
);

console.log(numbers);
[
    10,
    20,
    30,
    40
]

🔄 splice() bilan almashtirish

Avval elementni o‘chiramiz, keyin uning o‘rniga yangi element qo‘yamiz. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

fruits.splice(
    1,
    1,
    "Anor"
);

console.log(fruits);
[
    "Olma",
    "Anor",
    "Uzum"
]

🔄 Bir nechta elementni almashtirish 

let numbers = [
    10,
    20,
    30,
    40
];

numbers.splice(
    1,
    2,
    200,
    300
);

console.log(numbers);
[
    10,
    200,
    300,
    40
]

🎁 splice() nima qaytaradi?

splice() o‘chirilgan elementlarni yangi Array sifatida qaytaradi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

let deleted = fruits.splice(
    1,
    2
);

console.log(deleted);

console.log(fruits);
[
    "Banan",
    "Uzum"
]

[
    "Olma",
    "Anor"
]

⚖️ slice va splice farqi

Metod Vazifasi Original Array Qaytaradi
slice() Qismidan nusxa oladi O‘zgarmaydi Yangi Array
splice() Qo‘shadi/o‘chiradi/almashtiradi O‘zgaradi O‘chirilganlar Array'i

🧠 Eng muhim farq

slice()

"Menga Array'dan bir qismini ber."

Original Array o‘zgarmaydi.

splice()

"Array ichidagi elementlarni o‘zgartir."

Original Array o‘zgaradi.

🛒 Real loyiha — mahsulotni o‘chirish

Masalan, do‘konda mahsulotlar ro‘yxati bor va biz bitta mahsulotni o‘chirmoqchimiz. 

let products = [
    "Telefon",
    "Noutbuk",
    "Quloqchin",
    "Sichqoncha"
];

products.splice(2, 1);

console.log(products);
[
    "Telefon",
    "Noutbuk",
    "Sichqoncha"
]

✏️ Real loyiha — mahsulotni almashtirish 

let products = [
    "Telefon",
    "Noutbuk",
    "Quloqchin"
];

products.splice(
    1,
    1,
    "Planshet"
);

console.log(products);
[
    "Telefon",
    "Planshet",
    "Quloqchin"
]

✂️ Real loyiha — mahsulotlarni olish

slice() yordamida mahsulotlarning bir qismini olishimiz mumkin. 

let products = [
    "Telefon",
    "Noutbuk",
    "Planshet",
    "Quloqchin",
    "Sichqoncha"
];

let selected =
    products.slice(1, 4);

console.log(selected);

console.log(products);
[
    "Noutbuk",
    "Planshet",
    "Quloqchin"
]

Original:

[
    "Telefon",
    "Noutbuk",
    "Planshet",
    "Quloqchin",
    "Sichqoncha"
]

🔥 slice() bilan Array nusxasi

Array'ning nusxasini olish uchun slice()ni parametrsiz ham ishlatish mumkin. 

let numbers = [
    10,
    20,
    30
];

let copy = numbers.slice();

console.log(copy);
[
    10,
    20,
    30
]

⚠️ Eslab qoling

✂️ slice() → nusxa oladi

🔧 splice() → Array'ni o‘zgartiradi

slice(1, 4) → 1 dan boshlaydi, 4 ni olmaydi.

splice(1, 2) → 1-indexdan boshlab 2 ta elementni o‘chiradi.

Uyga vazifa 📝

1-vazifa:
Quyidagi Array'dan slice() yordamida 2-, 3- va 4-elementlarni oling: 

let fruits = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor",
    "Shaftoli"
];

2-vazifa:
splice() yordamida Array'dan "Banan"ni o‘chiring.

3-vazifa:
"Uzum" o‘rniga "Anor"ni qo‘ying.

4-vazifa:
Array boshiga emas, 2-indexga yangi element qo‘shing.

5-vazifa:
splice() bilan 2 ta elementni o‘chiring va o‘chirilgan elementlarni alohida o‘zgaruvchiga saqlang.

6-vazifa:
slice() yordamida Array'ning oxirgi 2 ta elementini oling.

7-vazifa:
slice() va splice() farqini o‘zingiz kod bilan ko‘rsating.

Bugungi dars xulosasi 🎯

✂️ slice() — Array'dan qism olib beradi.

🔒 slice() — original Array'ni o‘zgartirmaydi.

🔧 splice() — elementlarni o‘chiradi, qo‘shadi yoki almashtiradi.

⚠️ splice() — original Array'ni o‘zgartiradi.

🎁 slice() — yangi Array qaytaradi.

🗑️ splice() — o‘chirilgan elementlarni Array ko‘rinishida qaytaradi.
