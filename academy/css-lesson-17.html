CSS Flexbox 📦

Elementlarni bir qator yoki ustun bo'yicha tartibli joylashtirish uchun Flexbox'dan foydalanishni o'rganamiz.

1. Flexbox nima?

Flexbox — elementlarni bir o'lchamli tartibda joylashtirish uchun ishlatiladigan CSS layout tizimi.

Flexbox bilan elementlarni gorizontal yoki vertikal joylashtirish juda oson. 

.container {
    display: flex;
}

2. `display: flex`

Flexbox ishlashi uchun parent elementga `display: flex` beramiz. 

.container {
    display: flex;
}

3. `justify-content`

`justify-content` elementlarni asosiy yo'nalish bo'yicha joylashtiradi. 

.container {
    display: flex;
    justify-content: center;
}

Asosiy qiymatlar:

`flex-start` → boshiga
`center` → markazga
`flex-end` → oxiriga
`space-between` → orasini teng ochadi
`space-around` → atrofini teng ochadi
`space-evenly` → bo'sh joylarni teng taqsimlaydi

4. `align-items`

`align-items` elementlarni ikkinchi yo'nalish bo'yicha joylashtiradi. 

.container {
    display: flex;
    align-items: center;
}

6. `flex-direction`

Elementlarning yo'nalishini `flex-direction` bilan o'zgartiramiz.
