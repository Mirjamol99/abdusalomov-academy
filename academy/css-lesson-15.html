CSS Box Model 📦

CSS'da har bir element qanday joy egallashini — content, padding, border va margin orqali boshqarishni o'rganamiz.

1. Box Model nima?

CSS'da har bir HTML elementi aslida to'rt qismdan iborat box sifatida qaraladi.

MARGIN
BORDER
PADDING
CONTENT

2. `content`

Content — elementning ichidagi asosiy qism. Masalan, matn yoki rasm. 

.box {
    width: 200px;
    height: 100px;
}
CONTENT

3. `padding`

Padding — content bilan border orasidagi ichki masofa. 

.box {
    padding: 30px;
}
Content

4. `margin`

Margin — elementning tashqarisidagi masofa. 

.box {
    margin: 30px;
}
CARD 1
CARD 2

5. `border`

Border — padding va margin orasida joylashadigan chegara. 

.box {
    border: 5px solid #22d3ee;
}
BORDER

6. Box Model tartibi

📦 Tashqaridan ichkariga:

1️⃣ Margin
2️⃣ Border
3️⃣ Padding
4️⃣ Content 
Margin
   ↓
Border
   ↓
Padding
   ↓
Content

7. `box-sizing`

`box-sizing` elementning width va height qanday hisoblanishini belgilaydi. 

* {
    box-sizing: border-box;
}
🔥 Amaliy loyihalarda ko'pincha:

box-sizing: border-box; ishlatiladi.

8. `margin` qisqa yozilishi 

margin: 20px;

margin: 10px 20px;

margin: 10px 20px 30px;

margin: 10px 20px 30px 40px;
`1 ta qiymat` → barcha tomon

`2 ta qiymat` → yuqori/pastki va chap/o'ng

`3 ta qiymat` → yuqori, chap/o'ng, pastki

`4 ta qiymat` → yuqori, o'ng, pastki, chap

9. `padding` qisqa yozilishi 

padding: 20px;

padding: 10px 20px;

padding: 10px 20px 30px;

padding: 10px 20px 30px 40px;
Padding ham margin kabi 1, 2, 3 yoki 4 ta qiymat bilan yozilishi mumkin.
