CSS Grid 🧱

CSS Grid yordamida elementlarni qator va ustunlar bo'yicha tartibli joylashtirishni o'rganamiz.

1. CSS Grid nima?

CSS Grid — web sahifadagi elementlarni qator va ustunlar yordamida joylashtirish uchun ishlatiladi. 

.container {
    display: grid;
}
📌 Flexbox asosan bir yo'nalishda, Grid esa qator va ustunlar bilan ishlashda juda qulay.

2. `display: grid`

Grid ishlashi uchun ota elementga `display: grid` beriladi. 

.container {
    display: grid;
}

3. `grid-template-columns`

Ustunlar sonini va o'lchamini belgilash uchun ishlatiladi. 

.container {
    display: grid;

    grid-template-columns:
        repeat(3, 1fr);
}
1
2
3
`1fr` — mavjud joyning bir ulushi.

`repeat(3, 1fr)` → 3 ta teng ustun.

4. `grid-template-rows`

Grid qatorlarining o'lchamini belgilash uchun ishlatiladi. 

.container {
    display: grid;

    grid-template-rows:
        100px 100px;
}

5. `gap`

Grid elementlari orasidagi masofani `gap` yordamida belgilaymiz. 

.container {
    display: grid;
    gap: 20px;
}

8. `minmax()`

`minmax()` yordamida ustunlarning minimal va maksimal o'lchamini belgilash mumkin. 

.container {
    display: grid;

    grid-template-columns:
        repeat(3, minmax(150px, 1fr));
}
📱 Bu responsive dizaynlarda juda foydali.

9. Responsive Grid 📱

`auto-fit` va `minmax()` yordamida ekran o'lchamiga mos Grid yaratish mumkin. 

.container {
    display: grid;

    grid-template-columns:
        repeat(
            auto-fit,
            minmax(200px, 1fr)
        );

    gap: 20px;
}
