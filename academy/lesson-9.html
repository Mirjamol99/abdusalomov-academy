Colspan va Rowspan

Bugun HTML jadvallarida kataklarni birlashtirishni o'rganamiz.

1. colspan nima?

colspan bir qatordagi bir nechta ustunni bitta katakka birlashtiradi.

Masalan, colspan="2" ikkita ustunni birlashtiradi.

Kod: 

<table>

    <tr>

        <td colspan="2">
            Bitta katta katak
        </td>

    </tr>

</table>

Natija:

2 ta ustun birlashdi
HTML CSS

2. colspan="3"

Agar colspan="3" yozsak, uchta ustun bitta katakka birlashadi. 

<tr>

    <td colspan="3">
        Abdusalomov Academy
    </td>

</tr>
Abdusalomov Academy
HTML CSS JavaScript

3. rowspan nima?

rowspan esa bir ustundagi bir nechta qatorni bitta katakka birlashtiradi.

Masalan, rowspan="2" ikkita qatorni birlashtiradi.

Kod: 

<table>

    <tr>

        <td rowspan="2">
            Frontend
        </td>

        <td>
            HTML
        </td>

    </tr>


    <tr>

        <td>
            CSS
        </td>

    </tr>

</table>

Natija:

Frontend HTML
CSS
