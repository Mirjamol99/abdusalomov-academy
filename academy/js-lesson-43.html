sort()

Bugungi darsda JavaScript Array'laridagi sort() metodini o‘rganamiz.

sort() yordamida Array ichidagi elementlarni tartiblash mumkin.

📊 sort() nima?

sort() Array elementlarini tartibga solish uchun ishlatiladi.

Masalan, ismlarni alifbo bo‘yicha yoki sonlarni kichikdan kattaga tartiblash mumkin. 

let names = [
    "Vali",
    "Ali",
    "Hasan",
    "Zafar"
];

names.sort();

console.log(names);
[
    "Ali",
    "Hasan",
    "Vali",
    "Zafar"
]

🔤 Stringlarni sort()

String qiymatlar bilan sort() juda oddiy ishlaydi. 

let fruits = [
    "Banana",
    "Apple",
    "Orange",
    "Mango"
];

fruits.sort();

console.log(fruits);
[
    "Apple",
    "Banana",
    "Mango",
    "Orange"
]

⚠️ Sonlarda sort() muammosi

JavaScript'da sort() sonlarni oddiy chaqirganda har doim matematik tartibda joylashtirmaydi.

Chunki standart holatda elementlar string sifatida solishtiriladi. 

let numbers = [
    10,
    5,
    20,
    1,
    100
];

numbers.sort();

console.log(numbers);
[
    1,
    10,
    100,
    20,
    5
]
❗ Bu matematik tartib emas.

Shuning uchun sonlarni tartiblashda compare function ishlatamiz.

🔢 Sonlarni kichikdan kattaga 

let numbers = [
    10,
    5,
    20,
    1,
    100
];

numbers.sort(
    function(a, b) {
        return a - b;
    }
);

console.log(numbers);
[
    1,
    5,
    10,
    20,
    100
]
a - b

→ kichikdan kattaga tartiblaydi.

🧠 Compare function qanday ishlaydi?

sort((a, b) => a - b)

↓

a va b ikkita element solishtiriladi

↓

Natija manfiy → a oldinda

Natija musbat → b oldinda

0 → joylashuv o‘zgarmaydi

👨‍💻 Object Array'ni sort()

Objectlardan tashkil topgan Array'ni ham sort() yordamida tartiblash mumkin. 

let students = [

    },

    {
        name: "Vali",
        age: 18
    },

    {
        name: "Hasan",
        age: 22
    }

students.sort(
    (a, b) => a.age - b.age
);

console.log(students);

Hasan → 22

🆚 sort() va reverse()

sort()

Elementlarni tartiblaydi. 

numbers.sort(
    (a, b) => a - b
);

reverse()

Mavjud tartibni teskari qiladi. 

numbers.reverse();

⚠️ sort() Array'ni o‘zgartiradi

Muhim!

sort() yangi Array yaratmaydi. U original Array'ning o‘zini tartiblaydi. 

let numbers = [
    30,
    10,
    20
];

numbers.sort(
    (a, b) => a - b
);

console.log(numbers);
[
    10,
    20,
    30
]

🧠 sort() + slice()

Agar original Array o‘zgarmasligini xohlasak, avval nusxa olishimiz mumkin. 

let numbers = [
    30,
    10,
    20
];

let sortedNumbers =
    [...numbers].sort(
        (a, b) => a - b
    );

console.log(sortedNumbers);

console.log(numbers);
sortedNumbers:
[10, 20, 30]

numbers:
[30, 10, 20]
