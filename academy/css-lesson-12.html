CSS Background 🎨

Elementlarga rang, rasm, gradient va chiroyli background berishni o'rganamiz.

1. `background-color`

Elementning orqa fon rangini `background-color` yordamida o'zgartiramiz. 

.box {
    background-color: blue;
}
Background Color

2. `background-image`

Background sifatida rasm qo'yish uchun `background-image` ishlatiladi. 

.box {
    background-image:
        url("image.jpg");
}
Background Image
💡 Rasmni CSS orqali ham, HTML'dagi `` orqali ham ishlatish mumkin.

3. `background-size`

Background rasmining o'lchamini boshqaradi. 

.box {
    background-size: cover;
}
Eng ko'p ishlatiladigan qiymatlar:

`cover` → butun joyni qoplaydi
`contain` → rasmni to'liq ko'rsatadi
`auto` → asl o'lcham

4. `background-position`

Background rasmining joylashuvini belgilaydi. 

.box {
    background-position: center;
}
Misollar:

`center`
`top`
`bottom`
`left`
`right`

5. `background-repeat`

Background rasmining takrorlanishini boshqaradi. 

.box {
    background-repeat: no-repeat;
}
`no-repeat` → rasm takrorlanmaydi
`repeat` → takrorlanadi
`repeat-x` → gorizontal takrorlanadi
`repeat-y` → vertikal takrorlanadi

6. Linear Gradient 🌈

Gradient yordamida bir rangdan ikkinchi rangga chiroyli o'tish hosil qilamiz. 

.box {
    background:
        linear-gradient(
            90deg,
            blue,
            purple
        );
}
Linear Gradient

7. Radial Gradient 🟣

Radial gradient markazdan tashqariga qarab tarqaladi. 

.box {
    background:
        radial-gradient(
            circle,
            blue,
            purple
        );
}
Radial Gradient

8. Background Overlay

Rasm ustiga rang yoki gradient qo'yib, matnni yaxshi ko'rinadigan qilish mumkin. 

.hero {
    background:
        linear-gradient(
            rgba(0,0,0,.6),
            rgba(0,0,0,.6)
        ),
        url("image.jpg");

    background-size: cover;
}

9. Background shorthand

Bir nechta background xususiyatlarini qisqa yozish mumkin. 

.box {
    background:
        #0e7490
        url("image.jpg")
        center / cover
        no-repeat;
}
🔥 Shorthand kodni qisqartirishga yordam beradi.
