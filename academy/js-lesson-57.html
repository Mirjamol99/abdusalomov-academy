DOM style va class

Bugun JavaScript yordamida HTML elementlarining CSS style va classlarini boshqarishni o‘rganamiz.

Asosiy mavzular: style, classList, add(), remove(), toggle() va contains().

🎨 DOM style nima?

JavaScript orqali HTML elementining CSS style xususiyatlarini o‘zgartirish mumkin. 

let title =
    document.querySelector("#title");

title.style.color = "orange";
Bu kod #title elementining matn rangini o‘zgartiradi.

📝 style.color 

let text =
    document.querySelector("#text");

text.style.color = "red";

CSS'dagi color JavaScript'da: 

element.style.color = "red";

🔠 fontSize

Matn o‘lchamini ham JavaScript orqali o‘zgartirish mumkin. 

element.style.fontSize = "40px";
⚠️ CSS'dagi font-size JavaScript'da fontSize ko‘rinishida yoziladi.

📦 width va height 

element.style.width = "300px";

element.style.height = "200px";

Shu orqali elementning kengligi va balandligini o‘zgartirish mumkin.

🟡 backgroundColor 

element.style.backgroundColor =
    "orange";
CSS'dagi background-color JavaScript'da backgroundColor bo‘ladi.

🔥 Amaliy misol — style

JavaScript Style

Mening style'im o‘zgaradi. 

function changeStyle() {

    let box =
        document.querySelector(
            "#styleDemo"
        );

    box.style.backgroundColor =
        "orange";

    box.style.color =
        "black";

    box.style.padding =
        "40px";

}

📚 classList nima?

classList elementdagi CSS classlar bilan ishlash uchun ishlatiladi. 

let box =
    document.querySelector("#box");

console.log(box.classList);
classList yordamida class qo‘shish, olib tashlash, almashtirish va tekshirish mumkin.

➕ classList.add()

Elementga yangi class qo‘shadi. 

element.classList.add("active");

Bir nechta class ham qo‘shish mumkin: 

element.classList.add(
    "active",
    "large"
);

➖ classList.remove()

Elementdan classni olib tashlaydi. 

element.classList.remove("active");
Agar elementda active class bo‘lsa, u olib tashlanadi.

🔄 classList.toggle()

toggle() class bo‘lsa olib tashlaydi, bo‘lmasa qo‘shadi. 

element.classList.toggle("active");
💡 toggle() menyu, dark mode, modal, accordion va boshqa interaktiv elementlarda juda ko‘p ishlatiladi.

🔎 classList.contains()

Elementda ma'lum bir class bor yoki yo‘qligini tekshiradi. 

let result =
    element.classList.contains(
        "active"
    );

console.log(result);
Natija:

true → class mavjud.

false → class mavjud emas.

🔥 add, remove, toggle

add()

Class qo‘shadi. 

el.classList.add(
    "active"
);

remove()

Classni olib tashlaydi. 

el.classList.remove(
    "active"
);

toggle()

Classni qo‘shadi yoki olib tashlaydi. 

el.classList.toggle(
    "active"
);

🎯 Amaliy misol — class qo‘shish

Men class orqali o‘zgaraman 

function addClass() {

    let box =
        document.querySelector(
            "#classDemo"
        );

    box.classList.add(
        "border-4",
        "border-yellow-400"
    );

}

🔄 Amaliy misol — toggle

Toggle Demo

Tugmani bosib ko‘ring. 

function toggleBox() {

    let box =
        document.querySelector(
            "#toggleBox"
        );

    box.classList.toggle(
        "border-4"
    );

    box.classList.toggle(
        "border-yellow-400"
    );

}

🌙 Dark mode misoli

Light Mode

Dark mode uchun toggle ishlatamiz. 

function darkMode() {

    let box =
        document.querySelector(
            "#darkBox"
        );

    box.classList.toggle(
        "bg-white"
    );

    box.classList.toggle(
        "bg-slate-900"
    );

    box.classList.toggle(
        "text-slate-950"
    );

    box.classList.toggle(
        "text-white"
    );

}

🧠 Inline style va class farqi

style

    "red";

classList

element.classList.add(
    "active"
);
