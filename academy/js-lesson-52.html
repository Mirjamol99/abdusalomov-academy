DOM nima?

Bugundan boshlab JavaScript'da DOM bilan ishlashni boshlaymiz.

DOM yordamida JavaScript orqali HTML elementlarini topish, o‘zgartirish, qo‘shish va o‘chirish mumkin.

🌐 DOM nima?

DOM — Document Object Model degan so‘zlarning qisqartmasi.

Brauzer HTML sahifani o‘qib, uni JavaScript bilan ishlash mumkin bo‘lgan obyektlar daraxtiga aylantiradi.

DOM = HTML sahifaning JavaScript orqali boshqariladigan ko‘rinishi.

🏗️ HTML → DOM

Masalan, bizda quyidagi HTML bo‘lsin: 

<body>

    <h1>Salom JavaScript</h1>

    <p>Men JavaScript o‘rganayapman</p>

</body>

Brauzer bu HTML'ni DOM daraxtiga aylantiradi.

🌳 DOM daraxti 

document
   │
   └── html
        │
        ├── head
        │
        └── body
             │
             ├── h1
             │
             └── p

Har bir HTML elementi DOM ichida alohida node sifatida mavjud bo‘ladi.

📄 document nima?

JavaScript'da document — hozirgi HTML sahifani ifodalaydi. 

console.log(document);

Console'da sahifaning HTML tuzilmasini ko‘rishingiz mumkin.

🔍 DOM bilan nima qilish mumkin?

🔎 HTML elementini topish
✏️ Matnni o‘zgartirish
🎨 CSS stilini o‘zgartirish
➕ Yangi element qo‘shish
❌ Elementni o‘chirish
🖱️ Event qo‘shish

🔎 HTML elementini topish

DOM bilan ishlashning eng muhim qismlaridan biri — elementni topish.

Buni keyingi darslarda batafsil o‘rganamiz. 
document.getElementById("title");

🧩 DOM va JavaScript

JavaScript yordamida HTML elementini topib, uning tarkibini o‘zgartirishimiz mumkin. 

document.getElementById("title")
    .textContent = "Salom!";

🎯 Amaliy misol

Eski matn 

function changeTitle() {

    document.getElementById(
        "demoTitle"
    ).textContent =
        "Yangi matn!";

}

📝 DOM orqali matn o‘zgartirish 

let title =
    document.getElementById("title");

title.textContent =
    "JavaScript darsi";
textContent element ichidagi matnni o‘zgartirish uchun ishlatiladi.

🎨 DOM orqali style o‘zgartirish 

let title =
    document.getElementById("title");

title.style.color = "red";

JavaScript orqali CSS property'larini ham o‘zgartirish mumkin.

🛒 DOM + Shopping Cart

Masalan, internet do‘konda foydalanuvchi "Savatga qo‘shish" tugmasini bosganda DOM orqali savatdagi mahsulotlar sonini o‘zgartirish mumkin. 

let cartCount = 0;

function addToCart() {

    cartCount++;

    document.getElementById(
        "cartCount"
    ).textContent = cartCount;

}

0

⚠️ DOM bilan ishlashda muhim tushuncha

JavaScript HTML'dan oldin ishlasa, element hali mavjud bo‘lmasligi mumkin.

Shuning uchun JavaScript faylini ko‘pincha <body> oxirida ulash qulay. 

<body>

    ...

    <script src="script.js"></script>

</body>

🧠 DOM bo‘yicha asosiy tushunchalar

document

HTML hujjat.

element

HTML elementi.

node

DOM daraxtidagi tugun.

textContent

Element matnini boshqarish.

style

Element stilini boshqarish.
