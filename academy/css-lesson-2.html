CSS ulash usullari 🔗

CSS kodlarini HTML sahifaga qanday ulashni bosqichma-bosqich o'rganamiz.

1. Inline CSS

Inline CSS HTML elementining ichidagi style atributi orqali yoziladi. 

<h1 style="color: blue;">
    Abdusalomov Academy
</h1>
💡 Inline CSS faqat shu elementga ta'sir qiladi.

Abdusalomov Academy

Bu Inline CSS misoli.

2. Internal CSS

Internal CSS <style> tegi ichida yoziladi. 

<style>

    h1 {
        color: blue;
        font-size: 40px;
    }

    p {
        color: gray;
    }

</style>
💡 Internal CSS bitta HTML sahifaga tegishli CSS kodlarini yozish uchun qulay.

3. External CSS ⭐

External CSS alohida .css faylda yoziladi.

Masalan: 

<link rel="stylesheet"
      href="style.css">

Keyin style.css fayliga CSS kodlarini yozamiz: 

h1 {

    color: blue;

}

p {

    color: gray;

}
🚀 Katta loyihalarda External CSS juda ko'p ishlatiladi.

4. Uchala usulning farqi

5. Amaliy loyiha 💻

Endi External CSS yordamida oddiy karta yaratamiz. 

<!-- index.html -->

<link rel="stylesheet"
      href="style.css">

<div class="card">

    <h2>
        Abdusalomov Academy
    </h2>

    <p>
        CSS o'rganamiz!
    </p>

</div>
/* style.css */

.card {

    background: rgba(15, 23, 42, .72);

    padding: 30px;

    border-radius: 20px;

}

.card h2 {

    color: #22d3ee;

}

.card p {

    color: #94a3b8;

}
