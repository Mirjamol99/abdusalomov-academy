else va else if

16-darsda if yordamida shartni tekshirishni o‘rgandik.

Bugun esa shart bajarilmasa nima qilish kerakligini o‘rganamiz.

Buning uchun:

else — aks holda
else if — yana bir shart ishlatiladi.

else nima? 🤔

else ingliz tilida "aks holda" degan ma'noni anglatadi.

Agar if sharti true bo‘lsa, if ichidagi kod bajariladi.

Agar if sharti false bo‘lsa, else ichidagi kod bajariladi.

else sintaksisi 📚 

if (shart) {
    // shart true bo‘lsa
} else {
    // shart false bo‘lsa
}

Bu yerda if birinchi shartni tekshiradi.

Agar shart noto‘g‘ri bo‘lsa, JavaScript else blokini bajaradi.

Oddiy else misoli 

let age = 15;

if (age >= 18) {
    console.log("Kirish mumkin");
} else {
    console.log("Kirish mumkin emas");
}
Kirish mumkin emas

Chunki:

15 >= 18 → false

Shuning uchun else bajarildi.

Shart true bo‘lsa ✅ 

let age = 20;

if (age >= 18) {
    console.log("Kirish mumkin");
} else {
    console.log("Kirish mumkin emas");
}
Kirish mumkin

Bu safar:

20 >= 18 → true

Shuning uchun if bajarildi, else bajarilmadi.

else bilan Boolean 🧠 

let isLogin = false;

if (isLogin) {
    console.log("Xush kelibsiz!");
} else {
    console.log("Iltimos, tizimga kiring.");
}
Iltimos, tizimga kiring.

else va comparison operatorlar ⚖️ 

let number = 7;

if (number > 10) {
    console.log("10 dan katta");
} else {
    console.log("10 dan katta emas");
}
10 dan katta emas

else if nima? 🔀

Ba'zida faqat ikkita variant yetarli bo‘lmaydi.

Masalan, ball:

90 dan yuqori — A
70 dan yuqori — B
50 dan yuqori — C
Aks holda — F

Bunday vaziyatda else if ishlatiladi.

else if sintaksisi 

if (birinchiShart) {

} else if (ikkinchiShart) {

} else {

}

JavaScript shartlarni yuqoridan pastga qarab tekshiradi.

Birinchi true bo‘lgan shartning kodi bajariladi.

Oddiy else if misoli 

let age = 20;

if (age < 13) {
    console.log("Bola");
} else if (age < 18) {
    console.log("O‘smir");
} else {
    console.log("Katta yoshli");
}
Katta yoshli

Bir nechta else if 

let score = 85;

if (score >= 90) {
    console.log("A");
} else if (score >= 80) {
    console.log("B");
} else if (score >= 70) {
    console.log("C");
} else if (score >= 60) {
    console.log("D");
} else {
    console.log("F");
}
B

85 >= 90 → false
85 >= 80 → true

Shuning uchun JavaScript B ni chiqaradi va keyingi shartlarni tekshirishni davom ettirmaydi.

else if va && 🔥 

let age = 20;

    console.log("Kirish mumkin");

    console.log("Chipta kerak");

    console.log("Yoshingiz yetmaydi");
}
Kirish mumkin

else if qanday ishlaydi? 🔍

15 > 10 → true
