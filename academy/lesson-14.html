Button va Input tugmalari

HTML'da tugmalar yaratish va ularning qanday ishlashini o'rganamiz.

1. <button> nima?

<button> foydalanuvchi bosishi mumkin bo'lgan tugma yaratadi. 

<button>
    Bosish
</button>

2. Button type

Buttonning vazifasini type atributi orqali belgilash mumkin. 

<button type="button">
    Oddiy tugma
</button>


<button type="submit">
    Yuborish
</button>


<button type="reset">
    Tozalash
</button>

3. type="button"

type="button" oddiy tugma hisoblanadi. U formani avtomatik yubormaydi. 

<button type="button">
    Bosish
</button>

4. type="submit"

type="submit formadagi ma'lumotlarni yuborish uchun ishlatiladi. 

<button type="submit">
    Yuborish
</button>

5. type="reset"

type="reset" formadagi kiritilgan ma'lumotlarni boshlang'ich holatga qaytaradi. 

<button type="reset">
    Tozalash
</button>

6. <input type="button">

Tugmani input orqali ham yaratish mumkin. 

<input
    type="button"
    value="Bosish">

7. Tugmaga icon qo'shish

Font Awesome yordamida tugmaga chiroyli icon qo'shishimiz mumkin. 

<button>

    <i class="fa-solid fa-download"></i>

    Yuklab olish

</button>
