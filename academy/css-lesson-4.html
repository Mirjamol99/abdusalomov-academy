CSS Colors 🎨

CSS yordamida matn va elementlarga turli xil ranglar berishni o'rganamiz.

1. `color` xususiyati

color CSS xususiyati matn rangini o'zgartirish uchun ishlatiladi. 

h1 {
    color: blue;
}

p {
    color: red;
}

Ko'k rangdagi matn

Qizil rangdagi matn

💡 `color` — matn rangini o'zgartiradi.

2. `background-color`

Elementning orqa fon rangini o'zgartirish uchun background-color ishlatiladi. 

div {
    background-color: blue;
}

Background Color

Bu elementning foni rangli.

📌 `color` — matn rangi.
📌 `background-color` — fon rangi.

3. Rang nomlari

CSS'da ranglarni oddiy nomlari bilan ham yozish mumkin. 

color: red;

color: blue;

color: green;

color: yellow;

color: purple;

color: orange;
RED
BLUE
GREEN
YELLOW
PURPLE
ORANGE

4. HEX ranglar

HEX ranglar # belgisi bilan boshlanadi. 

h1 {
    color: #22d3ee;
}

p {
    color: #94a3b8;
}

body {
    background-color: #020617;
}
💡 Masalan:

#ff0000 → qizil
#00ff00 → yashil
#0000ff → ko'k
#22d3ee
#22c55e
#ef4444

5. RGB ranglar

RGB uchta qiymatdan foydalanadi:

R

Red — qizil

G

Green — yashil

B

Blue — ko'k 

color: rgb(255, 0, 0);

color: rgb(0, 255, 0);

color: rgb(0, 0, 255);

6. RGBA

RGBA RGB ga qo'shimcha ravishda alpha qiymatidan foydalanadi.

Alpha elementning shaffoflik darajasini bildiradi. 

background-color:
rgba(6, 182, 212, 0.5);
RGBA
📌 `1` — to'liq ko'rinadi.
📌 `0` — to'liq shaffof.
📌 `0.5` — yarim shaffof.

7. Amaliy loyiha 💻

Endi ranglardan foydalanib zamonaviy card yaratamiz. 

<div class="card">

    <h2>
        Abdusalomov Academy
    </h2>

    <p>
        CSS Colors
    </p>

</div>
.card {

    background-color: #0f172a;

    border: 1px solid #22d3ee;

}

.card h2 {

    color: #22d3ee;

}

.card p {

    color: #94a3b8;

}
