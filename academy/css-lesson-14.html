Border, Radius & Shadow 🎨

Elementlarga chegara, yumaloq burchak va soya berib, chiroyli dizayn yaratishni o'rganamiz.

1. `border`

`border` element atrofida chegara yaratish uchun ishlatiladi. 

.box {
    border: 2px solid blue;
}
Border

2. Border turi

Borderning turli xil ko'rinishlari mavjud. 

border: 2px solid blue;
border: 2px dashed blue;
border: 2px dotted blue;
Solid
Dashed
Dotted

3. `border-width`

Border qalinligini belgilaydi. 

.box {
    border-width: 5px;
}
5px Border

4. `border-color`

Border rangini o'zgartirish uchun `border-color` ishlatiladi. 

.box {
    border-color: #3b82f6;
}
Border Color

5. `border-radius`

Element burchaklarini yumaloq qilish uchun `border-radius` ishlatiladi. 

.box {
    border-radius: 20px;
}
Border Radius
💡 `border-radius: 50%` berilsa, kvadrat elementni aylana qilish mumkin.

6. `border-radius: 50%`

Elementni aylana ko'rinishiga keltirishimiz mumkin. 

.circle {
    width: 120px;
    height: 120px;

    border-radius: 50%;
}

7. `box-shadow`

Elementga soya berish uchun `box-shadow` ishlatiladi. 

.box {
    box-shadow:
        0 10px 30px
        rgba(0, 0, 0, .4);
}
Box Shadow

8. Shadow qiymatlari

Shadow bir nechta qiymatdan tashkil topishi mumkin. 

box-shadow:
    0 10px 30px rgba(0, 0, 0, .4);
`0` → X yo'nalish
`10px` → Y yo'nalish
`30px` → blur
`rgba(...)` → soya rangi

9. `outline`

`outline` ham element atrofida chiziq hosil qiladi. 

.box {
    outline: 3px solid blue;
}
Outline

10. Amaliy loyiha 💻

Endi border, radius va shadow yordamida zamonaviy kurs kartasi yaratamiz.
