Console bilan ishlash

Bugun JavaScript'dagi console bilan ishlashni va natijalarni Developer Console'da ko‘rishni o‘rganamiz.

Console nima? 🤔

Console — brauzerning JavaScript kodlarini tekshirish, natijalarni ko‘rish va xatolarni aniqlash uchun ishlatiladigan Developer Tools qismidir.

JavaScript o‘rganayotganimizda Console bizning eng asosiy yordamchilarimizdan biri bo‘ladi.

Console'ni qanday ochamiz? 🖥️

Chrome yoki boshqa zamonaviy brauzerda:

1. Saytni oching.
2. Sichqonchaning o‘ng tugmasini bosing.
3. Inspect ni tanlang.
4. Console bo‘limiga kiring.

⚡ Tezkor tugma:

F12 yoki Ctrl + Shift + J

console.log() 📢

JavaScript'da ma'lumotni Console'ga chiqarish uchun console.log() ishlatiladi. 

console.log("Salom JavaScript!");

Natijada Console'da: 

Salom JavaScript!

Sonlarni Console'ga chiqarish 🔢

Console'ga faqat matn emas, sonlarni ham chiqarish mumkin. 

console.log(10);

console.log(25);

console.log(100);

Natija: 

10
25
100

Hisob-kitob qilish 🧮

JavaScript Console orqali matematik amallarni ham bajarish mumkin. 

console.log(10 + 5);

console.log(20 - 7);

console.log(6 * 4);

console.log(20 / 5);

Natijalar:

15
13
24
4

Bir nechta qiymat chiqarish

Bitta console.log() ichida bir nechta qiymat ham chiqarish mumkin. 

console.log("Mirjamol", 15);

Console: 

Mirjamol 15

O‘zgaruvchi bilan console.log()

Keyingi darslarda o‘zgaruvchilarni chuqurroq o‘rganamiz. Hozir esa oddiy misol: 

let age = 15;

console.log(age);

Natija: 

15

console.warn() ⚠️

console.warn() ogohlantirish ko‘rsatish uchun ishlatiladi. 

console.warn("Diqqat!");

Bu usul dasturchiga biror muhim ogohlantirishni ko‘rsatishda foydali.

console.error() ❌

console.error() xatolik haqida ma'lumot chiqarishda ishlatiladi. 

console.error("Xatolik yuz berdi!");

❗ Bu JavaScript kodini avtomatik ravishda tuzatmaydi. Faqat Console'da error sifatida ko‘rsatadi.

console.table() 📊

Array yoki obyekt kabi ma'lumotlarni jadval ko‘rinishida ko‘rish uchun console.table() ishlatilishi mumkin. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

console.table(fruits);

Amaliy mashq 💻

Quyidagi kodni script.js faylingizga yozing: 

console.log("Mening ismim Mirjamol");

console.log(15);

console.log(10 + 20);

console.warn("Bu ogohlantirish");

console.error("Bu xatolik");

console.log("JavaScript o‘rganayapman!");

Keyin HTML faylingizni brauzerda ochib, Console bo‘limiga qarang.

Muhim eslab qoling 📚

🖥️ console.log() → ma'lumot chiqaradi.

⚠️ console.warn() → ogohlantirish chiqaradi.

❌ console.error() → error ko‘rsatadi.

📊 console.table() → ma'lumotni jadval ko‘rinishida ko‘rsatadi.

🔍 Console JavaScript kodini tekshirishda juda muhim.

Uyga vazifa 📝

Quyidagilarni Console'ga chiqarib ko‘ring:

2️⃣ Yoshingiz

5️⃣ 8 × 7
