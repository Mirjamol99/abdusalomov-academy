CSS Position 📍

CSS'dagi position property yordamida elementlarni sahifada aniq joylashtirishni o'rganamiz.

1. `position` nima?

`position` elementning sahifadagi joylashish usulini boshqaradi. 

.box {
    position: relative;
}
📌 Asosiy qiymatlar:

`static`
`relative`
`absolute`
`fixed`
`sticky`

2. `position: static`

`static` — elementning odatiy joylashish holati. 

.box {
    position: static;
}
STATIC
💡 Ko'pchilik HTML elementlar default holatda `static` bo'ladi.

3. `position: relative`

`relative` elementni o'zining odatiy joyiga nisbatan siljitish imkonini beradi. 

.box {
    position: relative;
    left: 30px;
    top: 10px;
}
RELATIVE
📌 `relative` ishlatilganda elementning asl joyi saqlanib qoladi.

4. `top`, `right`, `bottom`, `left`

Position bilan birga elementni yuqoriga, pastga, o'ngga yoki chapga siljitish mumkin. 

.box {
    position: relative;

    top: 20px;
    left: 30px;
}
⬆️ `top` — yuqoridan masofa
➡️ `right` — o'ngdan masofa
⬇️ `bottom` — pastdan masofa
⬅️ `left` — chapdan masofa

5. `position: absolute`

`absolute` elementni odatiy oqimdan chiqaradi va joylashtirish uchun yaqin positionlangan ota elementga tayanadi. 

.parent {
    position: relative;
}

.child {
    position: absolute;

    top: 20px;
    right: 20px;
}
Yangi

Kurs Card

Absolute element

⭐ Ko'p ishlatiladigan usul:

Ota elementga:
`position: relative`

Ichki elementga:
`position: absolute`

6. `position: fixed`

`fixed` elementni brauzer oynasiga nisbatan bir joyda ushlab turadi. 

.button {
    position: fixed;

    right: 20px;
    bottom: 20px;
}
📌 Masalan, saytlarning pastki burchagidagi yordam yoki yuqoriga qaytish tugmalari `fixed` bo'lishi mumkin.

7. `position: sticky`

`sticky` element scroll vaqtida ma'lum chegaraga yetganda yopishib turadi. 

.menu {
    position: sticky;
    top: 0;
}
STICKY MENU 📌

Bu element sticky sifatida ishlatilishi mumkin.

Scroll qilganda yuqoriga yopishib qoladi.

8. `z-index`

`z-index` ustma-ust turgan elementlardan qaysi biri yuqorida ko'rinishini belgilaydi. 

.box {
    position: absolute;
    z-index: 10;
}

🔥 `z-index` qiymati katta bo'lgan element odatda yuqoriroq qatlamda ko'rinadi.

9. Amaliy loyiha 💻

Endi `relative` va `absolute` yordamida chiroyli profil card yaratamiz. 

.profile {
    position: relative;
}

.badge {
    position: absolute;

    top: 15px;
    right: 15px;
}
