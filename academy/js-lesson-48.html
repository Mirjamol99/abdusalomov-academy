Spread Operator

Bugungi darsda JavaScript'dagi Spread Operator bilan ishlashni o‘rganamiz.

Spread operator ... yordamida Array va Object ichidagi qiymatlarni yoyish, nusxalash va birlashtirish mumkin.

📋 Spread Operator nima?

Spread operator — ... uchta nuqta bilan yoziladi.

U Array yoki Object ichidagi qiymatlarni "yoyib" beradi. 

let numbers = [10, 20, 30];

console.log(...numbers);
10 20 30
... → Spread operator

U Array'ni alohida qiymatlarga yoyib beradi.

🔢 Array'ni yoyish 

let fruits = [
    "Apple",
    "Banana",
    "Mango"
];

console.log(...fruits);
Apple Banana Mango

➕ Array'larni birlashtirish

Spread operator yordamida ikkita yoki undan ko‘p Array'ni birlashtirish mumkin. 

let first = [1, 2, 3];

let second = [4, 5, 6];

let result = [
    ...first,
    ...second
];

console.log(result);
[1, 2, 3, 4, 5, 6]

🔄 Array orasiga qo‘shish 

let numbers = [1, 2, 5, 6];

let result = [
    1,
    2,
    3,
    4,
    5,
    6
];

console.log(result);

Spread bilan yanada qulay: 

let first = [1, 2];

let second = [5, 6];

let result = [
    ...first,
    3,
    4,
    ...second
];

console.log(result);
[1, 2, 3, 4, 5, 6]

📑 Array nusxalash

Spread operator yordamida Array'ning yangi nusxasini yaratish mumkin. 

let fruits = [
    "Apple",
    "Banana",
    "Mango"
];

let copy = [
    ...fruits
];

console.log(copy);
copy — yangi Array.

Bu usul asl Array'ni o‘zgartirmasdan yangi Array yaratishda foydali.

⚡ Spread va push()

Bir Array'ni boshqa Array'ga qo‘shish uchun Spread'dan foydalanish mumkin. 

let fruits = [
    "Apple",
    "Banana"
];

let newFruits = [
    ...fruits,
    "Mango",
    "Orange"
];

console.log(newFruits);
[
    "Apple",
    "Banana",
    "Mango",
    "Orange"
]

📦 Object Spread

Spread operator Object bilan ham ishlaydi. 

let user = {

    name: "Ali",

    age: 18

};

let copy = {
    ...user
};

console.log(copy);
{
    name: "Ali",
    age: 18
}

➕ Object'larni birlashtirish 

let userInfo = {

    name: "Ali",

    age: 18

};

let address = {

    city: "Andijon",

    street: "Navoi"

};

let user = {

    ...userInfo,
    ...address

};

console.log(user);
{
    name: "Ali",
    age: 18,
    city: "Andijon",
    street: "Navoi"
}

✏️ Object'ga yangi property qo‘shish 

let user = {

    name: "Ali",

    age: 18

};

let newUser = {

    ...user,

    city: "Andijon"

};

console.log(newUser);
{
    name: "Ali",
    age: 18,
    city: "Andijon"
}

🔄 Object property'ni yangilash

Bir xil key ikki marta yozilsa, keyinroq yozilgan qiymat ustun keladi. 

let user = {

    name: "Ali",

    age: 18

};

let updatedUser = {

    ...user,

    age: 20

};

console.log(updatedUser);
{
    name: "Ali",
    age: 20
}

🧠 Spread va Destructuring farqi

Destructuring

Qiymatlarni ajratib oladi. 

let user = {
    name: "Ali",
    age: 18
};

let {
    name,
    age
} = user;

Spread

Qiymatlarni yoyadi yoki nusxalaydi. 

let copy = {
    ...user
};

🔢 Spread va Math.max()

Array ichidagi eng katta sonni topishda Spread juda qulay. 

let numbers = [
    10,
    50,
    20,
    90,
    30
];

let max = Math.max(...numbers);

console.log(max);
90

🔽 Spread va Math.min() 

let numbers = [
    10,
    50,
    20,
    90,
    30
];

let min = Math.min(...numbers);

console.log(min);
10

📋 Function argumentlarida Spread

Array ichidagi qiymatlarni function'ga alohida argument sifatida yuborish mumkin. 

function sum(a, b, c) {

    return a + b + c;

}

let numbers = [10, 20, 30];

console.log(
    sum(...numbers)
);
60

🛒 Real loyiha: Cart

Oldingi darslarda Array va Object bilan ishlaganimizni Spread bilan birlashtiramiz. 

let cart = [

    {
        name: "Pizza",
        price: 50000
    },

    {
        name: "Burger",
        price: 30000
    }

];

let newProduct = {

    name: "Cola",

    price: 10000

};

let newCart = [

    ...cart,

    newProduct

];

console.log(newCart);

🔥 Cart'ni yangilash 

let cart = [

    {
        id: 1,
        name: "Pizza",
        price: 50000
    },

    {
        id: 2,
        name: "Burger",
        price: 30000
    }

];


let newProduct = {

    id: 3,

    name: "Cola",

    price: 10000

};


cart = [

    ...cart,

    newProduct

];


console.log(cart);

🔄 Object va Array birga 

let user = {

    name: "Ali",

    age: 18,

    skills: [
        "HTML",
        "CSS"
    ]

};


let updatedUser = {

    ...user,

    skills: [

        ...user.skills,

        "JavaScript"

    ]

};


console.log(updatedUser);
{
    name: "Ali",
    age: 18,
    skills: [
        "HTML",
        "CSS",
        "JavaScript"
    ]
}

⚡ Spread bilan Array'ni oldiga qo‘shish 

let oldItems = [
    "Banana",
    "Mango"
];

let newItems = [
    "Apple",
    ...oldItems
];

console.log(newItems);
[
    "Apple",
    "Banana",
    "Mango"
]

📌 Spread operatorning asosiy ishlatilishi

...array

Array elementlarini yoyish.

[...array]

Array nusxasini yaratish.

{...object}

Object nusxasini yaratish.

{...obj, newProperty}

Object'ga yangi property qo‘shish.

Math.max(...numbers)

Array'dagi eng katta qiymatni topish.

🔥 To‘liq amaliy misol 

let user = {

    id: 1,

    name: "Ali",

    age: 18,

    skills: [
        "HTML",
        "CSS"
    ]

};


let newUser = {

    ...user,

    age: 19,

    city: "Andijon",

    skills: [

        ...user.skills,

        "JavaScript"

    ]

};


console.log(newUser);
Bu misolda:

...user → Object nusxalandi.

age: 19 → age yangilandi.

city: "Andijon" → yangi property qo‘shildi.

...user.skills → eski skills saqlandi.

"JavaScript" → yangi skill qo‘shildi.

🎯 Dars xulosasi

📑 Array nusxalash: [...array]

➕ Array'larni birlashtirish: [...a, ...b]

📦 Object nusxalash: {...object}

✏️ Object property'larini yangilash va qo‘shish mumkin.

🧮 Spread yordamida Math.max() va Math.min() bilan Array qiymatlarini ishlatish mumkin.

🔥 Spread real loyihalarda cart, user, product va API ma'lumotlari bilan ishlashda juda ko‘p qo‘llanadi.
