reduce()

Bugungi darsda JavaScript Array'laridagi reduce() metodini o‘rganamiz.

reduce() yordamida Array ichidagi qiymatlarni bitta umumiy natijaga yig‘ishimiz mumkin.

➗ reduce() nima?

reduce() Array ichidagi elementlarni ketma-ket ishlab chiqib, oxirida bitta natija qaytaradi. 

let numbers = [10, 20, 30, 40];

let result = numbers.reduce(function(
    sum,
    number
) {
    return sum + number;
}, 0);

console.log(result);
100

🧠 reduce() qanday ishlaydi?

[10, 20, 30, 40]

↓

Barcha qiymatlar yig‘iladi

↓

100

🔢 Oddiy misol 

let numbers = [
    1, 2, 3, 4, 5
];

let result = numbers.reduce(
    function(sum, number) {

        return sum + number;

    },
    0
);

console.log(result);
Hisoblanishi:

0 + 1 = 1
1 + 2 = 3
3 + 3 = 6
6 + 4 = 10
10 + 5 = 15 
15

📦 Accumulator nima?

reduce() ichidagi birinchi parametr ko‘pincha acc, sum yoki total deb nomlanadi.

U har bir qadamda yig‘ilib boradigan natijani saqlaydi. 

let numbers = [10, 20, 30];

let result = numbers.reduce(
    function(acc, number) {

        return acc + number;

    },
    0
);

console.log(result);
acc → yig‘ilib borayotgan natija

number → hozirgi element

0 → boshlang‘ich qiymat

0️⃣ Boshlang‘ich qiymat

reduce() oxiridagi 0 boshlang‘ich qiymat hisoblanadi. 

let numbers = [10, 20, 30];

let result = numbers.reduce(
    (sum, number) => sum + number,
    100
);

console.log(result);
160

Chunki: 100 + 10 + 20 + 30 = 160

✖️ Ko‘paytirish

reduce() faqat qo‘shish uchun ishlatilmaydi.

Masalan, sonlarni ko‘paytirish mumkin. 

let numbers = [2, 3, 4];

let result = numbers.reduce(
    (result, number) =>
        result * number,
    1
);

console.log(result);
24
1 × 2 × 3 × 4 = 24

🔢 Eng katta sonni topish 

let numbers = [
    15, 8, 32, 21, 10
];

let max = numbers.reduce(
    function(biggest, number) {

        if (number > biggest) {
            return number;
        }

        return biggest;

    },
    numbers[0]
);

console.log(max);

🛒 Cart bilan reduce()

Bu usul internet-do‘konlarda savatchaning umumiy narxini hisoblashda juda kerak bo‘ladi. 

let cart = [

    {
        name: "Pizza",

        quantity: 2

🆚 reduce() va filter()

filter() 

let numbers = [
    10, 20, 30, 40
];

let result = numbers.filter(
    number => number > 20
);

[30, 40]

reduce() 

let result = numbers.reduce(
    (sum, number) =>
        sum + number,
    0
);

100

filter() → bir nechta element qaytaradi.

reduce() → bitta umumiy natija qaytaradi.
