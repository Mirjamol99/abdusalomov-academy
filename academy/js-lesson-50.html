Date va vaqt

Bugungi darsda JavaScript'da sana va vaqt bilan ishlashni o‘rganamiz.

JavaScript'da sana va vaqt bilan ishlash uchun Date obyektidan foydalaniladi.

📅 Date nima?

Date — JavaScript'da sana va vaqtni saqlash va ular bilan ishlash uchun ishlatiladigan obyekt. 

let now = new Date();

console.log(now);
new Date() → hozirgi sana va vaqtni beradi.

⏰ Hozirgi vaqtni olish 

let now = new Date();

console.log(now);

Natija taxminan quyidagicha ko‘rinishi mumkin: 

Mon Aug 10 2026 15:30:00 GMT+0500

📆 Yilni olish — getFullYear() 

let now = new Date();

let year = now.getFullYear();

console.log(year);
2026

getFullYear() → yilni qaytaradi.

📅 Oy — getMonth() 

let now = new Date();

let month = now.getMonth();

console.log(month);
⚠️ Muhim!

JavaScript'da oylar 0 dan boshlanadi.

Yanvar → 0
Fevral → 1
Mart → 2
...
Dekabr → 11

📆 To‘g‘ri oy nomini chiqarish 

let now = new Date();

let month = now.getMonth() + 1;

console.log(month);

+ 1 qilish orqali odatdagi oy raqamini olamiz.

📅 Kun — getDate()

let day = now.getDate();

console.log(day);

getDate() → oyning nechanchi kuni ekanini qaytaradi.

🗓️ Hafta kuni — getDay()

⏳ getTime()

getTime() sana uchun millisekunddagi qiymatni qaytaradi.

console.log(time);
Bu qiymat yordamida Date'larni hisoblash va solishtirish juda qulay.

⏱️ Ikki sana orasidagi farq 

let date1 = new Date(
    "2026-08-10"
);

let date2 = new Date(
    "2026-08-15"
);


let difference =
    date2 - date1;


console.log(difference);

Natija millisekundlarda bo‘ladi.

📆 Kunlar farqini hisoblash 

let date1 = new Date(
    "2026-08-10"
);

let date2 = new Date(
    "2026-08-15"
);


let difference =
    date2 - date1;


let days =
    difference /
    (1000 * 60 * 60 * 24);


console.log(days);
5

🎂 Yoshni hisoblash 

let birthYear = 2008;

let currentYear =
    new Date().getFullYear();


let age =
    currentYear - birthYear;


console.log(age);
Bu oddiy yosh hisoblash usuli.

Tug‘ilgan kunning oy va kuni ham hisobga olinadigan aniq formula keyingi amaliyotlarda ko‘rib chiqilishi mumkin.

🕐 Digital Clock

Endi Date yordamida oddiy elektron soat yaratamiz.

        now.getHours();

    let minutes =
        now.getMinutes();

    let seconds =
        now.getSeconds();


    console.log(
        hours + ":" +
        minutes + ":" +
        seconds
    );

}


showTime();

🔥 00 format qilish 

function formatTime(value) {

    return String(value)
        .padStart(2, "0");

}


console.log(
    formatTime(5)
);
05

🔄 setInterval() bilan soat

Soatni har sekund yangilash uchun setInterval() ishlatamiz.

    showTime,

🕐 Real loyiha: Live Clock

function updateClock() {

    let now = new Date();


    let hours =
        String(
            now.getHours()
        ).padStart(2, "0");


    let minutes =
        String(
            now.getMinutes()
        ).padStart(2, "0");


    let seconds =
        String(
            now.getSeconds()
        ).padStart(2, "0");


    document.getElementById(
        "clock"
    ).textContent =
        hours + ":" +
        minutes + ":" +
        seconds;


    document.getElementById(
        "date"
    ).textContent =
        now.toLocaleDateString(
            "uz-UZ"
        );

}


updateClock();


setInterval(
    updateClock,
    1000
);
