Function asoslari

Function — JavaScript'dagi eng muhim tushunchalardan biridir.

Function yordamida ma'lum bir vazifani bajaradigan kodni bir joyga yozib, uni kerak bo‘lganda qayta-qayta ishlatishimiz mumkin.

Bugun function yaratish, uni chaqirish, parametrlar, argumentlar va return bilan ishlashni o‘rganamiz.

Function nima? 🤔

Function — ma'lum bir vazifani bajarish uchun yozilgan kodlar to‘plami.

Masalan, ekranga salom chiqaradigan function yaratishimiz mumkin. 

function salom() {

    console.log("Salom!");

}

Bu kod functionni yaratadi, lekin hali uni ishga tushirmaydi.

Functionni chaqirish 📞

Function ishlashi uchun uni chaqirish kerak. 

function salom() {

    console.log("Salom!");

}

salom();
Salom!

salom(); — functionni chaqirish hisoblanadi.

Function nega kerak? 🎯

Tasavvur qiling, bir xil kodni 10 marta ishlatishingiz kerak.

Function ishlatmasak, kodni 10 marta yozishga to‘g‘ri keladi.

Function bilan esa kodni bir marta yozamiz va kerakli joyda chaqiramiz. 

function salom() {

    console.log("Assalomu alaykum!");

}

salom();
salom();
salom();

Function sintaksisi 🧩 

function functionNomi() {

    // kodlar

}

Bu yerda:

function — function yaratish kalit so‘zi.

functionNomi — functionning nomi.

() — parametrlar yoziladigan joy.

{ } — function ichidagi kodlar.

Oddiy function misoli 💡 

function hello() {

    console.log("Hello World!");

}

hello();

Function nomini o‘zingiz mazmunli qilib tanlashingiz mumkin.

Masalan: 

function salomBer() {
    console.log("Salom!");
}

function xayr() {
    console.log("Xayr!");
}

salomBer();
xayr();

Parametr nima? 📦

Function tashqaridan ma'lumot qabul qilishi mumkin.

Function qavslarining ichida yozilgan o‘zgaruvchi parametr deyiladi. 

function salomBer(ism) {

    console.log("Salom, " + ism);

}

salomBer("Ali");
Salom, Ali

Argument nima? 🧠

Functionni chaqirganda parametrga berilgan haqiqiy qiymat argument deyiladi. 

function salomBer(ism) {

    console.log("Salom, " + ism);

}

salomBer("Ali");

Bu misolda:

ism — parametr.

"Ali" — argument.

Bir nechta parametrlar 🔢 

function tanishtir(ism, yosh) {

    console.log(
        "Mening ismim " + ism
    );

    console.log(
        "Men " + yosh + " yoshdaman"
    );

}

tanishtir("Ali", 15);
Mening ismim Ali
Men 15 yoshdaman

Matematik function ➕ 

function qoshish(a, b) {

    console.log(a + b);

}

qoshish(10, 20);

Bu function ikkita sonni qabul qilib, ularni qo‘shadi.

function ayirish(a, b) {

    console.log(a - b);

}

ayirish(20, 5);

Ko‘paytirish functioni ✖️ 

function kopaytirish(a, b) {

    console.log(a * b);

}

kopaytirish(5, 4);
20

Bo‘lish functioni ➗ 

function bolish(a, b) {

    console.log(a / b);

bolish(20, 4);

return nima? ↩️

return function ichidagi natijani tashqariga qaytaradi.

Bu functionning natijasini keyinchalik boshqa joyda ishlatish imkonini beradi. 

function qoshish(a, b) {

    return a + b;

}

let natija = qoshish(10, 20);

console.log(natija);
30

console.log va return farqi ⚖️

console.log() natijani Console'ga chiqaradi.

return esa natijani functiondan tashqariga qaytaradi. 

function test1() {

    console.log(10);

}

function test2() {

    return 20;

}

test1();

let result = test2();

console.log(result);

return functionni to‘xtatadi 🛑 

function test() {

    console.log("Birinchi");

    return;

    console.log("Ikkinchi");

}

test();
Birinchi

return bajarilgandan keyingi kod ishlamaydi.

Functiondan qiymat qaytarish 🎯 

function kvadrat(son) {

    return son * son;

}

let result = kvadrat(5);

console.log(result);
25

Natijani boshqa functionda ishlatish 🔗 

function qoshish(a, b) {

    return a + b;

}

function kopaytirish(a, b) {

    return a * b;

}

let result = kopaytirish(
    qoshish(2, 3),
    4
);

console.log(result);
20

Default parameter ⚙️

Agar argument berilmasa, parametrga oldindan qiymat berishimiz mumkin. 

function salom(ism = "Mehmon") {

    console.log("Salom, " + ism);

}

salom();

salom("Ali");
Salom, Mehmon
Salom, Ali

Function va if sharti 🔀 

function tekshir(yosh) {

    if (yosh >= 18) {

        return "Kirish mumkin";

    } else {

        return "Kirish mumkin emas";

    }

}

console.log(tekshir(20));
console.log(tekshir(15));

Bir function — bir vazifa 🎯

Yaxshi kod yozishda function imkon qadar bitta asosiy vazifani bajarishi ma'qul. 

function qoshish(a, b) {

    return a + b;

}

Bu function faqat ikkita sonni qo‘shish bilan shug‘ullanadi.

Amaliy loyiha: Kalkulyator 🧮 

function qoshish(a, b) {
    return a + b;
}

function ayirish(a, b) {
    return a - b;
}

function kopaytirish(a, b) {
    return a * b;
}

function bolish(a, b) {
    return a / b;
}

console.log(qoshish(10, 5));
console.log(ayirish(10, 5));
console.log(kopaytirish(10, 5));
console.log(bolish(10, 5));
15
5
50
2

Amaliy loyiha: Juft yoki toq 🔢 

function juftmi(son) {

    if (son % 2 === 0) {

        return "Juft son";

    }

    return "Toq son";

}

console.log(juftmi(10));
console.log(juftmi(7));
Juft son
Toq son

Amaliy loyiha: Eng katta son 🔎 

function kattaSon(a, b) {

    if (a > b) {

        return a;

    }

    return b;

}

console.log(kattaSon(20, 15));
20

Function va template literal 📝 

function tanishtir(ism, yosh) {

    return `Mening ismim ${ism}.

}

console.log(
    tanishtir("Ali", 16)

Functionda bir nechta return ⚡ 

function baho(score) {

    if (score >= 90) {
        return "A";
    }

    if (score >= 80) {
        return "B";
    }

    if (score >= 70) {
        return "C";
    }

    return "F";

}

console.log(baho(95));
console.log(baho(82));
console.log(baho(65));
A
B
F

Bugungi asosiy tushunchalar 🧠

⚙️ function — function yaratadi.

📞 functionName() — functionni chaqiradi.

📦 Parametr — function qabul qiladigan o‘zgaruvchi.

🎯 Argument — functionga beriladigan haqiqiy qiymat.

↩️ return — natijani functiondan qaytaradi.

🛑 return bajarilgandan keyingi function kodi ishlamaydi.

🔄 Functionni bir necha marta chaqirish mumkin.

Uyga vazifa 📝

1-vazifa:
salom() nomli function yarating va Console'ga "Salom, JavaScript!" chiqaring.

2-vazifa:
Ism qabul qiladigan function yarating.
Masalan: 

salom("Mirjamol");

Natija: 

Salom, Mirjamol!

3-vazifa:
Ikkita sonni qabul qilib, ularning yig‘indisini return qiladigan function yarating.

4-vazifa:
Sonning kvadratini qaytaradigan function yarating.

5-vazifa:
Son juft yoki toq ekanini aniqlaydigan function yarating.

6-vazifa:
Uchta son qabul qilib, eng kattasini qaytaradigan function yarating.

7-vazifa:
Ism va yosh qabul qiladigan function yarating va template literal yordamida ma'lumotni chiqaring.

8-vazifa:
Array qabul qilib, uning elementlarini Console'ga chiqaradigan function yarating.

9-vazifa:
1 dan 10 gacha sonlarni function yordamida chiqaring.

10-vazifa:
Oddiy kalkulyator uchun qoshish(), ayirish(), kopaytirish() va bolish() functionlarini yarating.
