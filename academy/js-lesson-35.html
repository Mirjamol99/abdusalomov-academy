concat()

34-darsda slice() va splice() yordamida Array ichidagi elementlar bilan ishlashni o‘rgandik.

Bugun esa bir nechta Array'ni bitta Array'ga birlashtirishni o‘rganamiz.

🔗 concat() nima?

concat() — bir nechta Array'ni birlashtirib, yangi Array qaytaradigan metod.

Eng muhim jihati:

concat() original Array'larni o‘zgartirmaydi. 

let fruits1 = [
    "Olma",
    "Banan"
];

let fruits2 = [
    "Uzum",
    "Anor"
];

let fruits = fruits1.concat(fruits2);

console.log(fruits);
[
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
]

🧩 concat() sintaksisi 

array1.concat(array2);

Bu yerda:

array1 — asosiy Array
array2 — qo‘shiladigan Array 

let a = [1, 2];

let b = [3, 4];

let result = a.concat(b);

console.log(result);
[1, 2, 3, 4]

➕ Bir nechta Array'ni birlashtirish

concat() faqat ikkita emas, bir nechta Array'ni ham birlashtira oladi. 

let a = [1, 2];

let b = [3, 4];

let c = [5, 6];

let result = a.concat(b, c);

console.log(result);
[
    1,
    2,
    3,
    4,
    5,
    6
]

let frontend = [

concat() yangi Array yaratadi.

Eski Array'lar esa o‘z holicha qoladi.

let all = first.concat(second);

console.log(all);

    "Husan"
]

]

🧠 concat() va push() farqi

concat()

Yangi Array qaytaradi.

Original Array o‘zgarmaydi.

push()

Original Array'ga element qo‘shadi.

Original Array o‘zgaradi.

⚖️ concat va push taqqoslash 

let a = [1, 2];

let b = [3, 4];

let result = a.concat(b);

console.log(result);

console.log(a);
result:

[1, 2, 3, 4]

a:

[1, 2]

Endi push() bilan: 

let a = [1, 2];

let b = [3, 4];

a.push(...b);

console.log(a);
[1, 2, 3, 4]

🔗 concat() va slice()

Bu ikki metodni birga ham ishlatish mumkin. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

let firstPart =
    fruits.slice(0, 2);

let secondPart =
    fruits.slice(2);

let result =
    firstPart.concat(secondPart);

console.log(result);
[
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
]

Bu yerda slice() qismlarni oldi, concat() esa ularni yana birlashtirdi.

🔢 concat() va length 

let a = [
    10,
    20,
    30
];

let b = [
    40,
    50
];

let result = a.concat(b);

console.log(result.length);
5

📋 concat() bilan nusxa olish

Bo‘sh Array bilan ham concat() ishlatish mumkin. 

let original = [
    1,
    2,
    3
];

let copy = [].concat(original);

console.log(copy);
[1, 2, 3]

🧠 concat() eslab qolish

🔗 concat() = birlashtirish

🔒 Original Array'lar o‘zgarmaydi.

⚠️ Muhim

let a = [1, 2];

let b = [3, 4];

let result = a.concat(b);

Chunki concat() yangi Array yaratadi.
