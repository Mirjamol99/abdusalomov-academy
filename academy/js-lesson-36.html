includes() va indexOf()

35-darsda concat() yordamida Array'larni birlashtirishni o‘rgandik.

Bugun esa Array ichidan kerakli elementni qidirishni o‘rganamiz.

🔎 includes() nima?

includes() — Array ichida ma'lum bir qiymat bor yoki yo‘qligini tekshiradi.

Natija doimo:

true yoki false bo‘ladi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(
    fruits.includes("Banan")
);
true

❌ Element mavjud bo‘lmasa 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(
    fruits.includes("Anor")
);
false

Chunki "Anor" Array ichida mavjud emas.

🧠 includes() qanday ishlaydi?

Array:

["Olma", "Banan", "Uzum"]

includes("Banan")

→ true ✅

includes("Anor")

→ false ❌

🔤 String bilan includes()

includes() faqat Array'da emas, String bilan ham ishlaydi. 

let name = "Mirjamol";

console.log(
    name.includes("jam")
);
true

Chunki "jam" String ichida mavjud.

⚠️ includes() katta-kichik harfga sezgir

JavaScript'da includes() katta va kichik harflarni farqlaydi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(
    fruits.includes("olma")
);
false

Array'da "Olma" bor, lekin "olma" boshqa qiymat.

🔢 Sonlar bilan includes() 

let numbers = [
    10,
    20,
    30,
    40
];

console.log(
    numbers.includes(30)
);

console.log(
    numbers.includes(50)
);
true

false

🔢 indexOf() nima?

indexOf() — Array ichidan berilgan elementni qidiradi va uning indexini qaytaradi.

Agar element topilmasa:

-1 qaytaradi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(
    fruits.indexOf("Banan")
);
1

🔢 indexlarni eslaymiz

0 → Olma

1 → Banan

2 → Uzum 

fruits.indexOf("Olma");
// 0

fruits.indexOf("Banan");
// 1

fruits.indexOf("Uzum");
// 2

❌ Element topilmasa 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(
    fruits.indexOf("Anor")
);
-1

-1 — qidirilgan element Array ichida yo‘qligini bildiradi.

🔁 Bir xil elementlar bo‘lsa

Agar Array'da bir xil qiymat bir necha marta bo‘lsa, indexOf() birinchi uchragan indexni qaytaradi. 

let numbers = [
    10,
    20,
    10,
    30
];

console.log(
    numbers.indexOf(10)
);
0

🔍 Oxirgi indexni topish

Agar bir xil elementning oxirgi uchragan indexini topmoqchi bo‘lsak, lastIndexOf() metodidan foydalanamiz. 

let numbers = [
    10,
    20,
    10,
    30
];

console.log(
    numbers.lastIndexOf(10)
);
2

⚖️ includes() va indexOf() farqi

Metod Natija Topilmasa
includes() true / false false
indexOf() index -1

🧠 Qaysi birini ishlatamiz?

includes()

Savol:

"Bu element bormi?"

Javob:
true / false

indexOf()

Savol:

"Bu element qaysi indexda?"

Javob:
index yoki -1

🛒 Real loyiha — mahsulot qidirish 

let products = [
    "Telefon",
    "Noutbuk",
    "Quloqchin",
    "Sichqoncha"
];

let product = "Noutbuk";

if (products.includes(product)) {

    console.log(
        "Mahsulot mavjud!"
    );

} else {

    console.log(
        "Mahsulot topilmadi!"
    );

}
Mahsulot mavjud!

🛒 indexOf() bilan mahsulot joylashuvi 

let products = [
    "Telefon",
    "Noutbuk",
    "Quloqchin",
    "Sichqoncha"
];

let index =
    products.indexOf("Quloqchin");

console.log(index);
2

Demak, "Quloqchin" Array'ning 2-indexida turibdi.

🔐 Login tizimida includes()

Masalan, saytda ruxsat berilgan rollar ro‘yxati mavjud. 

let roles = [
    "admin",
    "teacher",
    "student"
];

let userRole = "student";

if (roles.includes(userRole)) {

    console.log(
        "Ruxsat berildi!"
    );

} else {

    console.log(
        "Ruxsat yo‘q!"
    );

}
Ruxsat berildi!

🔎 indexOf() orqali tekshirish

Eski usullarda element borligini indexOf() bilan ham tekshirish mumkin. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

if (fruits.indexOf("Banan") !== -1) {

    console.log(
        "Banan mavjud!"
    );

} else {

    console.log(
        "Banan mavjud emas!"
    );

}

⚡ includes() bilan osonroq

Yuqoridagi vazifani includes() bilan qisqaroq yozish mumkin. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

if (fruits.includes("Banan")) {

    console.log(
        "Banan mavjud!"
    );

}
💡 Element faqat mavjud yoki yo‘qligini tekshirish kerak bo‘lsa, includes() juda qulay.

🧩 Amaliy misol 

let students = [
    "Ali",
    "Vali",
    "Hasan",
    "Husan"
];

let name = "Hasan";

let index =
    students.indexOf(name);


if (students.includes(name)) {

    console.log(
        name + " topildi!"
    );

    console.log(
        "Index:",
        index
    );

} else {

    console.log(
        name + " topilmadi!"
    );

}
Hasan topildi!

Index: 2

⚠️ Muhim: index 0 dan boshlanadi 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(
    fruits.indexOf("Olma")
);
0

0 chiqishi "topilmadi" degani emas.

0 — bu elementning birinchi indexi.

Faqat -1 chiqsa, element topilmagan bo‘ladi.
