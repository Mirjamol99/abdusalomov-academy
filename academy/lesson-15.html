Select va Option

HTML'da dropdown menyu yaratish va foydalanuvchiga variant tanlatishni o'rganamiz.

1. <select> nima?

<select> foydalanuvchiga bir nechta variant ichidan bittasini tanlash imkonini beradi. 

<select>

    <option>HTML</option>

    <option>CSS</option>

    <option>JavaScript</option>

</select>

2. <option>

<option> select ichidagi har bir tanlovni bildiradi. 

<select>

    <option>Frontend</option>

    <option>Backend</option>

    <option>Fullstack</option>

</select>

3. value atributi

value tanlangan optionning qiymatini belgilaydi. 

<select name="course">

    <option value="html">
        HTML
    </option>

    <option value="css">
        CSS
    </option>

    <option value="javascript">
        JavaScript
    </option>

</select>

4. selected

selected sahifa ochilganda qaysi option oldindan tanlangan bo'lishini belgilaydi. 

<select>

    <option>HTML</option>

    <option selected>
        CSS
    </option>

    <option>JavaScript</option>

</select>

5. disabled

disabled variantni tanlashni taqiqlaydi. 

<option disabled>
    Kursni tanlang
</option>

6. <optgroup>

<optgroup> optionlarni guruhlarga ajratish uchun ishlatiladi. 

<select>

    <optgroup label="Frontend">

        <option>HTML</option>

        <option>CSS</option>

        <option>JavaScript</option>

    </optgroup>


    <optgroup label="Backend">

        <option>Node.js</option>

        <option>Python</option>

    </optgroup>

</select>

7. name atributi

Form yuborilganda select qiymatini serverga yuborish uchun name ishlatiladi. 

<select name="course">

    <option value="html">
        HTML
    </option>

</select>
