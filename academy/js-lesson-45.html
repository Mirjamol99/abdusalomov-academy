Object asoslari

Bugungi darsda JavaScript'dagi Object tushunchasi bilan tanishamiz.

Object yordamida bir nechta ma'lumotlarni bitta o‘zgaruvchi ichida tartibli saqlash mumkin.

📦 Object nima?

Object — ma'lumotlarni key : value ko‘rinishida saqlaydigan JavaScript ma'lumot tuzilmasidir.

Masalan, bir odam haqida:

ismi, yoshi, shahri va kasbi kabi ma'lumotlarni bitta Object ichida saqlashimiz mumkin. 

let user = {
    name: "Ali",
    age: 18,
    city: "Andijon"
};

console.log(user);

🔑 Key va Value

Object ichidagi har bir ma'lumot key va value dan tashkil topadi. 

let user = {
    name: "Ali",
    age: 18
};

name: "Ali"

name → key

"Ali" → value

age: 18

age → key

18 → value

✍️ Object yaratish

Object yaratish uchun { } figurali qavslardan foydalanamiz. 

let car = {
    brand: "BMW",
    model: "M5",
    year: 2024
};

console.log(car);
Object ichidagi property'lar vergul , bilan ajratiladi.

🔍 Object property'ni olish

Object ichidagi qiymatni olishning eng oddiy usuli — nuqta . orqali murojaat qilish. 

let user = {
    name: "Ali",
    age: 18,
    city: "Andijon"
};

console.log(user.name);
console.log(user.age);
console.log(user.city);
Ali
18
Andijon

🧩 Bracket notation

Object property'lariga [] orqali ham murojaat qilish mumkin. 

let user = {
    name: "Ali",
    age: 18
};

console.log(user["name"]);
console.log(user["age"]);
Ikkalasi ham ishlaydi:

user.name
user["name"]

✏️ Object qiymatini o‘zgartirish

Object ichidagi mavjud qiymatni key orqali o‘zgartirish mumkin. 

let user = {
    name: "Ali",
    age: 18
};

user.age = 19;

console.log(user);
{
    name: "Ali",
    age: 19
}

➕ Object'ga yangi property qo‘shish 

let user = {
    name: "Ali",
    age: 18
};

user.city = "Andijon";

console.log(user);
{
    name: "Ali",
    age: 18,
    city: "Andijon"
}

❌ Property o‘chirish

Object ichidagi property'ni delete yordamida o‘chirish mumkin. 

let user = {
    name: "Ali",
    age: 18,
    city: "Andijon"
};

delete user.city;

console.log(user);
{
    name: "Ali",
    age: 18
}

📦 Object ichida Array

Object ichida Array ham saqlash mumkin. 

let student = {
    name: "Ali",

    subjects: [
        "Math",
        "English",
        "History"
    ]
};

console.log(student.subjects);
[
    "Math",
    "English",
    "History"
]

📦 Array ichida Object

Bu usul real loyihalarda juda ko‘p ishlatiladi. 

let users = [

    {
        name: "Ali",
        age: 18
    },

    {
        name: "Vali",
        age: 20
    },

    {
        name: "Hasan",
        age: 19
    }

];

console.log(users);
Bu — Objectlar Array'i.

Keyingi darslarda bunday ma'lumotlar bilan juda ko‘p ishlaymiz.

🧠 Object ichida Function

Object ichida function ham saqlash mumkin.

Object ichidagi function keyinchalik method deb ataladi. 

let user = {

    name: "Ali",

    sayHello: function() {
        console.log("Salom!");
    }

};

user.sayHello();

⚡ Shorthand property

Agar variable nomi va Object key bir xil bo‘lsa, qisqaroq yozish mumkin. 

let name = "Ali";
let age = 18;

let user = {
    name,
    age
};

console.log(user);
{
    name: "Ali",
    age: 18
}

🧩 Nested Object

Object ichida yana boshqa Object bo‘lishi mumkin. 

let user = {

    name: "Ali",

    address: {

        city: "Andijon",

        street: "Navoi"

    }

};

console.log(
    user.address.city
);
Andijon
