HTML Form 📝

Foydalanuvchidan ism, email, parol va boshqa ma'lumotlarni olish uchun formalar yaratishni o'rganamiz.

1. <form> nima?

<form> foydalanuvchidan ma'lumot olish uchun ishlatiladi. 

<form>

    <input type="text">

    <button>
        Yuborish
    </button>

</form>

2. <input> tegi

<input> foydalanuvchi ma'lumot kiritadigan maydon yaratadi. 

<input type="text">

3. input type

type input qanday ma'lumot qabul qilishini belgilaydi.

type="text"

Oddiy matn

type="email"

Email manzil

type="password"

Parol

type="number"

Raqam

type="date"

Sana

type="tel"

Telefon raqami

4. <label>

<label> input nima uchun ishlatilishini tushuntiruvchi yozuvdir. 

<label for="name">
    Ismingiz
</label>

<input
    type="text"
    id="name">

5. placeholder

placeholder input ichida foydalanuvchiga ko'rsatma beradi. 

<input
    type="text"
    placeholder="Ismingizni kiriting">

6. required

required inputni majburiy maydonga aylantiradi. 

<input
    type="text"
    required>

💡 required bo'lsa, foydalanuvchi maydonni to'ldirmasdan formani yubora olmaydi.
