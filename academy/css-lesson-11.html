CSS Position 📍

Elementlarni sahifada aniq joylashtirish, siljitish va ekranga biriktirishni o'rganamiz.

1. `position` nima?

CSS'dagi `position` xususiyati elementning sahifadagi joylashuvini boshqaradi. 

.box {
    position: relative;
}
CSS'da eng ko'p ishlatiladigan positionlar:

🔹 static
🔹 relative
🔹 absolute
🔹 fixed
🔹 sticky

2. `position: static`

Bu elementlarning standart holati. Odatda position yozilmasa ham `static` hisoblanadi. 

.box {
    position: static;
}
STATIC

3. `position: relative`

`relative` elementni o'zining normal joyiga nisbatan siljitish imkonini beradi. 

.box {
    position: relative;
    left: 30px;
}
Relative

4. `top`, `right`, `bottom`, `left`

Bu qiymatlar position berilgan elementni siljitish uchun ishlatiladi. 

.box {
    position: relative;

    top: 10px;
    left: 20px;
}
⬆️ `top`
➡️ `right`
⬇️ `bottom`
⬅️ `left`

5. `position: absolute`

`absolute` elementni eng yaqin position berilgan ota elementga nisbatan joylashtiradi. 

.parent {
    position: relative;
}

.child {
    position: absolute;

    top: 20px;
    right: 20px;
}
ABSOLUTE
Ota element

6. `position: fixed`

`fixed` elementni brauzer oynasiga biriktirib qo'yadi. Sahifa scroll qilinganda ham element joyida qoladi. 

.button {
    position: fixed;

    right: 20px;
    bottom: 20px;
}
💡 Masalan:

🔹 yuqoridagi navbar
🔹 chat tugmasi
🔹 "Yuqoriga" tugmasi

7. `position: sticky`

`sticky` element scroll vaqtida ma'lum joyga yetganda ekranga yopishib qoladi. 

.navbar {
    position: sticky;
    top: 0;
}
STICKY NAVBAR

Bu sticky elementning misoli.

8. `z-index`

`z-index` elementlarning ustma-ust kelganda qaysi biri yuqorida turishini belgilaydi. 

.box {
    position: relative;
    z-index: 10;
}
1
2
🔥 `z-index` katta bo'lgan element odatda ustki qatlamda turadi.
