Nested loop

Bugun JavaScript'da bir loop ichida boshqa loopdan foydalanishni o‘rganamiz.

Bunday loop Nested loop deb ataladi.

Nested looplar ayniqsa jadvallar, matritsalar, rasmlar, kombinatsiyalar va ko‘p qatorli ma'lumotlar bilan ishlaganda juda foydali.

Nested loop nima? 🤔

Nested loop — bu bir loop ichida boshqa loop joylashgan holat.

Masalan: 

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        console.log(i, j);

    }

}

Bu yerda tashqi for — birinchi loop.

Ichkaridagi for — ikkinchi loop.

Demak, bir loop ichida yana bir loop mavjud.

Oddiy nested loop 🔁 

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 2; j++) {

        console.log("i =", i, "j =", j);

    }

}
i = 1 j = 1
i = 1 j = 2

i = 2 j = 1
i = 2 j = 2

i = 3 j = 1
i = 3 j = 2

Tashqi loopning har bir aylanishida ichki loop to‘liq bajariladi.

Nested loop qanday ishlaydi? 🧠

Quyidagi kodni ko‘ramiz: 

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        console.log(j);

    }

}

i = 1 bo‘lganda ichki loop 3 marta ishlaydi.

Keyin i = 2 bo‘ladi va ichki loop yana 3 marta ishlaydi.

Keyin i = 3 bo‘ladi va ichki loop yana 3 marta ishlaydi.

Shuning uchun ichki loop jami 9 marta bajariladi.

Ko‘paytirish jadvali ✖️

Nested loop yordamida 1 dan 5 gacha bo‘lgan sonlarning ko‘paytirish jadvalini chiqarishimiz mumkin. 

for (let i = 1; i <= 5; i++) {

    for (let j = 1; j <= 10; j++) {

        console.log(
            i + " x " + j + " = " + i * j
        );

    }

}

Avval 1 sonining jadvali, keyin 2, 3, 4 va 5 sonlarining jadvali chiqariladi.

Ichma-ich for...of 🔁

Nested loop faqat oddiy for bilan emas, for...of bilan ham ishlaydi. 

let groups = [
    ["Ali", "Vali"],
    ["Hasan", "Husan"]
];

for (let group of groups) {

    for (let student of group) {

        console.log(student);

    }

}

break nested loopda 🛑

Nested loop ichida break ishlatilsa, odatda u joylashgan eng yaqin loopni to‘xtatadi. 

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        if (j === 2) {
            break;
        }

        console.log(i, j);

    }

}
1 1
2 1
3 1

break ichki loopni to‘xtatdi.

Tashqi loop esa o‘z ishini davom ettirdi.

continue nested loopda ⏭️ 

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        if (j === 2) {
            continue;
        }

        console.log(i, j);

    }

}
1 1
1 3

2 1
2 3

3 1
3 3

j === 2 bo‘lganda shu aylanish tashlab ketildi.

Lekin ichki loop davom etdi.

3 o‘lchamli nested loop 🔥

Nazariy jihatdan loop ichida yana loop va uning ichida yana loop bo‘lishi mumkin. 

for (let i = 1; i <= 2; i++) {

    for (let j = 1; j <= 2; j++) {

        for (let k = 1; k <= 2; k++) {

            console.log(i, j, k);

        }

    }

}

Bunday usuldan foydalanish mumkin, lekin looplar soni ko‘paygan sari kodning ishlash hajmi ham ortadi.

Nested loop qayerda ishlatiladi? 🎯

📊 Jadvallar bilan ishlashda.

🧩 Ikki o‘lchamli Arraylarda.

🎮 O‘yinlarda kataklar bilan ishlashda.

⭐ Turli shakllarni yaratishda.

🔢 Ko‘paytirish jadvallarida.

🔎 Ma'lumotlarni bir necha darajada qidirishda.

🧮 Matritsalar bilan ishlashda.

Muhim qoida ⚠️

Nested loopda har bir loopning o‘z o‘zgaruvchisi bo‘lishi mumkin. 

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        console.log(i, j);

    }

}

Bu yerda:

i — tashqi loop.
j — ichki loop.

Ularni bir-biridan farqlash kodni tushunishni osonlashtiradi.

Nested loopni tushunish usuli 🧠

Nested loopni tushunish uchun uni ikki qismga ajrating:

1. Tashqi loop
Necha marta qator yoki katta jarayon takrorlanishini belgilaydi.

2. Ichki loop
Har bir tashqi loop ichida necha marta amal bajarilishini belgilaydi.

Masalan:

5 ta qator × 5 ta ustun = 25 ta amal.

Xatolarga e'tibor bering ⚠️

Nested loop yozayotganda qavslarni to‘g‘ri yopish juda muhim. 

for (let i = 1; i <= 3; i++) {

    for (let j = 1; j <= 3; j++) {

        console.log(i, j);

    }

}

Har bir ochilgan { uchun mos yopiladigan } bo‘lishi kerak.

Shuningdek, ichki loopning shartini noto‘g‘ri yozish cheksiz loopga olib kelishi mumkin.
