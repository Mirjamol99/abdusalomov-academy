forEach()

36-darsda includes() va indexOf() yordamida Array ichidan ma'lumot qidirishni o‘rgandik.

Bugun esa Array ichidagi har bir element bilan ishlashni o‘rganamiz.

🔁 forEach() nima?

forEach() — Array ichidagi har bir element uchun berilgan funksiyani bir martadan bajaradi.

Masalan, Array'da 5 ta element bo‘lsa, forEach() funksiyani 5 marta ishga tushiradi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

fruits.forEach(function(fruit) {

    console.log(fruit);

});
Olma
Banan
Uzum

🧩 forEach() sintaksisi 

array.forEach(function(element) {

    // kod

});

Bu yerda element — Array'dagi hozirgi element. 

let names = [
    "Ali",
    "Vali",
    "Hasan"
];

names.forEach(function(name) {

    console.log(name);

});

🔢 forEach() va index

forEach() callback funksiyasiga ikkinchi parametr orqali elementning indexi ham keladi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

fruits.forEach(function(fruit, index) {

    console.log(index, fruit);

});
0 "Olma"
1 "Banan"
2 "Uzum"

📌 Element va index

0 → Olma

1 → Banan

2 → Uzum 

fruits.forEach(function(fruit, index) {

    console.log(
        "Index:",
        index
    );

    console.log(
        "Meva:",
        fruit
    );

});

⚡ Arrow Function bilan forEach()

Biz 28-darsda Arrow Function'ni o‘rgangan edik.

fruits.forEach((fruit) => {

    console.log(fruit);

});

    console.log(fruit)

Agar callback ichida faqat bitta amal bo‘lsa, uni yanada qisqa yozish mumkin.

🖥️ forEach() va DOM

Keyingi darslarda DOM bilan ishlaganimizda forEach() juda ko‘p kerak bo‘ladi.

Masalan, Array'dagi barcha mahsulotlarni HTML ichiga chiqarishimiz mumkin. 

let products = [
    "Telefon",
    "Noutbuk",
    "Quloqchin"
];

let list =
    document.getElementById("list");

products.forEach(function(product) {

    list.innerHTML +=
        `
  • ${product}
    • `;

});
    <ul id="list"></ul>

    Natijada Array'dagi har bir mahsulot HTML ro‘yxatiga qo‘shiladi.

    🔁 for loop va forEach()

    Ikkalasi ham Array elementlarini birma-bir ko‘rib chiqish uchun ishlatilishi mumkin. 

    let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

for (
    let i = 0;
    i < fruits.length;
    i++
) {

    console.log(fruits[i]);

}

    Xuddi shu ishni forEach() bilan qisqaroq yozish mumkin: 

    fruits.forEach(function(fruit) {

    console.log(fruit);

});

    ⚠️ forEach() nima qilmaydi?

    forEach() yangi Array yaratish uchun asosiy metod emas.

    Yangi Array olish uchun keyingi darslarda map()ni o‘rganamiz.

    forEach()ning asosiy vazifasi — har bir element ustida amal bajarish.

    🧠 Muhim qoida 

    let numbers = [10, 20, 30];

numbers.forEach(function(number, index) {

    console.log(number);
    console.log(index);

});

    number → hozirgi element

    index → hozirgi elementning indexi

    🔥 Eng ko‘p ishlatiladigan ko‘rinish 

    let users = [
    "Ali",
    "Vali",
    "Hasan"
];

users.forEach((user, index) => {

    console.log(
        `${index + 1}. ${user}`
    );

});
    1. Ali
2. Vali
3. Hasan

    🧩 Array ichidagi Object'lar
