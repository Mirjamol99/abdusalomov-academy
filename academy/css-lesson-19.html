CSS Responsive Design 📱💻

Saytni telefon, planshet va kompyuter ekranlariga moslashtirishni o'rganamiz.

1. Responsive Design nima?

Responsive Design — saytning turli ekran o'lchamlarida chiroyli va qulay ko'rinishini ta'minlash.

Masalan:

📱 Telefon
📲 Planshet
💻 Noutbuk
🖥️ Kompyuter

2. Viewport

Responsive saytlar uchun HTML'da viewport meta tegi juda muhim. 

<meta
    name="viewport"
    content="width=device-width,
    initial-scale=1.0"
>
💡 Bu kod sahifaning qurilma ekraniga mos ravishda ishlashiga yordam beradi.

3. `@media`

`@media` orqali ekran o'lchamiga qarab turli CSS qoidalarini yozish mumkin. 

@media (max-width: 768px) {

    .box {
        font-size: 18px;
    }

}
📱 Ekran kengligi 768px yoki undan kichik bo'lsa, ichidagi CSS ishlaydi.

4. `max-width`

`max-width` belgilangan o'lchamdan kichik yoki teng ekranlarda CSS qoidalarini qo'llash uchun ishlatiladi. 

@media (max-width: 600px) {

    .title {
        font-size: 28px;
    }

}

5. `min-width`

`min-width` esa ma'lum o'lchamdan katta ekranlarda CSS qo'llash uchun ishlatiladi. 

@media (min-width: 768px) {

    .box {
        padding: 40px;
    }

}

6. Responsive Grid

Grid yordamida desktopda 3 ta card, telefonda esa 1 ta card chiqarish mumkin. 

.cards {
    display: grid;
    grid-template-columns:
        repeat(3, 1fr);
}

@media (max-width: 700px) {

    .cards {
        grid-template-columns: 1fr;
    }

}

7. Responsive Flexbox

Flexbox yordamida ham mobil ekran uchun layoutni o'zgartirish mumkin. 

.menu {
    display: flex;
    gap: 20px;
}

@media (max-width: 600px) {

    .menu {
        flex-direction: column;
    }

}

8. Responsive Font

Mobil qurilmalarda katta sarlavhalarni kichraytirish mumkin. 

.title {
    font-size: 50px;
}

@media (max-width: 600px) {

    .title {
        font-size: 32px;
    }

}

9. Responsive Image

Rasm ekran chegarasidan chiqib ketmasligi uchun ko'pincha `max-width: 100%` ishlatiladi. 

img {
    max-width: 100%;
    height: auto;
}
