CSS Selectors 🎯

CSS selectorlar yordamida HTML elementlarini tanlash va ularga style berishni o'rganamiz.

1. Selector nima?

Selector — CSS qaysi HTML elementga style berishini ko'rsatadi.

💡 Oddiy qilib:

Selector = "Qaysi elementni bezaymiz?" 
p {
    color: blue;
}

Bu misolda p selector hisoblanadi.

2. Element Selector

HTML tegining nomini yozib, shu turdagi barcha elementlarni tanlashimiz mumkin. 

h1 {
    color: blue;
}

p {
    color: gray;
}

Bu H3 elementi

Bu P elementi.

📌 Masalan: p yozsak, barcha <p> elementlari tanlanadi.

3. Class Selector `.class`

Class selector . belgisi bilan yoziladi. 

<p class="text">
    Salom!
</p>

.text {
    color: blue;
    font-size: 25px;
}

Class selector ishladi! 🚀

💡 Bir xil classni bir nechta HTML elementida ishlatish mumkin.

4. ID Selector `#id`

ID selector # belgisi bilan yoziladi. 

<h1 id="title">
    Abdusalomov Academy
</h1>

#title {
    color: cyan;
}

ID Selector

⚠️ Odatda bir sahifada bir xil ID ni takrorlamaslik kerak.

5. Universal Selector `*`

* belgisi barcha elementlarni tanlash uchun ishlatiladi. 

* {
    box-sizing: border-box;
}
💡 `*` = barcha HTML elementlar.

6. Bir nechta selector

Bir xil CSS kodini bir nechta elementga berish uchun selectorlarni vergul bilan ajratamiz. 

h1,
h2,
p {
    color: white;
}
📌 Bu yerda h1 , h2 va p bir xil style oladi.

7. Class va ID farqi

🟦

Class

CSS: 

.card {
    color: blue;
}

Bir nechta elementga berish mumkin.

🟪

ID

CSS: 

#title {
    color: blue;
}

Odatda yagona element uchun ishlatiladi.

8. Amaliy loyiha 💻

Endi class selector yordamida kichik card yaratamiz. 

<div class="card">

    <h2>
        Abdusalomov Academy
    </h2>

    <p>
        CSS Selectors
    </p>

</div>


.card {
    background: rgba(15, 23, 42, .72);
    padding: 30px;
    border-radius: 20px;
}

.card h2 {
    color: #22d3ee;
}

.card p {
    color: #94a3b8;
}
