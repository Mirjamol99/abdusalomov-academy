Textarea

Foydalanuvchidan uzun matn, izoh, fikr yoki xabar olishni o'rganamiz.

1. <textarea> nima?

<textarea> foydalanuvchidan bir nechta qator matn olish uchun ishlatiladi.

Masalan: izoh, fikr-mulohaza, xabar yoki savol yozish. 

<textarea></textarea>

2. rows atributi

rows textarea balandligini, ya'ni nechta qator ko'rinishini belgilaydi. 

<textarea rows="5"></textarea>

3. cols atributi

cols textarea kengligini belgilash uchun ishlatiladi. 

<textarea
    rows="5"
    cols="30">
</textarea>

Hozirgi zamonaviy saytlarda kenglikni ko'pincha CSS orqali berish tavsiya qilinadi.

4. placeholder

placeholder foydalanuvchiga textarea ichida qanday ma'lumot yozish kerakligini ko'rsatadi. 

<textarea
    placeholder="Fikringizni yozing...">
</textarea>

5. required

required textarea bo'sh qoldirilsa, form yuborilmasligini ta'minlaydi. 

<textarea
    required>
</textarea>

6. disabled

disabled textarea bilan ishlashni vaqtincha taqiqlaydi. 

<textarea disabled>

Bu maydon ishlamaydi.

</textarea>

7. name atributi

Form yuborilganda textarea ma'lumotini serverga yuborish uchun name atributidan foydalaniladi. 

<textarea
    name="message"
    placeholder="Xabar yozing...">
</textarea>

Amaliy misol 🚀

Quyidagi maydonga yozing. Belgilar soni avtomatik hisoblanadi.
