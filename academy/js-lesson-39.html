filter()

filter() — Array ichidan berilgan shartga mos keladigan elementlarni tanlab olib, yangi Array qaytaradi.

Masalan:

[1, 2, 3, 4, 5, 6] ichidan faqat juft sonlarni olishimiz mumkin.

🔎 filter() nima?

filter() Array'dagi elementlarni birma-bir tekshiradi.

Agar shart true bo‘lsa, element yangi Array'ga qo‘shiladi.

Agar shart false bo‘lsa, element olinmaydi. 

let numbers = [
    1,
    2,
    3,
    4,
    5,
    6
];

let evenNumbers = numbers.filter(
    function(number) {

        return number % 2 === 0;

    }
);

console.log(evenNumbers);
[2, 4, 6]

🧠 filter() qanday ishlaydi?

Boshlang‘ich Array:

[1, 2, 3, 4, 5, 6]

↓

Shart:

number % 2 === 0

↓

Mos kelganlar:

[2, 4, 6]

📌 filter() sintaksisi 

let newArray = array.filter(
    function(element) {

        return shart;

    }
);

filter() callback funksiyasidan true yoki false kutadi.

true → element olinadi.
false → element olinmaydi.

🔍 Bir nechta shart

Bir vaqtning o‘zida bir nechta shartdan foydalanish mumkin.

Buning uchun && ishlatamiz. 

let users = [
    {
        name: "Ali",
        age: 20
    },
    {
        name: "Vali",
        age: 16
    },
    {
        name: "Hasan",
        age: 25
    }
];

let result = users.filter(
    user =>
        user.age >= 18 &&
        user.age <= 22
);

console.log(result);
[
    {
        name: "Ali",
        age: 20
    }
]

🧩 filter() va map() birga

`filter()` va `map()`ni ketma-ket ishlatish juda kuchli usul.

Avval kerakli elementlarni tanlaymiz, keyin ularni o‘zgartiramiz. 

let numbers = [
    1,
    2,
    3,
    4,
    5,
    6
];

let result = numbers
    .filter(number => number % 2 === 0)
    .map(number => number * 10);

console.log(result);
[20, 40, 60]

    ⚖️ filter() va map() farqi

    filter()

    Kerakli elementlarni tanlab oladi. 

    [1, 2, 3, 4]
      ↓
   filter
      ↓
[2, 4]

    map()

    Elementlarni o‘zgartiradi. 

    [1, 2, 3, 4]
      ↓
     map
      ↓
[2, 4, 6, 8]

    🧠 filter() va forEach() farqi

    forEach() — Array elementlarini ko‘rib chiqadi va amal bajaradi.

    filter() — shartga mos elementlardan yangi Array yaratadi. 

    let numbers = [1, 2, 3, 4];

numbers.forEach(number => {
    console.log(number);
});


let evenNumbers = numbers.filter(
    number => number % 2 === 0
);

console.log(evenNumbers);

    ⚠️ Muhim

    filter() original Array'ni odatda o‘zgartirmaydi.

    U yangi Array qaytaradi.

    Agar hech qanday element shartga mos kelmasa, natija [] bo‘ladi. 

    let numbers = [1, 2, 3];

let result = numbers.filter(
    number => number > 100
);

console.log(result);
    []
