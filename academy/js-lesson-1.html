Birinchi JavaScript kodingiz 👨‍💻

JavaScript kodini brauzer Console'ida ishga tushirishimiz mumkin. 

console.log("Salom, JavaScript!");

JavaScript qayerda yoziladi?

JavaScript'ni HTML ichida <script> tegi yordamida yozish mumkin. 

<script>

    console.log("Hello World");

</script>

Alohida JavaScript fayli

Katta loyihalarda JavaScript kodini alohida .js faylga yozish qulay. 

<script src="script.js"></script>

Masalan: script.js

Mini topshiriq 🧠
