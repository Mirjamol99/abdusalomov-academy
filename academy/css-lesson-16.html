CSS Position 📍

Elementlarni sahifada aniq joylashtirish uchun position, top, right, bottom va left xususiyatlarini o'rganamiz.

1. `position` nima?

`position` CSS elementi sahifada qanday joylashishini boshqaradi.

Eng ko'p ishlatiladigan qiymatlar:

static Oddiy joylashuv
relative O'z joyiga nisbatan
absolute Parentga nisbatan
fixed Ekranga biriktiriladi
sticky Scroll paytida yopishib qoladi

2. `position: static`

Bu elementlarning standart holati. Element oddiy tartibda joylashadi. 

.box {
    position: static;
}

3. `position: relative`

`relative` elementni o'zining boshlang'ich joyiga nisbatan siljitish imkonini beradi. 

.box {
    position: relative;
    top: 20px;
    left: 20px;
}
Normal
Relative

4. `top`, `right`, `bottom`, `left`

Bu xususiyatlar position bilan birga elementning joylashuvini o'zgartiradi. 

.box {
    position: relative;

    top: 20px;
    left: 30px;
}
⬆️ `top` — yuqoridan
➡️ `right` — o'ngdan
⬇️ `bottom` — pastdan
⬅️ `left` — chapdan

5. `position: absolute`

`absolute` elementni odatda position berilgan parent elementga nisbatan joylashtiradi. 

.parent {
    position: relative;
}

.child {
    position: absolute;

    top: 10px;
    right: 10px;
}
Parent
Child

6. `position: fixed`

`fixed` elementni brauzer oynasiga biriktirib qo'yadi.

Sahifani scroll qilsangiz ham element o'z joyida qoladi. 

.button {
    position: fixed;

    right: 20px;
    bottom: 20px;
}
💡 Masalan:

Chat tugmasi, "Yuqoriga" tugmasi yoki yordamchi tugmalar uchun ishlatiladi.

7. `position: sticky`

`sticky` element scroll paytida ma'lum joyga kelganda yopishib qoladi. 

.menu {
    position: sticky;
    top: 0;
}
STICKY MENU

Sticky element sahifa scroll qilinganda yuqorida qolishi mumkin.

8. `z-index`

Bir nechta positionlangan element ustma-ust kelganda, qaysi biri yuqorida turishini `z-index` belgilaydi. 

.box {
    position: absolute;
    z-index: 10;
}
