CSS Animations & Transitions ✨

Sayt elementlariga chiroyli harakat, animatsiya va yumshoq o'tish effektlarini qo'shishni o'rganamiz.

1. CSS Transition nima?

`transition` elementdagi o'zgarishlarni birdaniga emas, silliq tarzda amalga oshirish uchun ishlatiladi. 

.button {
    transition: 0.3s;
}

.button:hover {
    transform: scale(1.05);
}
Hover qiling 👆

2. `transform`

`transform` yordamida elementni kattalashtirish, kichraytirish, aylantirish yoki siljitish mumkin. 

.box:hover {
    transform: scale(1.1);
}
Hover qiling

3. `translate`

`translate` elementni X yoki Y yo'nalishida siljitadi. 

.box:hover {
    transform: translateY(-10px);
}
Tepaga ko'tarilaman 🚀

4. `rotate`

`rotate()` elementni aylantirish uchun ishlatiladi. 

.box:hover {
    transform: rotate(10deg);
}
🔄

5. `@keyframes`

`@keyframes` yordamida o'zimizning CSS animatsiyamizni yaratamiz. 

@keyframes move {

    from {
        transform: translateX(0);
    }

    to {
        transform: translateX(200px);
    }

}

6. `animation`

Yaratilgan `@keyframes` animatsiyasini elementga `animation` orqali beramiz. 

.box {
    animation:
        move 2s infinite alternate;
}
🚀

7. `animation-duration`

Animatsiyaning qancha vaqt davom etishini `animation-duration` bilan belgilaymiz. 

.box {
    animation-duration: 2s;
}

8. `animation-iteration-count`

Animatsiya necha marta takrorlanishini belgilaydi. 

.box {
    animation-iteration-count: infinite;
}
❤️

9. Amaliy loyiha 💻

Endi transition va animation yordamida zamonaviy kurs kartasini yaratamiz.
