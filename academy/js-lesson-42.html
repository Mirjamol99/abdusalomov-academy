some() va every()

Bugungi darsda JavaScript Array'laridagi some() va every() metodlarini o‘rganamiz.

Bu metodlar Array ichidagi elementlarni tekshirish uchun ishlatiladi va true yoki false qaytaradi.

☑️ some() nima?

some() Array ichida berilgan shartga mos keladigan kamida bitta element borligini tekshiradi.

Agar hech bo‘lmaganda bitta element shartni bajarsa, natija true bo‘ladi.

Aks holda false qaytaradi. 

let numbers = [10, 20, 30, 40];

let result = numbers.some(
    number => number > 30
);

console.log(result);
true
Chunki Array ichida 30 dan katta bo‘lgan son bor:

40 > 30 → true

🔍 some() qanday ishlaydi?

[10, 20, 30, 40]

↓

Har bir element tekshiriladi

↓

Bittasi mos kelsa → true

❌ some() false qaytarishi 

let numbers = [10, 20, 30];

let result = numbers.some(
    number => number > 50
);

console.log(result);
false
Chunki Array ichida 50 dan katta hech qanday son yo‘q.

☑️ every() nima?

every() Array ichidagi barcha elementlar berilgan shartni bajarayotganini tekshiradi.

Agar barcha elementlar shartni bajarsa, true qaytaradi.

Agar hatto bitta element shartni bajarmasa, false qaytaradi. 

let numbers = [10, 20, 30, 40];

let result = numbers.every(
    number => number > 5
);

console.log(result);
true
Barcha sonlar 5 dan katta:

10 > 5 ✅
20 > 5 ✅
30 > 5 ✅
40 > 5 ✅

❌ every() false qaytarishi 

let numbers = [10, 20, 3, 40];

let result = numbers.every(
    number => number > 5
);

console.log(result);
false
Chunki 3 > 5 noto‘g‘ri.

Bitta element shartni bajarmagani uchun every() false qaytaradi.

🆚 some() va every()

some()

Kamida bitta element shartni bajarsa:

true

every()

Barcha elementlar shartni bajarsa:

true

🧠 Yodda saqla:

some() → kamida bittasi

every() → hammasi

🔢 Sonlar bilan some() 

let numbers = [5, 12, 18, 25];

let result = numbers.some(
    number => number % 2 === 0
);

console.log(result);
true

Chunki Array ichida juft sonlar bor: 12 va 18.

🔢 Sonlar bilan every() 

let numbers = [2, 4, 6, 8];

let result = numbers.every(
    number => number % 2 === 0
);

console.log(result);
true
Barcha sonlar juft.

🛒 Cart bilan some()

Masalan, savatchada 100 000 so‘mdan qimmat mahsulot bor-yo‘qligini tekshiramiz.

        name: "Pizza",
        price: 50000
    },

    {
        name: "Burger",
        price: 120000
    },

    {
        name: "Cola",
        price: 15000

true

Demak, 100 000 so‘mdan qimmat mahsulot mavjud.

🆚 some(), every(), filter()

some()

Kamida bittasini tekshiradi.

true / false

every()

Hammasini tekshiradi.

true / false

filter()

Mos elementlarni qaytaradi.

Array

📚 Sintaksis 

array.some(
    element => shart
);
array.every(
    element => shart
);
Ikkala metod ham true yoki false qaytaradi.

🔥 Real loyiha misoli

Masalan, internet-do‘konda mahsulotlarning barchasi mavjudligini tekshiramiz. 

let products = [

    {
        name: "Pizza",
        available: true
    },

    {
        name: "Burger",
        available: true
    },

    {
        name: "Cola",
        available: false

let allAvailable = products.every(
    product => product.available

false

Shuning uchun barcha mahsulotlar mavjud emas → false.
