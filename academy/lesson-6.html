HTML'da rasmlar

Bugun HTML sahifaga rasm qo'shishni va <img> tegidan foydalanishni o'rganamiz.

1. <img> tegi nima?

HTML'da sahifaga rasm joylashtirish uchun <img> tegi ishlatiladi.

Rasmning manzili src atributi orqali beriladi.

Asosiy ko'rinishi 

<img src="rasm.jpg" alt="Rasm">

2. src atributi

src — rasm qayerda joylashganini ko'rsatadi. 

<img src="images/photo.jpg">

Agar rasm images papkasida bo'lsa, shu tarzda yozamiz.

3. alt atributi

alt — rasm haqida qisqacha ma'lumot beradi. 

<img
    src="images/photo.jpg"
    alt="Kompyuter rasmi"
>

Agar rasm yuklanmasa, alt ichidagi matn foydalanuvchiga ko'rinishi mumkin.

4. width va height

Rasmning kengligi va balandligini width va height bilan belgilash mumkin. 

<img
    src="photo.jpg"
    alt="Tabiat rasmi"
    width="400"
    height="250"
>

5. Kompyuterdagi rasmni qo'yish

Masalan, loyihamizda images degan papka yaratamiz. 


Abdusalomov-Academy/
│
├── index.html
├── lesson-6.html
│
└── images/
    └── photo.jpg

Keyin HTML'da: 

<img
    src="images/photo.jpg"
    alt="Mening rasmim"
>

6. Internetdagi rasm

Rasmning internetdagi manzilini src ichiga yozish ham mumkin. 

<img
    src="https://example.com/photo.jpg"
    alt="Internetdagi rasm"
>

7. Rasmni chiroyli qilish

CSS yordamida rasmga border-radius, width va boshqa xususiyatlarni berish mumkin. 

<img
    src="photo.jpg"
    alt="Rasm"
    class="w-64 rounded-2xl"
>

Eslab qolamiz 🧠

<img>

Sahifaga rasm qo'shadi.

src

Rasm manzilini ko'rsatadi.

alt

Rasm haqida matn beradi.

width / height

Rasm o'lchamini belgilaydi.
