10-DARS

HTML Form va Inputlar

Bugun foydalanuvchidan ma'lumot olish uchun HTML formalar yaratishni o'rganamiz.

1. <form> nima?

<form> foydalanuvchidan ma'lumot olish uchun forma yaratadi.

Masalan: ism, email, parol va boshqa ma'lumotlarni kiritish mumkin. 

<form>

    ...

</form>

2. <input> nima?

<input> foydalanuvchi ma'lumot kiritadigan maydon yaratadi. 

<input type="text">

3. type="text"

Matn kiritish uchun ishlatiladi. 

<input type="text"
       placeholder="Ismingizni kiriting">

4. type="email"

Email manzil kiritish uchun ishlatiladi. 

<input type="email"
       placeholder="Emailingiz">

5. type="password"

Parol kiritish uchun ishlatiladi. Kiritilgan belgilar yashiriladi. 

<input type="password"
       placeholder="Parol">

6. type="number"

Raqam kiritish uchun ishlatiladi. 

<input type="number"
       placeholder="Yoshingiz">

7. <label>

<label> input uchun tushuntiruvchi nom beradi. 

<label>Ismingiz</label>

<input type="text">

8. placeholder

placeholder input ichida foydalanuvchiga ko'rsatma beradi. 

<input
    type="text"
    placeholder="Ismingizni kiriting">

9. type="submit"

Formadagi ma'lumotlarni yuborish uchun ishlatiladi. 

<input type="submit"
       value="Yuborish">
