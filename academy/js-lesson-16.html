if sharti

if JavaScript'dagi eng muhim shart operatorlaridan biridir.

U ma'lum bir shartni tekshiradi. Agar shart true bo‘lsa, uning ichidagi kod bajariladi.

if nima? 🤔

if ingliz tilida "agar" degan ma'noni anglatadi.

Dasturlashda esa:

Agar shart to‘g‘ri bo‘lsa, ushbu kodni bajar.

if sintaksisi 📚 

if (shart) {
    // bajariladigan kod
}

if dan keyin qavs () ichida shart yoziladi.

Shart true bo‘lsa, jingalak qavs { } ichidagi kod bajariladi.

Oddiy if misoli 

let age = 18;

if (age >= 18) {
    console.log("Siz voyaga yetgansiz");
}
Siz voyaga yetgansiz

Chunki:

18 >= 18 → true

Shuning uchun if ichidagi kod bajariladi.

Agar shart false bo‘lsa ❌ 

let age = 15;

if (age >= 18) {
    console.log("Siz voyaga yetgansiz");
}

Bu safar:

15 >= 18 → false

Shuning uchun if ichidagi kod bajarilmaydi.

Console'da hech narsa chiqmaydi.

Comparison operator bilan if ⚖️ 

let number = 10;

if (number > 5) {
    console.log("10 soni 5 dan katta");
}
10 soni 5 dan katta

== bilan if 

let password = 1234;

if (password == 1234) {
    console.log("Parol to‘g‘ri");
}
Parol to‘g‘ri

=== bilan if 🔒

Amaliy dasturlashda ko‘pincha qat'iy tenglik operatori === ishlatiladi. 

let username = "admin";

if (username === "admin") {
    console.log("Xush kelibsiz!");
}
Xush kelibsiz!

if va Boolean 🧠

if Boolean qiymatlar bilan ham ishlaydi. 

let isLogin = true;

if (isLogin) {
    console.log("Siz tizimga kirdingiz");
}
Siz tizimga kirdingiz

if va ! operatori 

let isLogin = false;

if (!isLogin) {
    console.log("Iltimos, tizimga kiring");
}
Iltimos, tizimga kiring

Chunki:

!false → true

&& bilan if 🔥

Bir nechta shartni birlashtirish uchun && ishlatishimiz mumkin. 

let age = 20;
let hasTicket = true;

if (age >= 18 && hasTicket) {
    console.log("Kirish mumkin");
}
Kirish mumkin

|| bilan if 

let age = 16;
let permission = true;

if (age >= 18 || permission) {
    console.log("Kirish mumkin");
}
Kirish mumkin

Chunki shartlardan kamida bittasi true.

Balansni tekshirish 💰 

let balance = 50000;
let price = 30000;

if (balance >= price) {
    console.log("Xarid qilish mumkin");
}
Xarid qilish mumkin

if bilan bir nechta kod

{ } ichiga bir nechta kod yozishimiz mumkin. 

let age = 20;

if (age >= 18) {

    console.log("Yosh mos");

    console.log("Kirish mumkin");

    console.log("Xush kelibsiz!");

}

if ichida o‘zgaruvchi 

let score = 90;

if (score >= 70) {
    console.log("Imtihondan o'tdingiz");
}
Imtihondan o'tdingiz

if va comparison operatorlar 

let temperature = 30;

if (temperature > 25) {
    console.log("Havo issiq");
}
Havo issiq

if qanday ishlaydi? 🔍

JavaScript quyidagi tartibda ishlaydi:

1. Shartni tekshiradi.
2. Natija true yoki false bo‘ladi.
3. Agar true bo‘lsa, kod bajariladi.
4. Agar false bo‘lsa, kod o'tkazib yuboriladi.

Amaliy mashq 🔥

Quyidagi kodlarni ishga tushirishdan oldin natijani taxmin qiling. 

let age = 20;

if (age >= 18) {
    console.log("1");
}
let number = 3;

if (number > 5) {
    console.log("2");
}
let isStudent = true;

if (isStudent) {
    console.log("3");
}

Amaliy loyiha 🔐

Foydalanuvchining login qilganini tekshiramiz. 

let isLogin = true;

if (isLogin) {
    console.log("Profilga xush kelibsiz!");
}
Profilga xush kelibsiz!

Uyga vazifa 📝

1-vazifa:
age o‘zgaruvchisini yarating. Agar yosh 18 yoki undan katta bo‘lsa, "Kirish mumkin" chiqaring.

2-vazifa:
number yarating. Agar son 10 dan katta bo‘lsa, xabar chiqaring.

3-vazifa:
isLogin = true yarating. Agar foydalanuvchi login qilgan bo‘lsa, "Xush kelibsiz!" chiqaring.

4-vazifa:
balance va price yarating. Agar balans mahsulot narxidan katta yoki teng bo‘lsa, "Xarid qilish mumkin" chiqaring.

5-vazifa:
age va hasTicket yordamida && bilan shart yarating.

Bugungi darsni eslab qoling 🎯

❓ if — shartni tekshiradi.

✅ true bo‘lsa, ichidagi kod bajariladi.

❌ false bo‘lsa, ichidagi kod bajarilmaydi.

⚖️ if comparison operatorlar bilan ishlaydi.

🧠 &&, || va ! bilan murakkab shartlar yaratish mumkin.
