map()

map() — Array'dagi har bir elementni qayta ishlab, natijada yangi Array yaratadigan metod.

Eng muhim jihati:

map() → yangi Array qaytaradi.

🗺️ map() nima?

map() Array ichidagi har bir elementni bittadan olib, callback funksiyani bajaradi.

Callback'dan qaytgan qiymatlarning barchasi yangi Array ichiga yig‘iladi. 

let numbers = [
    1,
    2,
    3,
    4
];

let result = numbers.map(function(number) {

    return number * 2;

});

console.log(result);
[2, 4, 6, 8]

🔄 map() qanday ishlaydi?

Boshlang‘ich Array:

[1, 2, 3, 4]

↓

Har bir elementga:

× 2

↓

Yangi Array:

[2, 4, 6, 8]

📌 map() sintaksisi 

let newArray = array.map(function(element) {

    return yangiQiymat;

});

Bu yerda return juda muhim.

Chunki map() har bir callback'dan qaytgan qiymatni yangi Array'ga qo‘shadi.

🔢 Sonlarni 2 ga ko‘paytirish 

let numbers = [
    5,
    10,
    15,
    20
];

let doubled = numbers.map(function(number) {

    return number * 2;

});

console.log(doubled);
[10, 20, 30, 40]

🔤 String bilan map()

Stringlardan iborat Array'dagi elementlarni ham o‘zgartirish mumkin. 

let names = [
    "ali",
    "vali",
    "hasan"
];

let upperNames = names.map(
    (name) => name.toUpperCase()
);

console.log(upperNames);
[
    "ALI",
    "VALI",
    "HASAN"
]

🔢 map() va index

map() callback'iga ham forEach() kabi ikkinchi parametr orqali index keladi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

let result = fruits.map(
    (fruit, index) => {

        return `${index}: ${fruit}`;

    }
);

console.log(result);
[
    "0: Olma",
    "1: Banan",
    "2: Uzum"
]

🧠 map() va forEach() farqi

forEach()

Asosan har bir element ustida amal bajaradi.

Odatda yangi Array qaytarish uchun ishlatilmaydi.

map()

Har bir elementni o‘zgartirib, yangi Array qaytaradi.

💡 Esda tuting:

forEach() → bajaradi
map() → o‘zgartirib, yangi Array yaratadi

💰 Narxlarni o‘zgartirish

Masalan, mahsulotlarning narxiga 10% qo‘shmoqchimiz.

    (price) => price * 1.1
);

🎯 Object'dan yangi ma'lumot yaratish 

let users = [
    {
        name: "Ali",
        age: 18
    },
    {
        name: "Vali",
        age: 19
    }
];

let result = users.map(
    (user) => {

        return {
            name: user.name,
            age: user.age,
            student: true
        };

    }
);

console.log(result);

Bu usul orqali mavjud ma'lumotlardan kerakli yangi Object yaratish mumkin.

    🔗 map() natijasini join() bilan birlashtirish

    `map()` yangi Array qaytargani uchun keyinchalik boshqa Array metodlari bilan birga ishlatish mumkin. 

    let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

let html = fruits.map(
    fruit => `
  • ${fruit}
    • `
);

let result = html.join("");

console.log(result);

    ⚠️ returnni unutmaslik

    Agar `{ }` ishlatsangiz, qiymatni return qilish kerak. 

    let numbers = [1, 2, 3];

let result = numbers.map((number) => {

    return number * 2;

});

console.log(result);
    ⚠️ Agar return yozilmasa, callback'dan qiymat qaytmaydi va natijada undefined qiymatlar hosil bo‘lishi mumkin.

    ✨ returnni qisqartirish

    Arrow Function'da qavs ishlatilmasa, return avtomatik bo‘ladi. 

    let numbers = [1, 2, 3];

let result = numbers.map(
    number => number * 2
);

    Bu quyidagiga teng: 

    let result = numbers.map(
    number => {

        return number * 2;

    }
);
