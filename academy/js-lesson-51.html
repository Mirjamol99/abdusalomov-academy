Math object

Bugungi darsda JavaScript'dagi Math object bilan matematik hisob-kitoblarni bajarishni o‘rganamiz.

Sonlarni yaxlitlash, tasodifiy son yaratish, daraja, ildiz, maksimum, minimum va boshqa matematik amallarni ko‘rib chiqamiz.

🧮 Math object nima?

Math — JavaScript'da matematik hisoblashlar uchun tayyor property va methodlarni beradigan object. 

console.log(Math);
Math'ni yaratish uchun new Math() yozilmaydi.

To‘g‘ridan-to‘g‘ri:

Math.method() ko‘rinishida ishlatiladi.

📐 Math.PI

Math.PI — π sonining qiymatini beradi. 

console.log(Math.PI);
3.141592653589793

⭕ Doira yuzini hisoblash

Formula: 

let radius = 5;

let area =
    Math.PI *
    radius ** 2;

console.log(area);

⭕ Doira uzunligi 

let radius = 5;

let length =
    2 *
    Math.PI *
    radius;

console.log(length);
