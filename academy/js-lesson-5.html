Ma'lumot turlari

JavaScript'da o‘zgaruvchilarda turli xil ma'lumotlarni saqlash mumkin. Bugun asosiy ma'lumot turlari bilan tanishamiz.

Ma'lumot turi nima? 🤔

JavaScript'da har bir qiymatning o‘z ma'lumot turi bo‘ladi.

Masalan, "Mirjamol" — matn,
15 — son,
true — mantiqiy qiymat. 

let name = "Mirjamol";

let age = 15;

let isStudent = true;

1. Number 🔢

Number sonlarni saqlash uchun ishlatiladi.

Butun sonlar ham, kasr sonlar ham Number turiga kiradi. 

let age = 15;

let score = 95;

let price = 19.99;

console.log(age);
console.log(score);
console.log(price);

🔢 Misollar:

10
25
3.14
-50

2. String 🔤

String — matnlarni saqlash uchun ishlatiladi.

String qiymatlar qo‘shtirnoq, birtirnoq yoki backtick ichida yoziladi. 

let firstName = "Mirjamol";

let lastName = 'Abdusalomov';

let city = `Toshkent`;

String'ni Console'ga chiqaramiz: 

console.log(firstName);

3. Boolean ✅❌

Boolean faqat ikkita qiymatga ega:

true → rost
false → yolg‘on 

let isStudent = true;

let isAdmin = false;

console.log(isStudent);
console.log(isAdmin);

Boolean qiymatlar keyinchalik if shartlarida juda ko‘p ishlatiladi.

4. Undefined ❓

O‘zgaruvchi yaratilgan, lekin unga hali qiymat berilmagan bo‘lsa, uning qiymati undefined bo‘ladi. 

let userName;

console.log(userName);

Natija: 

undefined

5. Null 🚫

null — ataylab "qiymat yo‘q" deb belgilash uchun ishlatiladi. 

let selectedUser = null;

console.log(selectedUser);

Bu yerda dasturchi qiymatni ataylab null qilib qo‘ygan.

6. BigInt 🔢

BigInt juda katta butun sonlarni saqlash uchun ishlatiladi.

Oddiy JavaScript dasturlarida hozircha bunga ko‘p ehtiyoj bo‘lmasligi mumkin. 

let bigNumber = 12345678901234567890n;

console.log(bigNumber);

📌 BigInt sonining oxirida n yoziladi.

7. Symbol 🔑

Symbol — noyob qiymat yaratish uchun ishlatiladigan ma'lumot turi.

Hozircha uning murakkab xususiyatlarini o‘rganish shart emas. Keyingi mavzularda kerak bo‘lganda ishlatamiz. 

let id = Symbol("id");

console.log(id);

8. Object 🗂️

Object bir nechta ma'lumotni bitta tuzilma ichida saqlashga yordam beradi. 

let user = {
    name: "Mirjamol",
    age: 15,
    isStudent: true
};

console.log(user);

Bu mavzuni keyingi darslarda batafsil o‘rganamiz.

9. Array 📋

Array bir nechta qiymatlarni tartibli ravishda saqlash uchun ishlatiladi. 

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(fruits);

Array mavzusini ham keyingi darslarda batafsil o‘rganamiz.

typeof operatori 🔍

Qiymatning qanday ma'lumot turiga tegishli ekanini bilish uchun typeof ishlatiladi. 

let age = 15;

console.log(typeof age);

Natija: 

"number"

typeof bilan turli qiymatlarni tekshirish 

console.log(typeof 100);

console.log(typeof "Salom");

console.log(typeof true);

console.log(typeof undefined);

console.log(typeof 10n);

Taxminan quyidagi natijalarni ko‘rasiz: 

number
string
boolean
undefined
bigint

Muhim jadval 📚

Tur Misol Ma'nosi
Number 15 Son
String "Salom" Matn
Boolean true Rost / yolg‘on
Undefined undefined Qiymat berilmagan
Null null Qiymat yo‘q
BigInt 100n Juda katta butun son
Object {} Murakkab ma'lumot

Amaliy mashq 💻 

let name = "Mirjamol";

let age = 15;

let isStudent = true;

let user = null;

let city;

let fruits = [
    "Olma",
    "Banan",
    "Uzum"
];


console.log(typeof name);

console.log(typeof age);

console.log(typeof isStudent);

console.log(typeof user);

console.log(typeof city);

console.log(typeof fruits);

Har bir qiymatning turini Console orqali tekshirib ko‘ring.

Uyga vazifa 📝

Quyidagi o‘zgaruvchilarni yarating:

1️⃣ age — Number

2️⃣ firstName — String

3️⃣ isStudent — Boolean

4️⃣ user — Null

5️⃣ qiymat berilmagan o‘zgaruvchi — Undefined

6️⃣ Bir nechta mevalardan Array yarating.

7️⃣ Har birining ma'lumot turini typeof yordamida Console'ga chiqaring.

Bugungi darsni eslab qoling 🎯

🔢 Number → son

🔤 String → matn

✅ Boolean → true yoki false

❓ Undefined → qiymat berilmagan

🚫 Null → ataylab qiymat yo‘q

🔢 BigInt → juda katta butun son

🔑 Symbol → noyob qiymat

🗂️ Object → murakkab ma'lumot

📋 Array → qiymatlar ro‘yxati

🔍 typeof → ma'lumot turini aniqlaydi
