CSS Grid 🔲

CSS Grid yordamida elementlarni qator va ustunlar bo'yicha tartibli joylashtirishni o'rganamiz.

1. CSS Grid nima?

CSS Grid — sahifadagi elementlarni qatorlar va ustunlar orqali joylashtirish uchun ishlatiladigan layout tizimi.

Grid ayniqsa cardlar, galereyalar, dashboardlar va murakkab layoutlar yaratishda juda foydali. 

.container {
    display: grid;
}

2. `display: grid`

Grid ishlashi uchun parent elementga `display: grid` beramiz. 

.container {
    display: grid;
}

3. `grid-template-columns`

Ustunlar sonini belgilash uchun `grid-template-columns` ishlatiladi. 

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
}

`1fr 1fr 1fr` → 3 ta teng ustun.

4. `repeat()`

Ko'p ustun yozishda `repeat()` kodni qisqartirishga yordam beradi. 

.container {
    display: grid;
    grid-template-columns:
        repeat(3, 1fr);
}
