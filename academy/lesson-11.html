Checkbox va Radio

Bugun foydalanuvchiga bir nechta variantni belgilash va bitta variantni tanlashni o'rganamiz.

1. Checkbox nima?

checkbox foydalanuvchiga bir yoki bir nechta variantni belgilash imkonini beradi.

Masalan, foydalanuvchi bir nechta dasturlash tilini tanlashi mumkin. 

<input type="checkbox">
HTML

<input type="checkbox">
CSS

Checkbox misoli 👇

2. checked

Agar checkbox sahifa ochilganda oldindan belgilangan bo'lishini xohlasak, checked atributidan foydalanamiz. 

<input
    type="checkbox"
    checked>

HTML

3. Radio nima?

radio foydalanuvchiga bir nechta variant ichidan odatda faqat bittasini tanlash imkonini beradi. 

<input
    type="radio"
    name="gender">

Erkak


<input
    type="radio"
    name="gender">

Ayol

Radio misoli 👇

Quyidagi variantlardan bittasini tanlang:

4. name atributi

Radio inputlarda bir guruh variantni birlashtirish uchun name bir xil bo'lishi kerak. 

<input
    type="radio"
    name="language">

HTML


<input
    type="radio"
    name="language">

CSS


<input
    type="radio"
    name="language">

JavaScript

`name="language"` bir xil bo'lgani uchun ulardan bittasini tanlash mumkin.
