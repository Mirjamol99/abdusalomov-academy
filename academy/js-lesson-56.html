DOM text va HTML

Bugun DOM orqali HTML elementlarining ichidagi matnni va HTML kodini JavaScript yordamida o‘zgartirishni o‘rganamiz.

Asosiy mavzular: textContent, innerHTML va innerText.

📝 DOM text nima?

HTML elementining ichidagi yozuvni JavaScript orqali o‘zgartirishimiz mumkin. 

<h1 id="title">
    Salom!
</h1>

JavaScript: 

let title =
    document.querySelector("#title");

title.textContent =
    "Salom JavaScript!";

✏️ textContent

textContent element ichidagi barcha matnni olish yoki o‘zgartirish uchun ishlatiladi. 

let title =
    document.querySelector("#title");

console.log(title.textContent);

Matnni o‘zgartirish: 

title.textContent =
    "Yangi sarlavha";
⭐ textContent oddiy matn bilan ishlash uchun juda qulay.

🌐 innerHTML

innerHTML element ichidagi HTML kodini olish yoki o‘zgartirish imkonini beradi. 

let box =
    document.querySelector("#box");

box.innerHTML =
    "<h2>Salom!</h2>";
Muhim farq:

textContent → HTML kodini oddiy matn sifatida ko‘rsatadi.

innerHTML → HTML teglarini haqiqiy HTML sifatida yaratadi.

🆚 textContent va innerHTML

textContent 

element.textContent =
    "<b>Salom</b>";

Natija:
<b>Salom</b>

Teg ishlamaydi, matn sifatida ko‘rsatiladi.

innerHTML 

element.innerHTML =
    "<b>Salom</b>";

Natija:

Salom

Teg HTML sifatida ishlaydi.

👀 innerText

innerText elementda foydalanuvchiga ko‘rinadigan matn bilan ishlaydi. 

let text =
    document.querySelector("#text");

console.log(text.innerText);

Uni o‘zgartirish ham mumkin: 

text.innerText =
    "Yangi matn";

🔥 Amaliy misol — textContent

Eski matn 

function changeText() {

    let text =
        document.querySelector(
            "#textDemo"
        );

    text.textContent =
        "Matn o‘zgardi! 🎉";

}

🌐 Amaliy misol — innerHTML

Bu yerda HTML paydo bo‘ladi. 
function addHTML() {

    let box =
        document.querySelector(
            "#htmlDemo"
        );

    box.innerHTML =
        "<h2>Salom JavaScript! 🔥</h2>";

}

📦 Bir nechta HTML element qo‘shish 

let box =
    document.querySelector("#box");

box.innerHTML = `
    <h2>JavaScript</h2>
    <p>DOM bilan ishlayapmiz!</p>
    <button>Bosish</button>
`;
💡 Template literal yordamida bir nechta HTML elementni qulay yozish mumkin.

🧩 innerHTML bilan karta yaratish 

function createCard() {

    let box =
        document.querySelector(
            "#cardDemo"
        );

    box.innerHTML = `
        <div class="bg-slate-900 p-6 rounded-2xl">
            <h2>🍕 Pizza</h2>
            <p>50 000 so‘m</p>
        </div>
    `;

}

🛒 Real loyiha misoli

Masalan, online do‘konda mahsulot kartasini JavaScript orqali yaratishimiz mumkin. 

let products = [
    {
        name: "Pizza",
        price: 50000
    },
    {
        name: "Burger",
        price: 35000
    }
];


let container =
    document.querySelector(
        "#products"
    );


products.forEach(function(product) {

    container.innerHTML += `
        <div class="card">
            <h2>${product.name}</h2>
            <p>${product.price} so‘m</p>
        </div>
    `;

});
⭐ Bu usul real saytlarning mahsulotlar, kartalar va ro‘yxatlarini yaratishda juda ko‘p ishlatiladi.

➕ innerHTML +=

+= mavjud HTML'ni o‘chirmasdan unga yangi HTML qo‘shish uchun ishlatiladi. 

let box =
    document.querySelector("#box");

box.innerHTML +=
    "<p>Yangi element</p>";
= → mavjud HTML'ni almashtiradi.

+= → mavjud HTML'ga qo‘shadi.

⚠️ innerHTML bilan ehtiyot bo‘lish

innerHTML orqali tashqi yoki ishonchsiz ma'lumotlarni HTML sifatida qo‘yishda ehtiyot bo‘lish kerak.

🔐 Foydalanuvchidan kelgan noma'lum ma'lumotni to‘g‘ridan-to‘g‘ri innerHTML ga qo‘yish xavfsizlik muammolariga olib kelishi mumkin.

Oddiy matn uchun textContent ko‘pincha xavfsizroq tanlovdir.

🆚 Uchalasining farqi

textContent

Barcha matnni olish yoki oddiy matn sifatida o‘zgartirish.

innerText

Ko‘rinadigan matn bilan ishlash.

innerHTML

Element ichidagi HTML kodini olish yoki yaratish.

🧠 Muhim kodlar 

// Oddiy matn

element.textContent =
    "Salom";


// Ko‘rinadigan matn

element.innerText =
    "Salom";


// HTML

element.innerHTML =
    "<b>Salom</b>";

📝 Uyga vazifa

1-vazifa ✏️
h1 yarating va textContent yordamida uning matnini o‘zgartiring.
2-vazifa 🌐
div yarating va innerHTML yordamida uning ichiga h2 va p qo‘shing.
3-vazifa 🔄
Tugma bosilganda textContent yordamida matnni almashtiring.
4-vazifa 📦
innerHTML orqali mahsulot kartasi yarating.
5-vazifa 🛒
3 ta mahsulotdan iborat array yarating va innerHTML += yordamida ularni sahifaga chiqaring.
6-vazifa 🎨
innerHTML orqali rangli HTML card yarating.
7-vazifa 🔥
textContent, innerText va innerHTML o‘rtasidagi farqni amalda ko‘rsatadigan mini loyiha yarating.

🎯 Dars xulosasi

📝 textContent → elementdagi matn bilan ishlaydi.

👀 innerText → ko‘rinadigan matn bilan ishlaydi.

🌐 innerHTML → HTML kodini o‘zgartirishga imkon beradi.

➕ innerHTML += → mavjud HTML'ga yangi HTML qo‘shadi.

🔐 Ishonchsiz foydalanuvchi ma'lumotlarini innerHTML orqali chiqarishda ehtiyot bo‘lish kerak.

⭐ DOM'da elementni topish: querySelector(), querySelectorAll().
