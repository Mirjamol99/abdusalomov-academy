01. HTML haqida

HTML nima?

HTML — web sahifalarning tuzilishini yaratish uchun ishlatiladigan belgilash tilidir.

Masalan, web sahifada sarlavha, matn, rasm, havola va boshqa elementlar bo'lishi mumkin. HTML shu elementlarning sahifadagi tuzilishini belgilaydi.

02. Birinchi kodimiz

Eng oddiy HTML sahifa

HTML faylida oddiy sarlavha yaratib ko'ramiz:

HTML 
<h1>Salom dunyo!</h1>

Salom dunyo!
