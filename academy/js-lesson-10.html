null va undefined

JavaScript'da ba'zan o‘zgaruvchida qiymat bo‘lmasligi mumkin. Bunday holatlarda null va undefined tushunchalari juda muhim.

undefined nima? ❓

Agar o‘zgaruvchi yaratilgan bo‘lsa, lekin unga hali qiymat berilmagan bo‘lsa, uning qiymati odatda undefined bo‘ladi. 

let username;

console.log(username);

Natija: 

undefined

undefined — qiymat berilmagan

Quyidagi o‘zgaruvchiga hech qanday qiymat berilmagan: 

let age;

console.log(age);

JavaScript:

"Bu o‘zgaruvchi mavjud, lekin unga qiymat berilmagan"

deb qaraydi.

null nima? ❌

null — qiymat ataylab mavjud emasligini bildiradi.

Ya'ni dasturchi o‘zgaruvchiga "hozircha hech qanday qiymat yo‘q" deb aniq belgilaydi. 

let user = null;

console.log(user);
null

null va undefined farqi 🔎

undefined null
Qiymat berilmagan Qiymat ataylab bo‘sh qilingan
Ko‘pincha avtomatik hosil bo‘ladi Dasturchi o‘zi belgilaydi
let age; let age = null;

type bilan tekshirish

Qiymatning turini typeof yordamida tekshirish mumkin. 

let age;

console.log(typeof age);
undefined

undefined uchun typeof natijasi "undefined" bo‘ladi.

null uchun typeof ⚠️

null bilan qiziq holat bor. 

let user = null;

console.log(typeof user);
object

Bu JavaScript'dagi tarixiy xususiyatlardan biri.

Shuning uchun typeof null natijasi "object" chiqadi.

📌 Muhim: typeof null "object" qaytaradi.

O‘zgaruvchini null qilish

O‘zgaruvchida avval qiymat bo‘lishi, keyinchalik esa uni null qilish mumkin. 

let user = "Ali";

console.log(user);

user = null;

console.log(user);
Ali
null

undefined'ni tekshirish 

let username;

if (username === undefined) {
    console.log("Username berilmagan");
}

Bu yerda o‘zgaruvchining qiymati undefined ekanligi tekshirilmoqda.

null'ni tekshirish 

let user = null;

if (user === null) {
    console.log("Foydalanuvchi yo‘q");
}
Foydalanuvchi yo‘q

=== bilan tekshirish 🔎

=== qat'iy tenglikni tekshiradi. 

console.log(null === null);

console.log(undefined === undefined);

console.log(null === undefined);
true
true
false

Demak, null va undefined bir xil emas.

Amaliy misol 👤

Foydalanuvchining telefoni hali mavjud emas deb tasavvur qilamiz. 

let phone = null;

if (phone === null) {
    console.log(
        "Telefon raqami mavjud emas."
    );
}

undefined bilan amaliy misol 

let email;

if (email === undefined) {
    console.log(
        "Email hali kiritilmagan."
    );
}

Amaliy mashq 🔥

Quyidagi kodlarning natijasini oldindan topishga harakat qiling. 

let a;

console.log(a);

let b = null;

console.log(b);

console.log(a === undefined);

console.log(b === null);

console.log(null === undefined);

Uyga vazifa 📝

1️⃣ username nomli o‘zgaruvchi yarating, lekin unga qiymat bermang.

2️⃣ Console orqali uning qiymatini chiqaring.

3️⃣ email o‘zgaruvchisiga null qiymatini bering.

4️⃣ typeof yordamida ikkala qiymatning turini tekshiring.

5️⃣ if yordamida username === undefined shartini tekshiring.

6️⃣ if yordamida email === null shartini tekshiring.

7️⃣ Quyidagi natijalarni toping: 

console.log(null === null);

console.log(undefined === undefined);

console.log(null === undefined);

Bugungi darsni eslab qoling 🎯

❓ undefined — qiymat hali berilmagan.

❌ null — qiymat ataylab bo‘sh qilingan.

🔎 typeof undefined → "undefined"

⚠️ typeof null → "object"

✅ null === null → true

✅ undefined === undefined → true

❌ null === undefined → false
