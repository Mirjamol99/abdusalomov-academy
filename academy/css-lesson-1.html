CSS nima? 🎨

CSS yordamida HTML sahifamizni chiroyli va zamonaviy ko'rinishga keltiramiz.

1. CSS nima?

CSS — Cascading Style Sheets so'zlarining qisqartmasi.

CSS HTML elementlarining ko'rinishini o'zgartirish uchun ishlatiladi.

💡 Oddiy qilib aytganda:

HTML — saytning tuzilishi.
CSS — saytning ko'rinishi.

2. HTML va CSS farqi

🧱

HTML

Sahifaning tuzilishini yaratadi. 

<h1>
    Salom!
</h1>
🎨

CSS

Sahifaning ko'rinishini bezaydi. 

h1 {
    color: blue;
}

3. Birinchi CSS kodimiz 🚀

HTML elementiga CSS yordamida rang berib ko'ramiz. 

<h1>Abdusalomov Academy</h1>

<style>

    h1 {
        color: blue;
    }

</style>
💡 color xususiyati matn rangini o'zgartiradi.

4. CSS property nima?

CSS'da elementning xususiyatini o'zgartirish uchun property ishlatiladi. 

h1 {

    color: blue;

    font-size: 40px;

}
color

Matn rangini o'zgartiradi.

font-size

Matn o'lchamini o'zgartiradi.

5. CSS selector

Selector CSS qaysi HTML elementga ta'sir qilishini belgilaydi. 

p {

    color: red;

}

Bu yerda p — selector.

6. Amaliy misol 💻 

<h1>Abdusalomov Academy</h1>

<p>
    CSS o'rganishni boshladik!
</p>

<style>

    h1 {
        color: #3b82f6;
        font-size: 40px;
    }

    p {
        color: #94a3b8;
        font-size: 20px;
    }

</style>
