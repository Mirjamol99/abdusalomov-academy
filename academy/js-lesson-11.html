typeof operatori

typeof JavaScript'da qiymat yoki o‘zgaruvchining ma'lumot turini aniqlash uchun ishlatiladi.

typeof nima? 🤔

typeof — operator. U berilgan qiymatning turini String ko‘rinishida qaytaradi. 

console.log(typeof "Salom");
string

Demak, "Salom" qiymatining turi string.

Number turini aniqlash 🔢 

let age = 15;

console.log(typeof age);
number

Chunki 15 JavaScript'da Number turiga kiradi.

String turini aniqlash 🔤 

let name = "Mirjamol";

console.log(typeof name);
string

Boolean turini aniqlash ✅ 

let isStudent = true;

console.log(typeof isStudent);
boolean

undefined turini aniqlash ❓ 

let username;

console.log(typeof username);
undefined

null bilan typeof ⚠️ 

let user = null;

console.log(typeof user);
object

Eslab qoling:

typeof null natijasi "object".

Bu JavaScript'dagi tarixiy xususiyatlardan biridir.

typeof operatorini o‘zgaruvchi bilan 

let city = "Toshkent";

console.log(typeof city);

Bu: 

typeof city

degani city ichidagi qiymatning turini tekshirish.

typeof va matematik amal 🧮

typeof expression natijasining turini ham aniqlay oladi. 

console.log(typeof (10 + 5));

console.log(typeof (20 * 2));
number
number

typeof va String + Number 

let result = "10" + 5;

console.log(result);

console.log(typeof result);
105
string

Bu yerda "10" String bo‘lgani sababli + operatori qiymatlarni matn sifatida birlashtirdi.

typeof va Number + Number 

let result = 10 + 5;

console.log(result);

console.log(typeof result);
15
number

Bir nechta qiymatni tekshirish 

let name = "Ali";
let age = 17;
let isStudent = true;
let email;

console.log(typeof name);
console.log(typeof age);
console.log(typeof isStudent);
console.log(typeof email);
string
number
boolean
undefined

typeof natijasi nima uchun String?

typeofning o‘zi qiymat turini aniqlaydi va natijani String sifatida qaytaradi. 

console.log(typeof 25);

console.log(
    typeof (typeof 25)
);
number
string

Birinchi typeof 25ning turini "number" deb qaytaradi.

"number" esa String, shuning uchun ikkinchi typeof natijasi "string" bo‘ladi.

typeof jadvali 📚

Qiymat typeof natijasi
"Salom" "string"
25 "number"
true "boolean"
undefined "undefined"
null "object"

Amaliy loyiha 💻

Bir nechta ma'lumot yaratib, ularning turlarini aniqlaymiz. 

let firstName = "Mirjamol";
let age = 15;
let isStudent = true;
let phone = null;
let email;

console.log("firstName:", typeof firstName);
console.log("age:", typeof age);
console.log("isStudent:", typeof isStudent);
console.log("phone:", typeof phone);
console.log("email:", typeof email);

Amaliy mashq 🔥

Avval natijalarni o‘zingiz topishga harakat qiling. 

console.log(typeof 100);

console.log(typeof "100");

console.log(typeof true);

console.log(typeof false);

console.log(typeof undefined);

console.log(typeof null);

Uyga vazifa 📝

1️⃣ Quyidagi o‘zgaruvchilarni yarating: 

let name = "Ali";
let age = 16;
let isStudent = true;
let money = null;
let phone;

2️⃣ Har bir o‘zgaruvchining turini typeof bilan Console'ga chiqaring.

3️⃣ Quyidagilarning natijasini toping: 

console.log(typeof "JavaScript");

console.log(typeof 2026);

console.log(typeof false);

console.log(typeof null);

console.log(typeof undefined);

4️⃣ Quyidagi kod nima chiqarishini tushuntiring: 

let result = "5" + 5;

console.log(result);
console.log(typeof result);

Bugungi darsni eslab qoling 🎯

🔍 typeof — qiymat turini aniqlaydi.

🔤 String → "string"

🔢 Number → "number"

✅ Boolean → "boolean"

❓ Undefined → "undefined"

⚠️ Null → "object"

📌 typeof natijasining o‘zi String bo‘ladi.
