7. `line-height`

Qatorlar orasidagi masofani belgilaydi. 

p {
    line-height: 1.8;
}

CSS yordamida matnni o'qishga qulay qilish mumkin. Line-height qiymatini oshirish orqali qatorlar orasidagi masofani kattalashtiramiz.

8. `letter-spacing`
