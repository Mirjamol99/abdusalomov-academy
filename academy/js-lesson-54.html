querySelector

Bugun JavaScript yordamida HTML elementlarini CSS selectorlar orqali topishni o‘rganamiz.

querySelector() — DOM bilan ishlashdagi eng kerakli metodlardan biri.

🔍 querySelector nima?

querySelector() CSS selector yordamida HTML ichidan birinchi mos keladigan elementni topadi. 

document.querySelector("h1");
querySelector() ichiga CSS selector yoziladi.

Masalan:
h1
.title
#title

🆚 getElementById va querySelector

Oldingi darsda getElementById() bilan ishlagan edik. 

document.getElementById("title");

Xuddi shu elementni querySelector() bilan ham topish mumkin: 

document.querySelector("#title");
⚠️ querySelector() da id uchun # belgisi yoziladi.

🏷️ ID selector

Agar HTML elementida id bo‘lsa, # bilan tanlaymiz. 

<h1 id="title">
    Salom JavaScript
</h1>
let title =
    document.querySelector("#title");

console.log(title);

🔵 Class selector

Agar elementda class bo‘lsa, . belgisi ishlatiladi. 

<p class="text">
    Salom
</p>
let text =
    document.querySelector(".text");

console.log(text);

🏷️ Tag selector

HTML tegini to‘g‘ridan-to‘g‘ri yozish ham mumkin. 

let title =
    document.querySelector("h1");

console.log(title);

Bu sahifadagi birinchi h1 elementni topadi.

✏️ Matnni o‘zgartirish

Eski matn 

function changeText() {

    let title =
        document.querySelector("#demoTitle");

    title.textContent =
        "Yangi matn! 🎉";

}

🎨 CSS style o‘zgartirish

Mening stilim o‘zgaradi 

function changeStyle() {

    let text =
        document.querySelector("#styleText");

    text.style.color = "orange";

    text.style.fontSize = "40px";

}

🎯 Class orqali element tanlash

Class orqali topilgan element 

function changeClassText() {

    let text =
        document.querySelector(".lessonText");

    text.textContent =
        "Element topildi! ✅";

}

🧩 Murakkab selector

CSS selectorlar bir nechta qismdan iborat bo‘lishi mumkin. 

document.querySelector(
    "div .title"
);

Bu div ichidagi title class'li elementni qidiradi.

🖱️ Button selector

Tugmani ham selector orqali topish mumkin. 

let button =
    document.querySelector("button");

console.log(button);
⚠️ Agar sahifada bir nechta button bo‘lsa, querySelector() faqat birinchi mos kelgan tugmani qaytaradi.

🔢 Birinchi elementni oladi 

<p class="text">1-element</p>

<p class="text">2-element</p>

<p class="text">3-element</p>
let text =
    document.querySelector(".text");

console.log(text);
Natijada faqat birinchi .text elementi olinadi.

Barcha elementlarni olishni esa keyingi darsda o‘rganamiz.

❌ Element topilmasa

Agar selector bo‘yicha element topilmasa, null qaytadi. 

let element =
    document.querySelector(
        ".notFound"
    );

console.log(element);
null

document.querySelector("selector");

📝 Uyga vazifa

1-vazifa 🔍
id="title" bo‘lgan h1 yarating va uni querySelector() bilan toping.
2-vazifa 🏷️
class="text" bo‘lgan p yarating va uni selector orqali toping.
3-vazifa ✏️
querySelector() yordamida h1 matnini o‘zgartiring.
4-vazifa 🎨
Tugma bosilganda .text elementining rangini o‘zgartiring.
5-vazifa 🔢
.counter class'li element yarating. Tugma bosilganda sonni bittaga oshiring.
6-vazifa 🛒
Savatga mahsulot qo‘shadigan counter yarating va uni querySelector() yordamida boshqaring.

#title
.text
button

🎯 Dars xulosasi

🔍 querySelector() → CSS selector orqali element topadi.

🏷️ #title → ID selector.

🔵 .title → class selector.

📄 h1 → tag selector.

🎯 querySelector() → faqat birinchi mos elementni qaytaradi.

❌ Element topilmasa → null.

✏️ Topilgan elementning textContent, style va boshqa xususiyatlarini o‘zgartirish mumkin.
