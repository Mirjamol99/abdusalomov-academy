switch operatori

Bugun JavaScript'dagi switch operatorini o‘rganamiz.

switch biror qiymatni bir nechta variant bilan solishtirish uchun ishlatiladi.

U ko‘p variantli if / else if / else shartlarini yozishda juda qulay.

switch nima? 🤔

switch berilgan qiymatni turli case qiymatlari bilan taqqoslaydi.

Qaysi case mos kelsa, shu qismdagi kod bajariladi.

Agar hech qaysi case mos kelmasa, default bajariladi.

switch sintaksisi 📚 

switch (qiymat) {

    case qiymat1:
        // kod
        break;

    case qiymat2:
        // kod
        break;

    default:
        // kod
}

Bu yerda:

switch — tekshiriladigan qiymat.
case — mumkin bo‘lgan variant.
break — switch'dan chiqish.
default — hech bir case mos kelmaganda ishlaydi.

break nima uchun kerak? 🛑

break switch'dan chiqish uchun ishlatiladi.

Odatda har bir case oxirida break yoziladi. 

let number = 2;

switch (number) {

    case 1:
        console.log("Bir");
        break;

    case 2:
        console.log("Ikki");
        break;

    case 3:
        console.log("Uch");
        break;
}
Ikki

switch va if / else 🔄

Masalan, bir xil vazifani if / else if bilan ham yozish mumkin. 

let day = 2;

if (day === 1) {
    console.log("Dushanba");
} else if (day === 2) {
    console.log("Seshanba");
} else if (day === 3) {
    console.log("Chorshanba");
} else {
    console.log("Noma'lum");
}
