Ternary operator

Bugun if / else ning qisqa ko‘rinishi bo‘lgan ternary operator bilan ishlashni o‘rganamiz.

Ternary operator oddiy shartlarda kodni qisqa va tushunarli yozish uchun ishlatiladi.

Ternary operator nima? 🤔

Ternary operator — shartni tekshirib, ikkita qiymatdan bittasini tanlash imkonini beradigan operator.

U if / else ga o‘xshaydi, lekin ancha qisqa yoziladi.

Sintaksisi 📚 

shart ? trueQiymat : falseQiymat;

Bu yerda:

? — shartdan keyin yoziladi.
: — true va false holatlarini ajratadi.

Agar shart true bo‘lsa, ? dan keyingi qiymat olinadi.

Agar shart false bo‘lsa, : dan keyingi qiymat olinadi.

Eng oddiy misol 

let age = 20;

let result = age >= 18
    ? "Kirish mumkin"
    : "Kirish mumkin emas";

console.log(result);
Kirish mumkin

Chunki:

20 >= 18 → true

Shuning uchun:
"Kirish mumkin" tanlanadi.

if / else bilan solishtiramiz 🔄

Ternary operator aslida oddiy if / else shartini qisqaroq yozishimizga yordam beradi. 

let age = 20;

if (age >= 18) {
    console.log("Katta");
} else {
    console.log("Kichik");
}

Ternary ko‘rinishi: 

let age = 20;

let result = age >= 18
    ? "Katta"
    : "Kichik";

console.log(result);

Boolean bilan ishlash 🧠 

let isLogin = true;

let message = isLogin
    ? "Xush kelibsiz!"
    : "Iltimos, tizimga kiring.";

console.log(message);
Xush kelibsiz!

false holati ❌ 

let isLogin = false;

let message = isLogin
    ? "Xush kelibsiz!"
    : "Iltimos, tizimga kiring.";

console.log(message);
Iltimos, tizimga kiring.

Comparison operator bilan ⚖️ 

let number = 10;

let result = number > 5
    ? "Katta"
    : "Kichik";

console.log(result);
Katta

Natijani o‘zgaruvchiga saqlash 

let age = 16;

let status = age >= 18
    ? "Voyaga yetgan"
    : "Voyaga yetmagan";

console.log(status);
Voyaga yetmagan

String bilan ishlatish 📝 

let username = "Mirjamol";

let message = username
    ? "Foydalanuvchi mavjud"
    : "Foydalanuvchi mavjud emas";

console.log(message);
Foydalanuvchi mavjud

Sonni tekshirish 🔢 

let number = 7;

let result = number % 2 === 0
    ? "Juft son"
    : "Toq son";

console.log(result);
Toq son

Imtihon natijasi 🎓 

let score = 75;

let result = score >= 60
    ? "Imtihondan o'tdingiz"
    : "Imtihondan o'tmadingiz";

console.log(result);
Imtihondan o'tdingiz

&& bilan ternary 🔥 

let age = 20;
let hasTicket = true;

let result = age >= 18 && hasTicket
    ? "Kirish mumkin"
    : "Kirish mumkin emas";

console.log(result);
Kirish mumkin

Ternary bilan qiymat tanlash 

let isStudent = true;

let discount = isStudent ? 20 : 0;

console.log(discount);
20

Agar foydalanuvchi talaba bo‘lsa, 20 qiymati olinadi.

Aks holda 0 olinadi.

Ternary bilan HTML chiqarish 🌐 

let isLogin = true;

let button = isLogin
    ? "Profil"
    : "Kirish";

console.log(button);
Profil

Bu usul keyinchalik JavaScript yordamida interfeys yaratishda juda foydali bo‘ladi.

Ternary operatorni ketma-ket yozish

Ternary ichida yana ternary yozish mumkin.

Lekin bunday kod juda murakkab bo‘lib ketishi mumkin. 

let score = 85;

let grade =
    score >= 90
        ? "A"
        : score >= 70
            ? "B"
            : "C";

console.log(grade);
B

Oddiy shartlarda ternary juda qulay, lekin ko‘p shart bo‘lsa if / else if / else tushunarliroq bo‘lishi mumkin.

Qachon ternary ishlatamiz? 🎯

Ternary operator ayniqsa:

✅ Bitta oddiy shart bo‘lganda
✅ Ikki xil natijadan bittasini tanlash kerak bo‘lganda
✅ Kodni qisqa yozish kerak bo‘lganda

foydali.

Muhim farq ⚠️

if / else ko‘proq murakkab yoki bir nechta amal bajariladigan shartlarda qulay.

ternary esa odatda bitta qiymat yoki qisqa natijani tanlash uchun ishlatiladi. 

// Ternary

let age = 20;

let result =
    age >= 18 ? "Katta" : "Kichik";
// if / else

let age = 20;

if (age >= 18) {
    console.log("Katta");
} else {
    console.log("Kichik");
}

Amaliy loyiha 🛒

Mahsulot narxiga qarab chegirma beramiz.

let discount =
    price >= 100000 ? 10 : 0;

10% chegirma

Uyga vazifa 📝

1-vazifa:
age yarating. Ternary yordamida 18 yoshdan katta yoki kichikligini aniqlang.

2-vazifa:
number yarating. Ternary yordamida sonning juft yoki toq ekanini aniqlang.

3-vazifa:
isLogin yarating. Agar true bo‘lsa "Xush kelibsiz!", aks holda "Kirish kerak" chiqaring.

4-vazifa:
score yarating. Agar ball 60 yoki undan katta bo‘lsa "O‘tdi", aks holda "Yiqildi" chiqaring.

5-vazifa:
isStudent yordamida talaba uchun 20% chegirma, talaba bo‘lmaganlar uchun 0% chegirma belgilang.

Bugungi darsni eslab qoling 🎯

⚡ Ternary — qisqa shart operatori.

❓ ? — true holatni bildiradi.

➗ : — false holatni ajratadi.

🔀 Ternary: shart ? true : false ko‘rinishida yoziladi.

🧠 Oddiy shartlarda ternary, murakkab shartlarda esa if / else qulayroq.
