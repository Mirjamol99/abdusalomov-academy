Comparison operatorlar

Comparison operatorlar JavaScript'da ikki qiymatni bir-biri bilan taqqoslash uchun ishlatiladi.

Taqqoslash natijasi odatda true yoki false bo‘ladi.

Comparison operator nima? 🤔

Comparison — ingliz tilida "taqqoslash" degan ma'noni anglatadi.

Masalan, 10 soni 5 dan kattami? 

console.log(10 > 5);
true

Chunki 10 haqiqatan ham 5 dan katta.

Comparison operatorlar jadvali 📚

Operator Ma'nosi Misol
> Katta 10 > 5
< Kichik 5 < 10
>= Katta yoki teng 10 >= 10
<= Kichik yoki teng 5 <= 5
== Teng 5 == "5"
=== Qat'iy teng 5 === 5
!= Teng emas 5 != 3
!== Qat'iy teng emas 5 !== "5"

> Katta operatori

Birinchi qiymat ikkinchi qiymatdan katta bo‘lsa, true qaytaradi. 

console.log(10 > 5);
console.log(3 > 8);
true
false

< Kichik operatori 

console.log(5 < 10);
console.log(20 < 10);
true
false

>= Katta yoki teng

Qiymat ikkinchi qiymatdan katta yoki teng bo‘lsa true bo‘ladi. 

console.log(10 >= 10);
console.log(15 >= 10);
console.log(5 >= 10);
true
true
false

<= Kichik yoki teng 

console.log(5 <= 5);
console.log(3 <= 5);
console.log(10 <= 5);
true
true
false

== Tenglik operatori

== qiymatlarni taqqoslaydi. JavaScript kerak bo‘lsa, qiymat turlarini avtomatik o‘zgartirishi mumkin. 

console.log(5 == 5);

console.log(5 == "5");
true
true

Ikkinchi misolda biri Number, ikkinchisi String bo‘lsa ham, == faqat qiymatni teng deb hisoblaydi.

=== Qat'iy tenglik 🔥

=== qiymat bilan birga ma'lumot turini ham tekshiradi. 

console.log(5 === 5);

console.log(5 === "5");
true
false

5 — Number.
"5" — String.

Qiymat bir xil ko‘rinsa ham, ularning turlari har xil.

== va === farqi ⚠️ 

console.log(10 == "10");
// true

console.log(10 === "10");
// false

Zamonaviy JavaScript dasturlashda ko‘pincha === ishlatish tavsiya qilinadi, chunki u qiymat turini ham tekshiradi.

!= Teng emas

!= ikki qiymat teng bo‘lmaganda true qaytaradi. 

console.log(10 != 5);

console.log(10 != 10);
true
false

!== Qat'iy teng emas

!== qiymat yoki uning turi farq qilsa true qaytaradi. 

console.log(5 !== 5);

console.log(5 !== "5");

console.log(5 !== 10);
false
true
true

O‘zgaruvchilar bilan ishlash 

let age = 16;

console.log(age >= 18);
false

Chunki 16 soni 18 dan katta yoki teng emas.

Amaliy misol 🎓

O‘quvchining yoshini tekshiramiz. 

let age = 17;

let canEnter = age >= 16;

console.log(canEnter);
true

Chunki 17 soni 16 dan katta.

Stringlarni taqqoslash 🔤

String qiymatlarni ham taqqoslash mumkin. 

console.log("Ali" === "Ali");

console.log("Ali" === "Vali");
true
false

Natija true yoki false

Comparison operatorlarning eng muhim jihati — natija Boolean bo‘ladi. 

let a = 20;
let b = 10;

let result = a > b;

console.log(result);
console.log(typeof result);
true
boolean

Bu keyingi darslarda if / else shartlarida juda ko‘p ishlatiladi.

Amaliy loyiha 💰

Foydalanuvchining balansini tekshiramiz. 

let balance = 25000;
let price = 20000;

let enoughMoney = balance >= price;

console.log(enoughMoney);
true

Balans mahsulot narxidan katta yoki teng bo‘lgani uchun natija true chiqadi.

Bir nechta taqqoslash 🧮 

let age = 17;

console.log(age >= 13);
console.log(age >= 18);
console.log(age < 20);
console.log(age === 17);
true
false
true
true

Amaliy mashq 🔥

Quyidagi kodlarning natijasini avval o‘zingiz toping. 

console.log(15 > 10);

console.log(7 < 3);

console.log(10 >= 10);

console.log(4 <= 2);

console.log(5 == "5");

console.log(5 === "5");

console.log(8 != 3);

console.log(8 !== "8");

Uyga vazifa 📝

1️⃣ let age = 16; yarating va 18 yosh bilan taqqoslang.

2️⃣ Ikki son yarating va qaysi biri katta ekanligini comparison operator yordamida tekshiring.

3️⃣ >= yordamida o‘quvchi 16 yoshga yetganini tekshiring.

4️⃣ == va === orasidagi farqni kod orqali ko‘rsating.

5️⃣ != yordamida ikki son teng emasligini tekshiring.

6️⃣ !== yordamida Number va String qiymatlarni taqqoslang.

7️⃣ Balans va mahsulot narxini taqqoslab, pul yetarliligini aniqlang.

Bugungi darsni eslab qoling 🎯

⚖️ > — katta

⚖️ < — kichik

⚖️ >= — katta yoki teng

⚖️ <= — kichik yoki teng

🟰 == — qiymat bo‘yicha teng

🔒 === — qiymat va tur bo‘yicha teng

❌ != — teng emas

🔒 !== — qiymat yoki turi teng emas

💡 Comparison operatorlar natijada true yoki false qaytaradi.
