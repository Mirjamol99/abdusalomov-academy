CSS Flexbox 📦

Flexbox yordamida elementlarni qator yoki ustun bo'yicha tartibli, moslashuvchan joylashtirishni o'rganamiz.

1. Flexbox nima?

Flexbox — elementlarni bir o'lchamli tartibda joylashtirish uchun ishlatiladigan CSS tizimi. 

.container {
    display: flex;
}
⭐ Flexbox bilan elementlarni:

➡️ qatorga joylashtirish
⬇️ ustunga joylashtirish
🎯 markazga olib kelish
↔️ orasini teng taqsimlash
📱 responsive qilish mumkin.

2. `display: flex`

Ota elementga `display: flex` berilsa, uning ichidagi elementlar flex elementlarga aylanadi.

3. `flex-direction`

Elementlarning asosiy yo'nalishini belgilaydi. 

.container {
    display: flex;
    flex-direction: row;
}

7. `gap`

8. `flex-wrap`

Elementlar joy yetmaganda yangi qatorga tushishi uchun `flex-wrap` ishlatiladi. 

.container {
    display: flex;
    flex-wrap: wrap;
