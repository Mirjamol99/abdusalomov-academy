01. HTML strukturasi

HTML fayli qanday tuziladi?

HTML fayli ma'lum bir tartib asosida yoziladi. Har bir asosiy qismning o'z vazifasi bor.

Odatda HTML hujjatida <html> , <head> va <body> kabi asosiy qismlar bo'ladi.

02. Asosiy kod

HTML ning asosiy strukturasi

HTML 
<!DOCTYPE html>

<html lang="uz">

<head>

    <meta charset="UTF-8">

    <title>Mening saytim</title>

</head>

<body>

    <h1>Salom dunyo!</h1>

</body>

</html>
📄

1. <!DOCTYPE html>

Bu deklaratsiya brauzerga hujjatning HTML5 formatida yozilganini bildiradi.

<!DOCTYPE html>
🏗️

2. <html>

<html> tegi butun HTML hujjatini o‘z ichiga oladi.

<html lang="uz"> ... </html>
⚙️

3. <head>

<head> qismida sahifa haqida brauzer uchun kerakli ma'lumotlar joylashadi.

Masalan:

<title>

Sahifa nomini belgilaydi.

<meta>

Sahifa haqida texnik ma'lumot beradi.

👀

4. <body>

<body> ichida foydalanuvchi brauzerda ko'radigan asosiy elementlar joylashadi.

<body>
  <h1> Salom! </h1>
</body>

title, meta va boshqa ma'lumotlar

Esda saqlang

HTML sahifani qurishda strukturaga rioya qilish juda muhim. <head> va <body> bir-biridan farqli vazifani bajaradi.
