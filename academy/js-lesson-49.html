Rest Operator

Bugungi darsda JavaScript'dagi Rest Operator bilan ishlashni o‘rganamiz.

Rest operator ham ... uchta nuqta bilan yoziladi. U bir nechta qiymatlarni bitta Array yoki Object ichida yig‘ib olish uchun ishlatiladi.

📦 Rest Operator nima?

Rest operator — ... yordamida qolgan qiymatlarni bitta o‘zgaruvchiga yig‘ib olish imkonini beradi.

Masalan: 

function numbers(a, b, ...rest) {

    console.log(a);
    console.log(b);
    console.log(rest);

}

numbers(10, 20, 30, 40, 50);
10
20
[30, 40, 50]
a → 10
b → 20
rest → qolgan qiymatlar

🔢 Function'da Rest

Rest operatorning eng ko‘p ishlatiladigan joylaridan biri — function parametrlaridir. 

function sum(...numbers) {

    console.log(numbers);

}

sum(10, 20, 30, 40);
[10, 20, 30, 40]

Barcha argumentlar numbers nomli Array ichiga yig‘ildi.

➕ Rest bilan yig‘indi 

function sum(...numbers) {

    let total = 0;

    for (let number of numbers) {

        total += number;

    }

    return total;

}


console.log(
    sum(10, 20, 30)
);
60

🔄 Istalgan miqdorda argument

Rest yordamida function'ga nechta argument yuborilishini oldindan bilish shart emas. 

function showNumbers(...numbers) {

    console.log(numbers);

}


showNumbers(1, 2);

showNumbers(1, 2, 3, 4);

showNumbers(
    10,
    20,
    30,
    40,
    50,
    60
);

🎯 Oddiy parametr + Rest

Rest oddiy parametrlar bilan birga ishlashi mumkin. 

function showUser(name, age, ...skills) {

    console.log(name);

    console.log(skills);

}


showUser(

⚠️ Rest oxirida bo‘lishi kerak

Rest parameter function parametrlarida oxirgi o‘rinda turishi kerak. 

// TO‘G‘RI

function test(a, b, ...rest) {

    console.log(a, b, rest);

}
// NOTO‘G‘RI

function test(...rest, a) {

    console.log(rest, a);

}
Rest'dan keyin boshqa parameter yozib bo‘lmaydi.

🧠 Spread va Rest farqi

Spread

Qiymatlarni yoyadi. 

let a = [1, 2];

let b = [
    ...a,
    3,
    4
];

Rest

Qiymatlarni yig‘adi. 

function test(
    ...numbers
) {

    console.log(numbers);

}
Esda tuting:

📤 Spread → yoyadi
📦 Rest → yig‘adi

➕ Rest bilan Sum Function 

function sum(...numbers) {

    let result = 0;

    numbers.forEach(function(number) {

        result += number;

    });

    return result;

}


console.log(
    sum(5, 10, 15, 20)
);
50

🔢 Rest bilan o‘rtacha qiymat 

function average(...numbers) {

    let total = 0;


    for (let number of numbers) {

        total += number;

    }


    return total / numbers.length;

}


console.log(
    average(10, 20, 30)
);
20

🔍 Rest + Math.max() 

function getMax(...numbers) {

    return Math.max(...numbers);

}


console.log(
    getMax(10, 50, 30, 90, 20)
);
90

Bu yerda ikkita ... turli vazifani bajaryapti:

...numbers → Rest
...numbers → Spread

🧩 Rest operator qayerlarda ishlatiladi?

Function

Istalgan miqdordagi argumentlarni olish uchun.

Array

Qolgan elementlarni yig‘ish uchun.

Object

Qolgan property'larni yig‘ish uchun.

Real loyihalar

Cart, User, Product va API ma'lumotlarida.

🔥 To‘liq amaliy misol 

function createProduct(
    name,
    price,
    ...categories
) {

    return {

        name,

        price,

        categories

    };

}


let product = createProduct(

    "Pizza",

    "Fast Food",

    "Pizza",

    "Food"

);


console.log(product);

    name: "Pizza",

        "Pizza",
        "Food"

Bu misolda:

name → mahsulot nomi.
price → mahsulot narxi.
...categories → qolgan barcha argumentlarni Array ichiga yig‘di.

📝 Uyga vazifa

1-vazifa 🔢
Rest yordamida barcha sonlarni qabul qiladigan function yarating. 
sum(10, 20, 30, 40);
2-vazifa ➕
Rest yordamida sonlarning yig‘indisini hisoblang.
3-vazifa 🧮
Rest yordamida sonlarning o‘rtacha qiymatini toping.
4-vazifa 👤
Function quyidagicha ishlasin: 
createUser(
    "Ali",
    18,
    "HTML",
    "CSS",
    "JavaScript"
);

Natijada Object qaytarsin: 

{
    name: "Ali",
    age: 18,
    skills: [
        "HTML",
        "CSS",
        "JavaScript"
    ]
}
5-vazifa 📦
Object destructuring'da Rest yordamida qolgan property'larni alohida Object'ga oling. 
let user = {

    name: "Ali",

    age: 18,

    city: "Andijon",

    job: "Developer",

    phone: "+998901234567"

};
6-vazifa 🔍
Rest yordamida eng katta sonni topadigan function yarating.
7-vazifa 🛒
Bir nechta product qabul qiladigan va ularning umumiy narxini hisoblaydigan function yarating. 
calculateTotal(
    pizza,
    burger,
    cola
);
8-vazifa 🔥
Rest va Spread'ni bitta loyihada birga ishlating.

Masalan:
Rest bilan mahsulotlarni qabul qiling, Spread bilan yangi Cart yarating.

🎯 Dars xulosasi

📦 Rest operator → ... yordamida yoziladi.

🔢 Rest bir nechta qiymatlarni bitta Array ichiga yig‘adi.

⚙️ Function parametrlarida juda ko‘p ishlatiladi.

📋 Array destructuring'da qolgan elementlarni olish mumkin.

📦 Object destructuring'da qolgan property'larni olish mumkin.

⚠️ Function parametrlarida Rest oxirgi o‘rinda bo‘lishi kerak.

📤 Spread → yoyadi.

📥 Rest → yig‘adi.

🔥 Rest va Spread bir-biriga o‘xshash ko‘rinsa ham, vazifalari boshqa.
