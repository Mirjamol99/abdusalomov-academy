while loop

Bugun JavaScript'dagi while loop bilan ishlashni o‘rganamiz.

while berilgan shart true bo‘lib turgan vaqt davomida kodni qayta-qayta bajaradi.

Bu loop ayniqsa takrorlanish soni oldindan aniq bo‘lmagan holatlarda juda foydali.

while loop nima? 🤔

while ingliz tilida "davomida" degan ma'noni anglatadi.

JavaScript'da while shartni tekshiradi.

Agar shart true bo‘lsa, ichidagi kod bajariladi.

Keyin shart yana tekshiriladi.

Shart false bo‘lganda loop to‘xtaydi.

while sintaksisi 📚 

while (shart) {

    // bajariladigan kod

}

while — loopni boshlaydi.

shart — loop ishlash-ishlamasligini tekshiradi.

{ } — takrorlanadigan kod yoziladigan qism.

Eng oddiy while loop 

let i = 1;

while (i <= 5) {

    console.log(i);

    i++;

}

Har bir aylanishdan keyin i++ ishlaydi.

i 6 ga yetganda i <= 5 false bo‘ladi va loop to‘xtaydi.

while qanday ishlaydi? 🧠 

let i = 1;

while (i <= 3) {

    console.log(i);

    i++;

}

1-qadam: i = 1

2-qadam: 1 <= 3 → true

3-qadam: 1 ekranga chiqadi.

4-qadam: i++ → 2

Keyin yana shart tekshiriladi.

2 <= 3 → true

3 <= 3 → true

4 <= 3 → false

Loop shu yerda to‘xtaydi.

i++ bo‘lmasa, i o‘zgarishsiz qoladi.

Shunda shart doim true bo‘lib qolishi mumkin va loop cheksiz davom etadi.

Cheksiz loop ⚠️

Agar shart hech qachon false bo‘lmasa, loop cheksiz davom etishi mumkin. 

let i = 1;

while (i <= 5) {

    console.log(i);

}

Bu kodda i hech qachon o‘zgarmaydi.

Shuning uchun i <= 5 doim true bo‘lib qoladi.

To‘g‘ri variant: 

let i = 1;

while (i <= 5) {

    console.log(i);

    i++;

}

for va while farqi 🔍 

// for

for (let i = 1; i <= 5; i++) {

    console.log(i);

}
// while

let i = 1;

while (i <= 5) {

    console.log(i);

    i++;

}

Ikkalasi ham bir xil natija berishi mumkin.

for loopda boshlanish, shart va o‘zgarish bitta qatorda yoziladi.

while esa shartni alohida ko‘rsatishga qulay.

Qachon while ishlatamiz? 🎯

while quyidagi holatlarda juda foydali:

✅ Shart bajarilguncha kodni takrorlash kerak bo‘lsa.

✅ Takrorlanishlar soni oldindan aniq bo‘lmasa.

✅ Foydalanuvchi ma'lum bir qiymat kiritguncha kutish kerak bo‘lsa.

✅ Biror shart bajarilmaguncha jarayon davom etishi kerak bo‘lsa.

Bugungi darsni eslab qoling 🎯

🔄 while — shart true bo‘lganida kodni takrorlaydi.

🧠 Shart har bir aylanishdan oldin tekshiriladi.

➕ i++ yoki boshqa o‘zgarish loopni oldinga siljitadi.

🛑 break — loopni to‘xtatadi.

⏭️ continue — joriy aylanishni tashlab ketadi.

⚠️ Loop ichida shartga ta'sir qiluvchi o‘zgarish bo‘lmasa, cheksiz loop yuzaga kelishi mumkin.

🔥 for va while ikkalasi ham takrorlash uchun ishlatiladi.
