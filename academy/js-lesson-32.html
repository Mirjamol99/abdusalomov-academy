push va pop

Bugungi darsda Array'ga element qo‘shish va Array'dan element o‘chirishni o‘rganamiz.

Buning uchun ikkita muhim metod:

➕ push()
➖ pop()

➕ push() nima?

push() — Array'ning oxiriga yangi element qo‘shadi.

Bu metod Array'ning o‘zini o‘zgartiradi. 

let mevalar = [
    "Olma",
    "Banan"
];

mevalar.push("Uzum");

console.log(mevalar);
[
    "Olma",
    "Banan",
    "Uzum"
]

🔍 push() qanday ishlaydi?

Dastlab:

["Olma", "Banan"]

↓ push("Uzum")

Keyin:

["Olma", "Banan", "Uzum"]

➕ Bir nechta elementni push qilish

push() ichiga bir vaqtning o‘zida bir nechta element berish mumkin. 

let sonlar = [1, 2, 3];

sonlar.push(4, 5, 6);

console.log(sonlar);
[
    1,
    2,
    3,
    4,
    5,
    6
]

📏 push() va length

push() Array'ga element qo‘shganda uning length qiymati ham o‘zgaradi. 

let mevalar = [
    "Olma",
    "Banan"
];

console.log(mevalar.length);

mevalar.push("Uzum");

console.log(mevalar.length);
2
3

🎯 push() nima qaytaradi?

Muhim jihat:

push() qo‘shilgan elementni emas, yangi Array uzunligini qaytaradi. 

let mevalar = [
    "Olma",
    "Banan"
];

let result = mevalar.push("Uzum");

console.log(result);
3
push() dan keyingi Array uzunligi → 3

➖ pop() nima?

pop() — Array'ning oxirgi elementini o‘chiradi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

mevalar.pop();

console.log(mevalar);
[
    "Olma",
    "Banan"
]

🔍 pop() qanday ishlaydi?

Dastlab:

["Olma", "Banan", "Uzum"]

↓ pop()

Keyin:

["Olma", "Banan"]

🎁 pop() nima qaytaradi?

pop() o‘chirilgan elementning o‘zini qaytaradi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

let deleted = mevalar.pop();

console.log(deleted);

console.log(mevalar);
Uzum

[
    "Olma",
    "Banan"
]

📏 pop() va length 

let sonlar = [
    10,
    20,
    30,
    40
];

console.log(sonlar.length);

sonlar.pop();

console.log(sonlar.length);
4
3

🔥 push va pop birga 

let fruits = [
    "Olma",
    "Banan"
];

fruits.push("Uzum");

console.log(fruits);

fruits.pop();

console.log(fruits);
[
    "Olma",
    "Banan",
    "Uzum"
]

[
    "Olma",
    "Banan"
]

🔁 push va pop bilan loop 

let numbers = [];

numbers.push(10);
numbers.push(20);
numbers.push(30);

for (let number of numbers) {

    console.log(number);

}
10
20
30

📦 Bo‘sh Array'ga push()

Bo‘sh Array'ga ham bemalol element qo‘shish mumkin. 

let users = [];

users.push("Ali");

users.push("Vali");

users.push("Hasan");

console.log(users);
[
    "Ali",
    "Vali",
    "Hasan"
]

🧹 Bir nechta pop()

pop() har chaqirilganda oxirgi elementni bittadan o‘chiradi. 

let numbers = [
    1,
    2,
    3,
    4,
    5
];

numbers.pop();

numbers.pop();

console.log(numbers);
[
    1,
    2,
    3
]

⚠️ Bo‘sh Array'da pop()

Agar Array bo‘sh bo‘lsa, pop() hech qanday element topa olmaydi. 

let numbers = [];

let result = numbers.pop();

console.log(result);
undefined

🧠 push va pop farqi

Metod Vazifasi Qayerda? Qaytaradi
push() Element qo‘shadi Oxiriga Yangi length
pop() Element o‘chiradi Oxiridan O‘chirilgan element

🛒 Real loyiha — savatcha

Masalan, internet do‘kondagi savatchaga mahsulot qo‘shamiz. 

let cart = [];

cart.push("Telefon");

cart.push("Quloqchin");

cart.push("Sichqoncha");

console.log(cart);
[
    "Telefon",
    "Quloqchin",
    "Sichqoncha"
]

🛒 Savatchadan oxirgi mahsulotni o‘chirish 

let cart = [
    "Telefon",
    "Quloqchin",
    "Sichqoncha"
];

let removedProduct = cart.pop();

console.log(
    "O‘chirildi:",
    removedProduct
);

console.log(
    "Savatcha:",
    cart
);
O‘chirildi: Sichqoncha

Savatcha:
[
    "Telefon",
    "Quloqchin"
]

🔢 push() bilan sonlar 

let numbers = [];

numbers.push(5);
numbers.push(10);
numbers.push(15);
numbers.push(20);

console.log(numbers);

🔄 push() va pop() ketma-ketligi 

let numbers = [1, 2, 3];

numbers.push(4);

console.log(numbers);

numbers.pop();

console.log(numbers);

numbers.push(5);

console.log(numbers);
[1, 2, 3, 4]

[1, 2, 3]

[1, 2, 3, 5]

💡 Muhim eslatma

push() — oxiriga qo‘shadi.

pop() — oxiridan o‘chiradi.

Ikkalasi ham Array'ning oxiri bilan ishlaydi.

Uyga vazifa 📝

1-vazifa:
Bo‘sh Array yarating va unga 5 ta ismni push() yordamida qo‘shing.

2-vazifa:
5 ta sonli Array yarating va pop() yordamida oxirgi sonni o‘chiring.

3-vazifa:
push() nechta element qo‘shganini length orqali tekshiring.

4-vazifa:
pop() orqali o‘chirilgan elementni alohida o‘zgaruvchiga saqlang va Console'ga chiqaring.

5-vazifa:
Savatcha yarating: cart = []. Unga 4 ta mahsulot qo‘shing.

6-vazifa:
Savatchadagi oxirgi mahsulotni pop() bilan o‘chiring.

7-vazifa:
push() va pop()ni birgalikda ishlatib ko‘ring.

Bugungi dars xulosasi 🎯

➕ push() — Array oxiriga element qo‘shadi.

➖ pop() — Array oxiridagi elementni o‘chiradi.

📏 push() — yangi Array uzunligini qaytaradi.

🎁 pop() — o‘chirilgan elementni qaytaradi.
