shift va unshift

32-darsda push() va pop() yordamida Array'ning oxiri bilan ishlashni o‘rgandik.

Endi Array'ning bosh qismi bilan ishlashni o‘rganamiz.

↔️ shift va unshift nima?

shift()

Array'ning boshidagi elementni o‘chiradi.

unshift()

Array'ning boshiga yangi element qo‘shadi.

push() → oxiriga qo‘shadi

pop() → oxiridan o‘chiradi

unshift() → boshiga qo‘shadi

shift() → boshidan o‘chiradi

➖ shift() nima?

shift() Array'dagi birinchi elementni o‘chiradi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

mevalar.shift();

console.log(mevalar);
[
    "Banan",
    "Uzum"
]

🔍 shift() qanday ishlaydi?

Dastlab:

["Olma", "Banan", "Uzum"]

↓ shift()

Keyin:

["Banan", "Uzum"]

🎁 shift() nima qaytaradi?

shift() o‘chirilgan elementni qaytaradi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

let deleted = mevalar.shift();

console.log(deleted);

console.log(mevalar);
Olma

[
    "Banan",
    "Uzum"
]

📏 shift() va length 

let numbers = [
    10,
    20,
    30,
    40
];

console.log(numbers.length);

numbers.shift();

console.log(numbers.length);
4
3

Birinchi element o‘chirilgani uchun Array uzunligi 1 taga kamaydi.

➕ unshift() nima?

unshift() Array'ning boshiga yangi element qo‘shadi. 

let mevalar = [
    "Banan",
    "Uzum"
];

mevalar.unshift("Olma");

console.log(mevalar);
[
    "Olma",
    "Banan",
    "Uzum"
]

🔍 unshift() qanday ishlaydi?

Dastlab:

["Banan", "Uzum"]

↓ unshift("Olma")

Keyin:

["Olma", "Banan", "Uzum"]

🎯 unshift() nima qaytaradi?

unshift() qo‘shilgan elementni emas, yangi Array uzunligini qaytaradi. 

let mevalar = [
    "Banan",
    "Uzum"
];

let result =
    mevalar.unshift("Olma");

console.log(result);
3

➕ Bir nechta element qo‘shish

unshift() orqali bir vaqtning o‘zida bir nechta element qo‘shish mumkin. 

let numbers = [
    30,
    40
];

numbers.unshift(
    10,
    20
);

console.log(numbers);
[
    10,
    20,
    30,
    40
]

🔄 shift va unshift birga 

let numbers = [
    20,
    30
];

numbers.unshift(10);

console.log(numbers);

numbers.shift();

console.log(numbers);
[
    10,
    20,
    30
]

[
    20,
    30
]

🧠 push/pop va shift/unshift

Metod Vazifasi Qismi Qaytaradi
push() Qo‘shadi Oxiri length
pop() O‘chiradi Oxiri O‘chirilgan element
unshift() Qo‘shadi Boshi length
shift() O‘chiradi Boshi O‘chirilgan element

Tasavvur qiling, bizda mijozlar navbati bor.

⚠️ Bo‘sh Array bilan shift()

Bo‘sh Array'da birinchi element bo‘lmagani uchun shift() undefined qaytaradi. 

let numbers = [];

let result = numbers.shift();

console.log(result);
undefined

📏 Bo‘sh Array va unshift() 

let numbers = [];

let result =
    numbers.unshift(100);

console.log(numbers);

[100]

1

🔥 To‘rtta metodni birga ishlatish 

let fruits = [

🧠 Yodlab olishning oson usuli

UNSHIFT → boshiga qo‘shadi

SHIFT → boshidan o‘chiradi

PUSH → oxiriga qo‘shadi

POP → oxiridan o‘chiradi

Uyga vazifa 📝

1-vazifa:
5 ta ismli Array yarating. shift() bilan birinchi ismni o‘chiring.

2-vazifa:
Array boshiga yangi ismni unshift() bilan qo‘shing.

3-vazifa:
shift() orqali o‘chirilgan ismni alohida o‘zgaruvchiga saqlang.

4-vazifa:
unshift() bilan bir vaqtning o‘zida 3 ta son qo‘shing.

5-vazifa:
Quyidagi navbatdan birinchi odamni chiqaring: 

let queue = [
    "Ali",
    "Vali",
    "Hasan",
    "Husan"
];

6-vazifa:
Navbat boshiga "Sardor"ni qo‘shing.

7-vazifa:
push(), pop(), shift() va unshift()ni bitta Array'da ishlatib ko‘ring.
