Array index va length

Bugungi darsda Array ichidagi elementlarning index raqami va Array uzunligini ko‘rsatuvchi length xususiyatini batafsil o‘rganamiz.

🔢 Index nima?

Index — Array ichidagi elementning tartib raqami.

JavaScript'da indexlar 0 dan boshlanadi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];
0

Olma

1

Banan

2

Uzum

3

Anor

📌 Nega index 0 dan boshlanadi?

JavaScript'da Array elementlari birinchi elementdan boshlab 0, keyin 1, 2, 3... tarzida indekslanadi. 

let ism = [
    "Ali",
    "Vali",
    "Hasan"
];

console.log(ism[0]);
console.log(ism[1]);
console.log(ism[2]);
Ali
Vali
Hasan
⚠️ Birinchi elementni olish uchun [1] emas, [0] yoziladi.

🎯 Index orqali elementni olish 

let ranglar = [
    "Qizil",
    "Yashil",
    "Ko‘k"
];

console.log(ranglar[0]);

Natija: 

Qizil

✏️ Index orqali elementni o‘zgartirish

Index orqali Array'dagi mavjud elementning qiymatini o‘zgartirish mumkin. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

mevalar[1] = "Anor";

console.log(mevalar);
[
    "Olma",
    "Anor",
    "Uzum"
]

Chunki 1-indexdagi qiymat Banan edi.

Uni Anorga almashtirdik.

📏 length nima?

length — Array ichidagi elementlar sonini bildiradi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

console.log(mevalar.length);
4

🔢 length va index farqi

Bu ikkisini adashtirmaslik juda muhim. 

let sonlar = [
    10,
    20,
    30,
    40
];

console.log(sonlar.length);

console.log(sonlar[3]);

sonlar.length → 4 — elementlar soni


sonlar[3] → 40 — 3-indexdagi element

🎯 Oxirgi elementni olish

Array uzunligi 4 bo‘lsa, oxirgi index 3 bo‘ladi.

Shuning uchun oxirgi elementni:

length - 1

orqali topamiz. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

console.log(
    mevalar[mevalar.length - 1]
);
Anor

🧠 Nima uchun length - 1?

Masalan, Array'da 5 ta element bo‘lsin: 

let sonlar = [
    10, 20, 30, 40, 50
];
0

10

1

20

2

30

3

40

4

50

sonlar.length → 5

sonlar.length - 1 → 4

Demak oxirgi index → 4

❌ Mavjud bo‘lmagan index

Agar Array'da mavjud bo‘lmagan indexga murojaat qilsak, JavaScript undefined qaytaradi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum"
];

console.log(mevalar[10]);
undefined
Array'da faqat 0, 1, 2 indekslar mavjud. 10-index mavjud emas.

📭 Bo‘sh Array va length 

let mevalar = [];

console.log(mevalar.length);
0

Bo‘sh Array'da element yo‘q, shuning uchun uning uzunligi 0 bo‘ladi.

➕ length orqali element qo‘shish

length orqali Array oxiriga yangi element joylashtirish ham mumkin. 

let mevalar = [
    "Olma",
    "Banan"
];

mevalar[mevalar.length] = "Uzum";

console.log(mevalar);
[
    "Olma",
    "Banan",
    "Uzum"
]
💡 Lekin amaliyotda element qo‘shish uchun push() ishlatish qulayroq.

🔄 length va for loop

length Array bilan loop ishlatishda juda ko‘p qo‘llanadi. 

let mevalar = [
    "Olma",
    "Banan",
    "Uzum",
    "Anor"
];

for (
    let i = 0;
    i < mevalar.length;
    i++
) {

    console.log(mevalar[i]);

}
Olma
Banan
Uzum
Anor

🧮 Index bilan hisoblash 

let sonlar = [
    10,
    20,
    30,
    40
];

console.log(sonlar[0] + sonlar[1]);

console.log(sonlar[2] * 2);
30
60

Index orqali Array'dagi kerakli qiymatni olib, matematik amallarda ishlatish mumkin.

📝 String Array bilan ishlash 

let ismlar = [
    "Ali",
    "Vali",
    "Hasan",
    "Husan"
];

console.log("Birinchi:", ismlar[0]);

console.log("Ikkinchi:", ismlar[1]);

console.log("Oxirgi:",
    ismlar[ismlar.length - 1]
);

🧑‍💻 Real loyiha misoli

Masalan, internet do‘kondagi mahsulotlar Array'da saqlansin: 

let products = [
    "iPhone",
    "Samsung",
    "Xiaomi",
    "Redmi"
];

console.log(
    "Mahsulotlar soni:",
    products.length
);

console.log(
    "Birinchi mahsulot:",
    products[0]
);

console.log(
    "Oxirgi mahsulot:",
    products[products.length - 1]
);

⚠️ Eng ko‘p qilinadigan xato 

let ismlar = [
    "Ali",
    "Vali",
    "Hasan"
];

console.log(ismlar[3]);

Bu yerda 3-index mavjud emas.

Chunki indexlar:
0 → Ali
1 → Vali
2 → Hasan

length = 3, lekin oxirgi index 2.

Shuning uchun:
lastIndex = length - 1

🎯 Muhim formula

Oxirgi index = length - 1 

let numbers = [
    10,
    20,
    30,
    40,
    50,
    60
];

let lastIndex = numbers.length - 1;

console.log(lastIndex);

console.log(numbers[lastIndex]);
5
60

🧠 Array index va length farqi

Tushuncha Vazifasi Misol
Index Element joylashuvi arr[2]
length Elementlar soni arr.length
last index Oxirgi element joylashuvi arr.length - 1

Uyga vazifa 📝

1-vazifa:
5 ta ismni Array ichiga yozing. Birinchi ismni Console'ga chiqaring.

2-vazifa:
5 ta ismli Array'ning length qiymatini chiqaring.

3-vazifa:
Array'dagi oxirgi elementni length - 1 yordamida oling.

4-vazifa:
Array'dagi 2-indexdagi elementni boshqa qiymatga o‘zgartiring.

5-vazifa:
6 ta sonli Array yarating. Eng oxirgi elementni index orqali toping.

6-vazifa:
for loop yordamida Array'dagi barcha elementlarni chiqaring.

7-vazifa:
Array'da mavjud bo‘lmagan indexga murojaat qilib ko‘ring. Natija nima bo‘lishini kuzating.

8-vazifa:
Quyidagi Array'da birinchi, ikkinchi va oxirgi elementni chiqaring: 

let students = [
    "Ali",
    "Vali",
    "Hasan",
    "Husan",
    "Sardor"
];
