Logical operatorlar

Logical operatorlar JavaScript'da bir nechta shartni birlashtirish, tekshirish va natijani teskari qilish uchun ishlatiladi.

JavaScript'da 3 ta asosiy logical operator mavjud:

&& — AND — VA
|| — OR — YOKI
! — NOT — EMAS

Logical operator nima? 🤔

Logical operatorlar odatda true va false qiymatlar bilan ishlaydi.

Masalan: 

let age = 18;

console.log(age >= 18);
true

Endi ikkita shartni bir vaqtning o‘zida tekshirishimiz kerak bo‘lsa, logical operatorlardan foydalanamiz.

Logical operatorlar jadvali 📚

Operator Nomi Ma'nosi
&& AND VA
|| OR YOKI
! NOT EMAS

&& — AND operator 🧠

&& operatori VA degan ma'noni anglatadi.

Barcha shartlar true bo‘lsagina natija true bo‘ladi. 

console.log(true && true);
true

Ikkala tomon ham true.

&& operatorida false

Agar hech bo‘lmaganda bitta shart false bo‘lsa, natija false bo‘ladi. 

console.log(true && false);

console.log(false && true);

console.log(false && false);
false
false
false

&& bilan real misol 🎓

Foydalanuvchi kamida 16 yoshda va kursga ro‘yxatdan o‘tgan bo‘lishi kerak. 

let age = 17;
let registered = true;

console.log(age >= 16 && registered);
true

Chunki:

age >= 16 → `true`
registered → `true`

Demak:
true && true → `true`

|| — OR operator 🔀

|| operatori YOKI degan ma'noni anglatadi.

Kamida bitta shart true bo‘lsa, natija true bo‘ladi. 

console.log(true || false);

console.log(false || true);

console.log(true || true);
true
true
true

|| operatorida false

Faqat barcha shartlar false bo‘lsa, natija false bo‘ladi. 

console.log(false || false);
false

|| bilan real misol 🎮

Foydalanuvchi 18 yoshdan katta yoki maxsus ruxsatga ega bo‘lishi mumkin. 

let age = 16;
let permission = true;

console.log(age >= 18 || permission);
true

Birinchi shart `false`, lekin ikkinchi shart `true`.

! — NOT operator 🔄

! operatori natijani teskarisiga o‘zgartiradi.

true → false
false → true 

console.log(!true);

console.log(!false);
false
true

! bilan o‘zgaruvchi 

let isLogin = true;

console.log(!isLogin);
false

Chunki isLogin qiymati true edi.

!true → false

&&, || va ! birgalikda 🔥 

let age = 20;
let balance = 50000;
let blocked = false;

let access =
    age >= 18 &&
    balance >= 30000 &&
    !blocked;

console.log(access);
true

Tekshiramiz:

age >= 18 → `true`
balance >= 30000 → `true`
!blocked → `true`

Natija:
true && true && true → true

Login tizimi 🔐

Login va parol to‘g‘ri bo‘lsa, natija true bo‘ladi. 

let username = "admin";
let password = "1234";

let correctUsername =
    username === "admin";

let correctPassword =
    password === "1234";

let login =
    correctUsername &&
    correctPassword;

console.log(login);
true

Balansni tekshirish 💰 

let balance = 50000;
let price = 30000;

let canBuy =
    balance >= price &&
    price > 0;

console.log(canBuy);
true

Balans narxdan katta va mahsulot narxi 0 dan katta.

Shuning uchun xarid qilish mumkin.

Bir nechta shartni birlashtirish 

let age = 17;
let hasTicket = true;
let hasPermission = false;

let result =
    age >= 18 ||
    (age >= 16 &&
     hasTicket &&
     hasPermission);

console.log(result);
false

Bu yerda qavs ichidagi shartlar birgalikda tekshiriladi.

Qavsdan foydalanish 📌

Murakkab shartlarda qavs ishlatish kodni tushunarli qiladi. 

let age = 17;
let hasTicket = true;

let result =
    age >= 18 ||
    (age >= 16 && hasTicket);

console.log(result);
true

Logical operatorlar va Boolean

Logical operatorlar Boolean qiymatlar bilan juda ko‘p ishlatiladi. 

let isStudent = true;
let isLogin = true;

let result = isStudent && isLogin;

console.log(result);
console.log(typeof result);
true
boolean

Amaliy mashq 🔥

Avval natijalarni o‘zingiz toping, keyin Console'da tekshiring.

console.log(true && false);

console.log(false && false);

console.log(true || false);

console.log(false || false);

console.log(!true);

console.log(!false);
