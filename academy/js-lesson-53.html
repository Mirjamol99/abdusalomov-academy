getElementById

Bugun DOM'dagi HTML elementlarini id orqali topishni o‘rganamiz.

getElementById() — DOM bilan ishlashda eng muhim selectorlardan biridir.

🎯 getElementById nima?

getElementById() HTML ichidagi id qiymati orqali bitta elementni topadi. 

document.getElementById("title");
Bu yerda:

document → HTML hujjat
getElementById() → id orqali element qidiradi
"title" → qidirilayotgan id

🏷️ HTML'da id berish

Avval HTML elementiga id beramiz. 

<h1 id="title">
    Salom JavaScript
</h1>

Keyin JavaScript orqali shu elementni topamiz: 

let title =
    document.getElementById("title");

console.log(title);

🔍 Elementni topish 

let title =
    document.getElementById("title");

Endi title o‘zgaruvchisi HTML'dagi h1 elementni saqlaydi.

Muhim:

getElementById() odatda bitta elementni qaytaradi.

✏️ textContent bilan ishlash

Elementni topganimizdan keyin uning matnini o‘zgartirishimiz mumkin. 

let title =
    document.getElementById("title");

title.textContent =
    "JavaScript darsi";

🎨 style bilan ishlash

Topilgan elementning CSS style'larini ham o‘zgartirish mumkin. 

let title =
    document.getElementById("title");

title.style.color = "red";

title.style.fontSize = "50px";

🖱️ Tugma orqali elementni o‘zgartirish

Eski sarlavha 

function changeTitle() {

    let title =
        document.getElementById(
            "demoTitle"
        );

    title.textContent =
        "Yangi sarlavha! 🎉";

}

🎨 Tugma orqali rang o‘zgartirish

Mening rangim o‘zgaradi 

function changeColor() {

    let text =
        document.getElementById(
            "colorText"
        );

    text.style.color = "orange";

}

🔢 Sonni o‘zgartirish

0 
let count = 0;

function increaseNumber() {

    count++;

    document.getElementById(
        "number"
    ).textContent = count;

}

❗ ID nomi aynan bir xil bo‘lishi kerak

HTML'dagi id va JavaScript'dagi id bir xil bo‘lishi kerak. 

<h1 id="title">
    Salom
</h1>
document.getElementById("title");
❌ Masalan:

HTML: id="title"
JavaScript: getElementById("Title")

Bu bir xil emas.

⚠️ ID topilmasa nima bo‘ladi?

Agar berilgan id bilan element mavjud bo‘lmasa, natija null bo‘ladi. 

let element =
    document.getElementById(
        "notFound"
    );

console.log(element);
null

📌 Muhim qoida

getElementById()

→ faqat id orqali element qidiradi.

→ ID qiymati odatda sahifada yagona bo‘lishi kerak.

→ Element topilmasa null qaytadi.
