Assignment operatorlar

Assignment operatorlar o‘zgaruvchiga qiymat berish yoki uning mavjud qiymatini o‘zgartirish uchun ishlatiladi.

Eng asosiy operator: =

Bundan tashqari +=, -=, *=, /= va %= operatorlari ham mavjud.

Assignment operator nima? 🤔

Assignment so‘zi ingliz tilida "qiymat berish" degan ma'noni anglatadi.

JavaScript'da = operatori o‘ng tomondagi qiymatni chap tomondagi o‘zgaruvchiga beradi. 

let age = 16;

Bu yerda 16 qiymati age o‘zgaruvchisiga berildi.

= Oddiy assignment 

let name = "Ali";

console.log(name);
Ali

Keyinchalik o‘zgaruvchiga yangi qiymat berishimiz ham mumkin: 

let name = "Ali";

name = "Vali";

console.log(name);
Vali

+= Qo‘shib qiymat berish ➕

+= operatori mavjud qiymatga yangi qiymatni qo‘shadi. 

let score = 10;

score += 5;

console.log(score);
15

Bu kod aslida quyidagiga teng: 

score = score + 5;

-= Ayirib qiymat berish ➖

-= operatori o‘zgaruvchining qiymatidan berilgan sonni ayiradi. 

let balance = 20000;

balance -= 5000;

console.log(balance);
15000

Bu: 

balance = balance - 5000;

*= Ko‘paytirib qiymat berish ✖️ 

let number = 5;

number *= 4;

console.log(number);
20

Bu: 

number = number * 4;

/= Bo‘lib qiymat berish ➗ 

let number = 100;

number /= 4;

console.log(number);
25

Bu: 

number = number / 4;

%= Qoldiqni saqlash

%= operatori bo‘lishdan hosil bo‘lgan qoldiqni o‘zgaruvchiga saqlaydi. 

let number = 17;

number %= 5;

console.log(number);
2

Chunki:

17 % 5 = 2

**= Darajaga oshirib assignment

**= operatori qiymatni berilgan darajaga oshirib, natijani o‘sha o‘zgaruvchiga saqlaydi. 

let number = 2;

number **= 3;

console.log(number);
8

Bu: 

number = number ** 3;

Operatorlarni taqqoslash 📚

Operator Ma'nosi Misol
= Qiymat berish x = 10
+= Qo‘shish x += 5
-= Ayirish x -= 5
*= Ko‘paytirish x *= 5
/= Bo‘lish x /= 5
%= Qoldiq x %= 5
**= Daraja x **= 2

+= bilan String ishlatish 🔤

Assignment operator faqat sonlar bilan emas, String bilan ham ishlashi mumkin. 

let message = "Salom";

message += " Mirjamol";

console.log(message);
Salom Mirjamol

Bu: 

message = message + " Mirjamol";

Bir nechta assignment ketma-ket 

let number = 10;

number += 5;
number *= 2;
number -= 10;
number /= 5;

console.log(number);

Bosqichma-bosqich:

10 + 5 = 15
15 × 2 = 30
30 - 10 = 20
20 ÷ 5 = 4 

4

Amaliy loyiha 💰

Balansimiz 50000 so‘m. Unga pul qo‘shamiz va keyin xarajat qilamiz. 

let balance = 50000;

balance += 30000;

console.log(`Balans: ${balance} so'm`);

balance -= 15000;

console.log(`Balans: ${balance} so'm`);
Balans: 80000 so'm
Balans: 65000 so'm

Assignment va const ⚠️

const bilan yaratilgan o‘zgaruvchiga keyinchalik yangi qiymat berib bo‘lmaydi. 

const age = 16;

age = 17;

❌ Bu xatolik beradi.

Chunki const qiymatini qayta assignment qilish mumkin emas.

let bilan assignment

let bilan yaratilgan o‘zgaruvchining qiymatini o‘zgartirish mumkin. 

let age = 16;

age = 17;

age += 1;

console.log(age);
18

Amaliy mashq 🔥

Natijalarni avval o‘zingiz toping. 

let x = 10;

x += 5;

console.log(x);

x *= 2;

console.log(x);

x -= 10;

console.log(x);

x /= 2;

console.log(x);

Uyga vazifa 📝

1️⃣ let balance = 10000; yarating.

2️⃣ += yordamida 5000 qo‘shing.

3️⃣ -= yordamida 2000 ayiring.

4️⃣ *= yordamida 2 ga ko‘paytiring.

5️⃣ /= yordamida 2 ga bo‘ling.

6️⃣ %= yordamida 3 ga bo‘lgandagi qoldiqni saqlang.

7️⃣ **= yordamida biror sonni 2-darajaga oshiring.

8️⃣ String bilan += operatoridan foydalanib, to‘liq gap yarating.

Bugungi darsni eslab qoling 🎯

📝 = — qiymat beradi.

➕ += — qo‘shadi.

➖ -= — ayiradi.

✖️ *= — ko‘paytiradi.

➗ /= — bo‘ladi.

🔢 %= — qoldiqni saqlaydi.

🔥 **= — darajaga oshiradi.

⚠️ const bilan yaratilgan o‘zgaruvchiga qayta qiymat berib bo‘lmaydi.
