reverse()

Bugungi darsda JavaScript Array'laridagi reverse() metodini o‘rganamiz.

reverse() Array ichidagi elementlarning tartibini teskari o‘zgartiradi.

🔄 reverse() nima?

reverse() Array elementlarini oxiridan boshiga qarab joylashtiradi.

Masalan:

[1, 2, 3, 4, 5] → [5, 4, 3, 2, 1] 

let numbers = [
    1,
    2,
    3,
    4,
    5
];

numbers.reverse();

console.log(numbers);
[
    5,
    4,
    3,
    2,
    1
]

🧠 reverse() qanday ishlaydi?

[10, 20, 30, 40]

↓

reverse()

↓

[40, 30, 20, 10]

⚠️ reverse() original Array'ni o‘zgartiradi

Muhim!

reverse() yangi Array yaratmaydi.

U original Array'ning o‘zini o‘zgartiradi. 

let numbers = [
    1,
    2,
    3
];

numbers.reverse();

console.log(numbers);
[
    3,
    2,
    1
]

🛡️ Original Array'ni saqlash

Agar original Array o‘zgarmasligini xohlasak, avval nusxa olishimiz mumkin. 

let numbers = [
    1,
    2,
    3,
    4
];

let reversedNumbers =
    [...numbers].reverse();

console.log(numbers);

console.log(reversedNumbers);
numbers:
[1, 2, 3, 4]

reversedNumbers:
[4, 3, 2, 1]
[...numbers] → Array'ning nusxasini yaratadi.

Keyin reverse() shu nusxani o‘zgartiradi.

🔗 slice() + reverse()

Array'ni nusxalashning yana bir usuli slice() metodidir. 

let numbers = [
    1,
    2,
    3,
    4,
    5
];

let reversed =
    numbers.slice().reverse();

console.log(reversed);
[
    5,
    4,
    3,
    2,
    1
]

📊 sort() + reverse()

sort() va reverse() birgalikda juda foydali bo‘lishi mumkin.

Masalan, sonlarni kattadan kichikka tartiblash. 

let numbers = [
    10,
    50,
    20,
    40,
    30
];

numbers.sort(
    (a, b) => a - b
);

numbers.reverse();

console.log(numbers);
[
    50,
    40,
    30,
    20,
    10
]

⚡ sort((a,b) => b-a) bilan

Yuqoridagi ishni bitta sort() bilan ham bajarish mumkin. 

let numbers = [
    10,
    50,
    20,
    40,
    30
];

numbers.sort(
    (a, b) => b - a
);

console.log(numbers);
[
    50,
    40,
    30,
    20,
    10
]
🧠

sort((a,b) => b-a) → sonlarni kattadan kichikka tartiblaydi.

sort() + reverse() → avval kichikdan kattaga, keyin teskari qiladi.

🪄 reverse() va string

reverse() to‘g‘ridan-to‘g‘ri String'da ishlamaydi.

Chunki reverse() Array metodi hisoblanadi. 

let word = "JavaScript";

let result =
    word.split("")
         .reverse()
         .join("");

console.log(result);
tpircSavaJ
Bu yerda:

split("") → String'ni Array'ga aylantiradi.

reverse() → Array'ni teskari qiladi.

join("") → Array'ni yana String'ga aylantiradi.

🆚 sort() va reverse()

sort()

Elementlarni ma'lum tartibga soladi. 

numbers.sort(
    (a, b) => a - b
);

reverse()

Mavjud tartibni teskari qiladi. 

numbers.reverse();

🧠 sort() + reverse() misoli 

let scores = [
    70,
    95,
    50,
    85,
    100
];

scores.sort(
    (a, b) => a - b
);

console.log(scores);

scores.reverse();

console.log(scores);
sort():

[50, 70, 85, 95, 100]


reverse():

[100, 95, 85, 70, 50]

⚠️ Muhim eslatma

reverse() original Array'ni o‘zgartiradi.

Agar original Array kerak bo‘lsa:

[...array].reverse()

yoki:

array.slice().reverse()

ishlatish mumkin.
